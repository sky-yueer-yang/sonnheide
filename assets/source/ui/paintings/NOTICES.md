# Menu paintings

The user supplied these five JPEG files from their `Downloads/油画` folder and
requested their use as Sonnheide's menu background. Necessary project files are
hosted on GitHub under the user's standing project instruction.

The originals are copied byte for byte. Their names, sizes, dimensions and
SHA-256 values are recorded in `assets/manifests/menu_paintings.json`; the offline
copy/validation recipe is `tools/import_menu_paintings.py`.

No artist, public-domain status, CC0 or other third-party license is inferred
from the `ChatGPT Image` filenames. These files do not inherit the licenses of
the engine libraries. Runtime overlays and transforms provide the darkening,
cropping, slow movement and crossfades; there is no edited replacement source.

This fixed set totals about 3.2 MB and is kept in ordinary Git so the offline
menu preview works from a normal checkout. Larger future art uses Git LFS or
pinned Releases as required by the project asset pipeline.
