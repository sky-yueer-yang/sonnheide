The original binary is designated for this project's `native-sources-v1`
GitHub Release, to be retrieved and verified by the native vendor workflow before building.
Its intended runtime path is `NotoSerifCJKsc-Regular.otf` beside this notice.
The checked-in [manifest](../../../../manifests/native_fonts.json) fixes
the official URL, project Release URL, size and SHA-256. A URL in a manifest
does not itself establish that a Release upload has completed.

`verify_font.py` is an offline, Python 3.9+ standard-library audit of original
bytes, SFNT/CFF identity, table bounds, embedded OFL declaration and character
coverage of the current native menu. It is not a substitute for loading and
rasterizing the font with the packaged FreeType build.
