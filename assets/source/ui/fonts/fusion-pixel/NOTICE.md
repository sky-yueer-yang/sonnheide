# Fusion Pixel Font

Unmodified Fusion Pixel 12px Proportional zh-Hans, release 2026.07.20 by TakWolf. Official project: https://github.com/TakWolf/fusion-pixel-font . Font release commit: c29615e1f629c6bb27dac3e6dcaa4556e629d09f .

Distributed under SIL Open Font License 1.1. The full Fusion Pixel notice and contributing Ark Pixel, Cubic 11 and Galmuri notices accompany this font in OFL.txt and LICENSES/. They apply to their respective original glyph contributions. These licenses grant no rights over Sonnheide original artwork/code.

The checked-in .otf.gz contains the exact original OTF bytes; decompression verifies the upstream member hash. No glyph, metrics, name table or embedded notice was changed. Sonn Arcade is only the application's in-memory RmlUi family alias.

The full official release archive is separately hash-locked in assets/manifests/arcade_fonts.json; it contains additional language variants not used by Sonnheide. Chinese, English and German interface glyph coverage is checked from the actual cmap; coverage is not a promise for every possible player-entered Unicode code point.
