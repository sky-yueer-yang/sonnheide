阶段0设计完成不等于阶段0原生工程完成。本轮文档核验只属于规则准备。建筑和美术先锁规格，在初始地表/游戏界面/创建/存载基础完成后立即正式制作；不把它们拖到经济和军事之后。游戏舞台未成立前不浪费批量美术制作。

每阶段新增内容先完成全批修改、依赖和跨模块审查，再**一次构建所有目标、一次完整CTest**；涉及事务/空间/保存统一再跑sanitizer。只在验收发现实际错误时集中修正并再次验收；未改shader/源件/缓存不重复烘焙。规划数值由真实测量调参，不把更新标签或空文件当推进。

## 必须优先证明的贯穿场景

1. 相同选区的最高预览、创建World、保存/载入拥有同样的有效高度/坡面/海湖/主题；首次保存故障保原Continue。
2. 一座丘陵住宅同时有步行入口、车库车道、前侧送货；邻楼不堵旧通路；拆坡道同提交撤证、停在途车并保货。
3. 两种亚种在人/动物原species限制内体现耐寒/耐饿/力量差异；提高上限不回满；高峰所有生命/飞行/神手都不能进入。
4. 新放置动物反复宰杀无可售产物；真实食物/时间才形成畜产；启智原ID、年龄/物品/伤势保留，旧牲畜预约一次撤销。
5. 只有启智动物的世界没有新文化/正式语言；人类生出文化语言并真实教授后动物可教书/工作/继位；合法后代意识继承但不生文化。
6. 王位/私人遗产分账，未成熟继位/摄政、选举并列/空位无候选不刷人；改辖区不瞬移/吞税债/伪造和约。
7. 普通清楼/路先处理人货与已有接入，生命清理留死档；地形复制/恢复/换主题不补熟果/矿库存/人口/衣服。
8. 长期公共经济与服装耐久/修补/需求不会在头批消费后全行业停工；缺正装者仍工作领薪。
