# 完整施工计划：先完成启动、真实空世界与游戏界面，再开始建筑

2026-10-07。按最新用户要求重排为 **11 阶段（0—10）**。阶段0—2先交付原生启动/深沉油画主页面、创建世界、真实初始地表、底部三语界面、Light/Darkness环境控制与保存载入；**基础体验验收通过后，阶段3才启动新的建筑、人物和服装资产制作**。本计划覆盖完整游戏；阶段是结果门槛，不是周历，没有团队/硬件/工作量数据前不虚构工期。每阶段约3—5个工作包。排序见[ADR 0007](../decisions/0007-foundation-experience-first.md)，油画与两种环境见[ADR 0008](../decisions/0008-sacred-interface-and-light-ages.md)，纯文字主菜单/静态公司Logo/无不必要小字见[ADR 0009](../decisions/0009-monumental-minimal-interface.md)。程序结构见[CLIENT_STRUCTURE](../architecture/CLIENT_STRUCTURE.md)，启动与切世界见[APPLICATION_FLOW](../architecture/APPLICATION_FLOW.md)，环境单写者/计时见[LIGHT_AGES](../architecture/LIGHT_AGES.md)，规则源与有限实现见[DOMAIN_MAP](../architecture/DOMAIN_MAP.md)和[VALIDATION](VALIDATION.md)。

**当前执行范围：** 用户确认主页面视觉后，要求“就把接入做好”；本轮只完成原生窗口、GPU、界面、输入、三语设置和来源托管。真实地形包、创建World和生产存档暂缓，不把创建/载入提示页面当作这些功能已实现。

## 1. 先突破的依赖与三条施工线

真正的首要依赖是“可信地理包→隔离创建候选→发布一个空World→原生地图/界面读取它→安全保存、切换与返回”。主页面和漂亮地形不能各自维护一份世界；不能在预览阶段分配生产人物/国家/建筑，也不能先卸掉旧世界再尝试加载新世界。先把这条可反复运行的应用流程做实，再在其上增加建筑和生活。

|施工线|阶段0—2允许做|基础验收后才开始|贯穿限制|
|---|---|---|---|
|A · 地表/UI与后续原创内容|基础地表材质、天空/水面、字体、原创UI图标/主页面视觉；建筑/成人/衣物仅规格、许可与预算准备|阶段3原创楼体/地基/入口/围网、成年角色/服装作者源与代表件；后续按功能完成各家族|前期不新做建筑或人物样衣/模型，不以建筑工作掩盖启动流程未完成；已有灰盒与离线来源保留作为旧验证输入|
|B · 原生客户端/渲染/三语|应用状态、主页面/设置、创建/载入、相机、底栏7分区、输入仲裁、三语和基础信息窗口|真实人物/建筑点选与互通编辑，逐步40页、比较、领域工具与性能|UI不另造World；浏览器原型不能替代原生端/GPU证据|
|C · 权威世界/地理/存档|冻结地理定义、World identity、空世界发布、隔离候选/取消/失败、最小checkpoint与profile|人口/库存/任务/劳时统一，公共生活和完整领域因果|一事实一owner，oracle保留验证而非四份生产World互相同步；不赠人口/物资掩缺口|

**门槛顺序不可倒置：** 原生应用成立→创建真实空世界→游戏界面/保存切换可用→原创代表件/建址→首次生活。阶段0—2可以进行建筑尺寸、门位、成年rig/fit、来源许可研究；“规格已准备”不等于“制作已启动”。UI和地表本身需要的视觉资源属于基础体验，不受建筑后移限制。

### 基础体验验收必须包含什么

1. 真原生启动→主页面→切英汉德→选择已核验区域包→只读预览→确认创建。
2. 空世界实际显示固定真实高度/天然陆海；人口0、建筑0，查看来源/原精度/比例；相机与底部七分区不写模拟。
3. Light/Darkness手动→开启自动/修改时长→暂停/保存→返回→载入→天然hash、worldId、时钟、环境/自动余量与空世界事实一致；手动切换原子关自动，同tick竞态、跨多个deadline加速与连续运行对照，旧档迁移不重解释时间；视图按对应worldId恢复。
4. 保留当前World发起另一创建/载入：取消、坏源、坏档、预算失败、迟到结果不毁当前World/profile或好存档；成功只换一次。
5. 反复创建/载入/返回/退出，已弃候选和GPU资源释放，旧typed引用/环境计时/回调不得落到新世界；油画加载失败与降低动态仍能用菜单，主菜单右下角右对齐纯文字无icon，全部按钮无边框且无不必要小字，Logo/多环钟盘整组固定顺时针倾斜且静止，油画小亮焦点/大部分渐暗对照，主页文字/射线/光晕同色#fff6df静态柔光，无按钮ring；三语失败反馈与IME/DPI/focus实测。

### 基础体验不需要先做完什么

- 不要求40类信息页、251关联路线、35项法规全文、完整企业/宗教/战争工具或10000人口性能；未接入工具清楚不可用，不能假成功。
- 不要求完整全球可创建覆盖或房屋尺度地理精度；首个已核验区域包先完成，覆盖/精度上限在UI显示，全球验收单列。
