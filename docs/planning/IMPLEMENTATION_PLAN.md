# 完整施工计划：先有原创资产，再有贯穿世界

2026-10-06。计划覆盖当前基线到完整游戏交付，分 10 阶段。阶段是结果门槛，不是周历；没有团队规模/硬件/工作量数据前不虚构工期。每阶段约 3–5 个工作包，按真实依赖施工，不拆成每天几十张任务。程序结构见 [CLIENT_STRUCTURE](../architecture/CLIENT_STRUCTURE.md)，规则源与有限实现见 [DOMAIN_MAP](../architecture/DOMAIN_MAP.md)和 [VALIDATION](VALIDATION.md)。

## 1. 三条并行线与真正依赖

|施工线|从哪里开始|贯穿责任|限制|
|---|---|---|---|

## 4. 阶段 1：原生骨架与正式视觉样件

**结果：** 自研C++20原生客户端，底部壳和对象窗口读取真实少量World；作者源进入近景，不依赖浏览器。

- **1A 平台/渲染桥：** 固定SDL3/bgfx/bx/bimg/工具兼容commit，macOS Metal先实跑，再Windows D3D/Linux Vulkan；resize/HiDPI、输入/IME、相机、PBR/IBL/阴影、GPU生命周期；不并行第二套renderer。
- **1B 原生界面：** RmlUi/FreeType/SDL3/bgfx桥；section/工具、焦点、状态、对象路由/搜索/返回、三语切换、字段草稿/回执；中文IME、ä/ö/ü/ß、长德语、caret候选框、多DPI。
- **1C 统一世界接口：** 单写者CommandGateway、detached query/render snapshot、EntityRef/档案、基本PlacePerson；最小人员/物品/建筑迁入权威World，oracle保留差分，不维持双生产事实。
- **1D 正式视觉：** 住宅/广场/工坊/港口样件，成人/基本衣/搬运进入cgltf→pack→ozz/bgfx；原创模块/许可、LOD/材质预算；原创图标进入RML。

**退出：** macOS真实设备窗口/拾取/IME/DPI有记录；Windows/Linux至少构建启动，GPU按设备记录；近景点人开同一真实Person页；切语/镜头/窗口不改World fingerprint；clean clone所有输入可取。无GPU CI不冒充画面通过。

## 5. 阶段 2：真实地表与有入口建造

**结果：** 官方固定源生成真实世界，坡地单栋有效、邻楼不毁旧入口；港口依赖人工陆地，正式水体移植。

- **2A 地理到世界：** 完整ETOPO/GSHHG固定源/许可、分块EarthPack、全球低LOD/局部选区、AEQD/日期线/极区、同XYZ scale、NoData/datum/precision、冻结mask/height hash；DEM不具车道精度时明确限制或合法细DTM。
- **2B 地基/入口：** Site接权威World/产权/预算/导航/永久保护域；联合批准长方体地基、完整人行、必要车库车道、现状地面前侧接货、施工占用/网罩；全车身转弯/底盘扫掠、stairs/landing、标高/自交/共享权利，不切山。
- **2C 人工工程/Port：** 路/桥/逐格四邻接填海，真实材料劳动、完工LAND；Chunk+portal三态导航、临时阻航/泊位；Port四向/连续WATER/RECLAIMED-only；原创路桥岸壁Port同步批次，不借水平台。
- **2D 水/地视觉：** Abyssal固定算法→bgfx GPU与CPU FFT对照；岸线/mask、浮动原点相位、泡沫/深度pass、三后端shader/RT预算；地表/施工overlay只读。

**退出：** 真实坡地住宅的联合建址证书包含现状地面接货、人行入口、必要车库车道、围网施工占用及永久保护域；测试实体沿完整路线进门/入库，后建邻楼仍保旧通道，证书/空间状态保存续跑一致。非法基/短坡/错侧接货/狭岸/泊位侵入/海岛拒绝无半写。GPU幅度方向与CPU一致；自然hash不变；记录GPU/导航时间；至少一条住宅/广场/港口正式外观，灰盒不是最终承诺。真实Person搬运、材料/工期结算和全域生活存档由阶段3在同一场景完成，不把尚未接入的行为算作阶段2证据。
