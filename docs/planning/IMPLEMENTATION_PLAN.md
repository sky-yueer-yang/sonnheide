2026-10-09，实施顺序第二版，基于 v0.9 / ADR0018。**本文件整体取代上一版计划，是当前唯一施工顺序。** 2026-10-10：S00/S01 已进入新 C++ 原生实现与统一验收；S02—S12 尚未交付生产实现。具体构建、原生 GPU、持久读回和平台状态见 [S00/S01 本批报告](S00_S01_NATIVE_DELIVERY.md)，不能将功能已写或开发机通过称为目标平台完成。旧 PBR、旧 headless、Python 模型结果不继承为新阶段完成度；被替代计划从 Git 历史查阅。

## 3. 各阶段工作包及退出条件

### S00 原生基础、协议与街机主菜单

1. 建真实 C++20 核心/应用/平台目标，核心独立窗口/GPU。复用 [当前依赖锁](../../data/native_dependencies.lock.json) 与已核原件：SDL3/bgfx/RmlUi/FreeType及wrapper/bx/bimg七项，不重新下载调查；验证 Windows 编译、字体/输入/UI/GPU初始化风险。
2. 落地 Ref/墓碑、量纲/整数时间、SONNRNG1、包准入、单写者命令/版本/事件及11阶段 tick 最小路径。新域扩指定阶段，不建自己的时钟、随机和健康写入器。
3. 按2026-10-10最新要求，所有前端连同主页全部采用复古街机像素构图、像素字体和填充像素控件；旧油画/Logo原件保留为历史来源。设置、三语、DPI、中文IME、德文长文、无框可见焦点、失焦、音频设备/音量基础成立。两套UI配色直接跟随World的Light/Darkness。
4. 建 query/typed draft/preview/commit/三语错误与关系导航，先交 World/设置/存档状态；全局工具只进八底栏。没有handler的能力不装成可执行成功按钮。
5. 新建统一一次全目标构建＋完整CTest入口、必要项目/内容校验、场景输入/replay/故障记录。保存header/包hash协议开始实装；只随真实功能建目录。

**退出：**新原生程序启动、菜单三语可操作，实际链接锁定组件，核心不include GPU/UI；命令幂等、时钟/RNG/晚结果边界可复现。Windows栈风险和设备待验项清楚记录；当前实现的真实结果以本批报告为准，旧程序不作证据。

### S01 初始真三维地表与创建世界

1. 固定八档column顶/侧面与真实深度，渲染/水网/射线/支承同源；原创像素地皮、静态像素蓝色水面、方块云天空及Light/Darkness基础效果。画风参考Minecraft的方块材质和简单方向光影，移除写实反光/PBR，不用无材质单色地图交差。
2. Blank全海/平土与Earth海陆选区共用候选。GSHHG只初始化海陆，固定投影/日期线/格中心分类；无DEM、随机高程或岸边/外缘过渡。全球导航图与最终最高可玩精度预览分开，最终预览准确对应生成。
3. 精确矩形裁切、8格deep-ocean guard、域外纯表现海；无墙/框/海面尽头，矩形截岸如实展示，普通chunk边不是海岸。初始0人类/0启智动物/0楼；只开放并生成当期已实装的初始来源，其余生态选项暂不开放，不能先记录未实现配置再在升级/载入时补刷。S04/S06接真实植物食源/动物后分别回验Blank/Earth来源预算、首档发布与不重复生成。
4. 轨道yaw/pitch、360°、近地观察、缩放/移动、底栏与真实拾取，侧面/遮挡可见；域外可看，写入拒绝。
5. 隔离候选→预算/包验证→首checkpoint持久读回→World/Continue发布；返回、取消、失败、晚结果、继续共用生命周期。

**退出：**Blank/Earth创建→旋转近看→保存→返回→继续/载入成立，几何/主题/来源一致；失败保旧世界。Windows真GPU留下斜视/侧面/近景/水天空/UI及设备证据，开发机/NullRenderer/CI不代替。

### S07 文化语言、正式城市、国家与扩张
