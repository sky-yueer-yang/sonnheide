## 第一条必须完成的基础故事

**原生启动→批准的主页面→英汉德→Blank/Earth两入口→来源/尺寸/profile/预算→同算法最高预览→首checkpoint写入读回→0人0楼真三维像素World→旋转/拾取→底栏刷地造岛丘山/湖海峡→Light/Darkness→保存返回→载入续跑。** 坏源/坏档/超预算/取消/迟到均保当前World和好档，成功只发布一次；WorldId只隔离镜头窗口收藏/profile，locale是全应用偏好。

Earth首版来自真实海陆/岸线，不含DEM实测高度/水深；Blank可选全海或平陆内域、外沿仍为明确外海源，玩家塑造地表。二者共用量化权威和持久化。起始2m格/.5m高度量化/64²chunk待准入，创建后profile冻结而有效地形可变；水位0、四连通外海源为SEA否则LAKE，不做洞穴/高位湖/瀑布。自然来源证明与编辑后果分开，25×25 ETOPO历史窗口不称全球地图；新创建入口只列已准入且覆盖可用的数据包，全球导航不保证每个地点full可创建。

基础门槛还必须用核心真实结构fixture证明 **OccupiedTerrainAdapter**：一格海峡影响远港、楼基/入口/人/货/任务的依赖闭包，保护跳过/破坏批准、陈旧预览/分配失败强异常、失效证书同提交撤销、有限撤销不复活退货。这先于城市play，阶段4再接实际居民与经济。Godterrain不耗工程材料但不产商品/退款；文明填海/楼基仍付真实投入。普通施工与分类清理保旧通路，破坏地形神力可毁通路且结算后果。

基础阶段不要求40页/251关系、35法全文、完整经济宗教战争/生态生长、全球所有地点或10000人口；未接能力不假成功，新创建不赠人房机构物资。首版静态水位/深度表现允许，原创像素水深度/边界/透明拾取/明暗与GPU预算必须验收；固定Abyssal是可选数学参考/迁移，不将完整写实FFT/泡沫/折射列为Steam门槛。MakeHuman不进入新生产人物路线；旧MakeHuman/PBR大资源/Release及许可历史全部保存。

地皮、纯装饰小植物、功能树严格三层：地皮/装饰不产货不参与农业；装饰按seed/密度/清除mask复建；树有生长、木材和合同可食成熟果。农田独立不变，恢复只管新野生萌发，关闭旧树照长/成熟。主题重刷/LOD/重载不补木果或重置树龄；实际采收有路径工时容量/预约。沙地是材质habitat，干沙优先/水下不新长椰树，旧树不变种；炎地首版纯静态有界熔岩地皮，无流体/灼伤/焚楼/随机喷发。

底栏八分区为观察、地形与生态、人物、文明制度、建设资源、经济物品、世界、设置。World Laws保留 `reproduction / aging / hunger_consequences / ai_new_wars`，另加 `god_terrain_enabled / natural_vegetation_regrowth`；饥饿/衰老关闭不免除神力危险，恢复开关不冻结旧树或独立农田。
