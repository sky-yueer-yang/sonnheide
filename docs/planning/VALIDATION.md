# v0.8验收边界与贯穿场景

本轮仅核对设计与机器合同。所有生产功能尚未实现，不能运行已删除的旧build/validator；历史PBR/headless/CI证据不转为新完成度。工程落地后先完成本批全部改动，再统一一次全目标构建+完整CTest；事务/空间/保存修改统一sanitizer，实际错误集中补修后再验。

## 设计核验

原v0.6源hash不变；248研究项全部有唯一处置/具体原因/新设计和合同落点；正文27章覆盖全部原领域并明示旧矛盾覆盖；新contract JSON结构、ID/三语、引用、species包络、遗传权限/意识来源、坡面量子/高峰规则、繁育开关、人口来源、World Laws与继任一致；历史/新版明确区分，退役后的当前入口无失效链接。

## 必须运行的工程反例

|反例|要求结果|
|---|---|
|2m/.5m格造1:8车坡|坡角细量子125mm产生连续合法坡面，不把.5m陡阶称缓坡|
|一角高峰的坡格|只峰多边形禁区，高峰上方飞行也不可；山脚未峰部分仍可按真实坡度走|
|NW/SE干、NE/SW湿的ramp格|两个局部湿连通分量，不因同格wet=true偷偷打通海峡|
|丘陵宅有人入口无车道|有车库建址拒绝；坡宽/转弯/送货任一不足不能开建|
|普通邻楼/墙堵旧宅|建设拒绝，旧通路证书不暗失效|
|Godterrain拆唯一坡道/海峡|预览列本地及远端依赖，提交同时撤证、停任务、保人货或记真实伤损|
|旧坡道恢复写到新编辑上|revision冲突拒绝或重算预览，不覆盖新几何/历史|
|耐寒拉满上峰|仍不可进入；低于峰在Cold阈值内可减少负荷，饥饿保温仍耗能|
|提高最大血/能量/寿命|绝对伤/能量/已活时间保真，不回满、不复活|
|亚种把兔力量/牛速度全拉满|仍受不可编辑species包络，兔速度与牛力量特色不被翻转|
|连续放动物然后宰杀|不能卖源不明肉/皮/骨；真实进食reserve才可回收一次|
|同动物重复照光/载入|同Actor年龄/身体/伤物保留，无奖励；只有一次身份转换事件|
|照光命中牲畜有货/预约|产权终止和CivicAgent注册同提交，真实货保产权，预约调整不复制|
|启智亚种编辑advanced=true|拒绝，意识源只能神光或合法已启智亲代|
|只有启智动物的聚落|不发生Primary/Secondary Culture或正式语言创生/分化|
|学会人类语言后人类灭绝|语言文化继续被使用/教学/保存，不删除，不再无源新创生|
|关闭新繁育已有孕期/蛋|禁止新受孕，既有按真实到期继续；复开不积压爆生|
|年龄0人或动物|成人体规，出生来源0岁；资格按人类18或species成熟，不因体型成年|
|空国家招工/征兵/迁移|无Actor来源拒绝，不刷人/士兵/移民|
|幼君即位/先君私人债务|摄政独立执政，王位不承继私人物资，遗产剔除代管先结债|
|选举并列/无合格候选|按章程确定下一步与空位，不能随机造君主|
|跨国边界画私宅/库存|只明确主权/行政变化，不吞产权、不伪造和约/居民迁移|
|缺正装公司聘人|仍工作领薪保岗位，只提高真实可支付衣物购买优先|
|首次衣物全买够后多年|有限耐久/修补/真实更换产生持续需求，不无限修、不刷款装|
|关野生恢复+换主题/LOD|既有树果/农业继续，decor无资源；不补树/熟果/木储|
|清楼有人/船有货/清生命|普通清楼保人货/接入，港登记不消失；生命记死亡且结任务/继任|
|钱已付款货在半路|源仓不再可用、目的未到不能用，断坡只改真实Shipment状态|
|神意祝福/装备雨/复活UI入口|护理/真实调拨可执行；免费物资/护盾/死人复活没有生产命令|
|创建首存档磁盘满/晚mesh|保旧World/Continue，新generation失败不能发布|
|加载非法species/负库存/伪神授|拒绝/显式迁移隔离，不自动批准/赠物/换species|
|镜头/locale/粒子/图表设置变化|同种子权威World结果相同，UI草案不丢失|
|Fog看不到外地|外地仿真仍推进；控制命令不能绕过实际知情和身体能力|
