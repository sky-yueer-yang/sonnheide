# 实物像素图标：生产图册与语义设计

当前最新覆盖：图标必须高分辨率、重磅粗线、暗而鲜艳。41 张实体图已重新制作，采用两逻辑像素深墨外轮廓和约两像素的主要内部刻线；上一轮一格细轮廓和浅亮高光只保留为历史记录。

本轮按钮图像直接作为实体物件设计，而非给旧线条符号加边框。41 个稳定资源名均已重新制作；采用原创程序绘制，完全透明背景，无第三方图片或字体，也不授予原创图像公共开放许可。图像配方为 `tools/generate_visual_assets.py`，审计登记为 `assets/manifests/original_ui_icons.json`。

48×48 是精细按钮插画的逻辑色块网格，96×96 与 192×192 为整数 2×、4×无插值导出。每张 SVG 仅包含整数坐标、整数宽度和 1 单位高度的矩形色块；相邻同色横向像素合并，不使用嵌入 PNG、曲线、外部资源、字体、描边或模糊滤镜。SVG 与两个 PNG 表达完全相同的像素。图形至少占据每边 75% 的画幅，留真实透明的安全边，禁止用透明 padding 缩小按钮内容。

材料采用压暗而高饱和的主体色、阶梯明暗色簇、粗刻槽与纹理。取消大面积白、黄高亮，仅留面积很小且亮度有上限的材料亮点。主体安全绘图区为逻辑格 [3,44]，随后生成 Manhattan 距离不超过 2 的深墨外轮廓；任一非深墨材料像素的该范围均不允许透明，画布最外行列仍透明。每个实物的主要内线独立重画；双碑刻槽先采用三源像素宽度，再于最终 48 格画布重刻为每条恰好两格厚度，修复量化可能带来的多一行暗色。十道槽逐格验证均为实心 2 格刻槽，各 7–8 格长，彼此至少间隔 2 行石面，位置写入 `key_line_features`。不是把整盒彩色内容膨胀或模糊。暗轮廓用于物件分离；没有强制白色环边、统一方框、白色斜面或定向白色边框高光。金光由可数的阶梯射线和亮点组成。白色用于石材、羽毛、雪、银及实际光点。黄色原色为 `#ffaa00`，是可追溯的色源，实际金材质使用它的较深派生色，不强制显示未压暗的本色。明暗和少量染白均有明确登记；石材、木材、铜、皮肤、植被是另行登记的材料基色。材料色簇不会因环境 Age 自动变色。蓝、红、黄、绿、铜实际用色按 `0.2126R + 0.7152G + 0.0722B`（sRGB 字节 0–255）度量不超过 160；所有物质的该值超过 220 的像素为零。具体逐图实测值与外轮廓检查写入 `SonnOriginalIcons9` manifest，不能只声明粗线。

八个分区是不同物件家族；分区与同域工具按语义复用图像，保持识别稳定。返回与向左也刻意共享黄铜左箭。这里的草、动物、建筑、书本与金币是纯 UI 图像，不能创建仿真实体或实物库存。

若以后引入 AI 创作参考，提示词必须首先说明按钮语义，再说明实物构图、材料与刻面，而不是只要求“像素图标”。例如：

> 世界规则按钮。两块有厚度的、刻有十道古老刻槽的石碑，五道一块；深蓝灰石材，细小自然裂纹，石碑背后强烈金色放射光和分层像素金环。图形饱满占据画幅，透明背景，完全硬边的高分辨率复古像素插画，不要文字、整块底板、软模糊、摄影或平滑矢量曲线。

生产资源当前全部采用可重放的程序配方，保证真透明和真像素 SVG。运行 `python3 tools/generate_visual_assets.py --check` 只重建内存结果并逐字节校验，不能重写资源或以不一致 manifest 冒充通过。每个对象的实际范围、实际面积、材料颜色数、深墨占比、分材质亮度上限、两格外轮廓检查和文件哈希均写入 manifest，原生 UI 是否加载和实际显示由本批原生验收独立确认。
