# SONNHEIDE 前端美术规范

2026-10-10 / ADR0022，覆盖所有旧颜色、无边框、剪影及地图创建要求。真实原生街机像素UI；此文件说明目标，实现结果见当批交付报告。

蓝白红黄构成界面主色。背景进一步压深，稍偏青；菜单保留实际闪星与流星。框的中心深色半透明，厚度只通过深色边缘表现，禁止白色斜面与定向高光。深饱和蓝按钮、深橙红选中、黄色重要文字，黄色本色`#ffaa00`。允许从主色派生明暗。

弹窗、输入、选择器、提示、按钮和底栏使用厚深海蓝像素边带、切角与明确pressed/focus反馈。中心与框带互不重叠，半透明中心只混合一次。按钮保持足够命中面积，图标32dp或更大，细节由原始32格整数放大，禁止插值模糊和细弱单线标志。图标必须原创：全周均匀连续纯白轮廓、细深蓝外界线和饱满平色主体；不加投影或高光斜面。图标蓝色本色`#1662b8`、橙红本色`#de402d`，按钮使用更深的同色族；配方、PNG/SVG和manifest同源。

正文是真实12dp三语像素字体。重要标题24dp、主页36dp，红/黄实体字加均匀纯白二值像素描边。中文标题及世界名称使用单向水平字形膨胀保留内部字腔，Latin主页标题使用方形膨胀；轮廓没有定向高光。锁定Regular字体通过真实FontEffect生成效果，不请求不存在的Bold，不用浏览器CSS假效果或截图贴字。保持必要状态、输入后果和错误的完整可读语义；装饰小字不增加。

创建世界只有平土/全海，没有世界地图、Earth、经纬度或框选。608×648dp完整表单正中央、受视口减32dp约束、真实滚动；名称、五档实际尺寸、独立长宽和主题集中。预览成功折为底部创建托盘，场景支持360°查看；编辑恢复居中表单，任何参数变化使旧预览失效。没有假的即刻成功，首档读回后才发布World。

八分区为搭接工具栏上沿的低矮梯形页签：顶窄底宽、像素台阶斜侧、底部开口；选中分区深橙红并略高。页签和工具栏有真实搭接，不能做成八个四边封闭方块。参考已实际浏览的[WorldBox开发者截图](https://x.com/Mixamko/status/1575249911507046400)，不复制其图标资产。面板内部只有当前分区工具，未实装工具清楚禁用。工具全名通过实际简中/英文/德文tooltip可查。模态/表单/输入阻止背景镜头操作，关闭后释放；小窗口/DPI2仍可命中、滚动并切换。

地表仍是ADR0021的真正独立微几何和细像素材质，UI厚边不为地表增加彩色轮廓。Light/Darkness是世界环境，UI保持四主色与可读性。隐藏、暂停、降低动态冻结本地表现时间，不消耗模拟RNG；不改变任何人物、库存或地形。
