# Sonnheide：深青蓝半透明与无框像素界面

2026-10-10最新要求，按[ADR0020](../decisions/0020-translucent-navy-borderless-ui.md)覆盖柜式大框、大字和紫绿主色。[ADR0019](../decisions/0019-fine-terrain-and-colorful-arcade.md)的细地形继续有效。全部前端是高分辨率复古像素游戏：偏青深蓝背景、全部框为深色半透明；按钮尽量无边框，底栏按钮全部无边框。此前卡其羊皮纸方案被最终要求替代。

UI与icon主要蓝、红、白、黄。黄色本色统一`#ffaa00`；亮暗、渐变和光照由此派生，例如0.5倍`#805500`、20%白色`#ffbb33`、50%白色`#ffd580`。偏青深蓝半透明填色承托白/浅蓝文字，红蓝区分操作；重要事实有足够对比。世界Age只影响环境与状态，不锁UI整套配色；世界植物自然绿色不受UI约束。

主页是偏青深蓝星空。细星分布疏密有别，少量十字星，亮度及相位缓慢变化；偶发斜向流星有纤细渐隐尾迹。背景原生GPU绘制，无图片、油画、菜单假World或静态群岛。小一号SONNHEIDE像素字标与五项无框紧凑菜单；不再有包住整组的大框和宽大色块。真实可操作，中英德及最低640×480保可读。

信息页、创建控制、输入、下拉、滚动、弹窗采用无描边填色和细像素切角。正文12dp、重要标题24/36dp，缩紧间距但保留可点区域。当前只有Regular字库，不能靠font-weight:bold假称实际加粗；标题用字号、亮度和有界实体投影强化。选中、悬停、按下、键盘焦点以填色和明暗表达，不围每个按钮。

八底栏大icon、小字：宽屏目标64dp图标/12dp标签，窄屏相应压缩；英文德文短词尽量与图标边长接近，全称tooltip按需显示。32格原创图标整数放大到96/192px，alpha二值、GPU点采样；蓝#397dde、红#e34b3f、白#ffffff、黄#ffaa00的明暗配方与实际输出hash保留。Fusion Pixel原件及OFL不改，中英德用相同实际像素字形。

世界地形颗粒真实250mm，每64²chunk实际16m。默认512²地块128×128m，最高1008²为252×252m，当前边界不是最终容量宣传。平地仍按八档固定高度。最高创建预览、mesh、侧面、支承、拾取、水深及存档一致。

原创128²材质使用大小不同的色簇、低对比纹理与稀疏细节，32px/m即单纹理像素3.125cm；世界空间采样，合并顶面不会拉伸图案。小草、花和石粒以小尺寸形成自然稀疏分布与细风动；这些只是装饰，不伪造树果、食物、人口或资源。机制树与正式角色/建筑后续独立制作。

水色从蓝到青绿，根据真实水深变化；动画为细像素水纹和离散亮纹，不使用写实镜面、Fresnel或PBR。天空分层色彩与薄云缓慢漂移。所有表现只用本地时钟，降低动态、隐藏及世界暂停冻结，不消耗模拟随机数或修改World；恢复不跳时。

实际验收需全界面三语/DPI/窄屏、细地形斜视及近景、材质消融、真实创建/存载/取消与错误、360°拾取，以及星空运动与冻结对照。CPU表现时钟必须严格不变；GPU冻结图像仅容最终UNORM通道最多1/255舍入差，所有更大变化拒绝，运动图像必须有超过此容差的实际变化。记录最大差、真实GPU/hash与包，不声称字节完全一致；不能把文档、NullRenderer或CI当GPU视觉通过。
