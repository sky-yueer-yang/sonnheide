# SONNHEIDE 前端美术规范

2026-10-10 / [ADR0026](../decisions/0026-compact-two-row-toolbar.md)。当前界面统一采用很深灰色石材；覆盖ADR0024浅奶黄石面与此前木材/皮革/珐琅等大面积面板和按钮底色。全界面保持高分辨率、粗重但克制的实物像素风。

创建、世界信息、设置、帮助、错误、存档、主页菜单承托、状态与提示等全部窗体采用同一深灰石材。通常的执行、关闭、工具、存档条目、选项与分区按钮也使用这块石材。黑曜石可保留给输入槽。石面整体很深、近中性略冷，表面细颗粒与矿物层次低对比；完整石板上只有少量来自真实边缘的缺口和短裂纹，按钮及页签同样有适量裂纹，不平铺成满面碎块。

工具台顶端保留连续6dp凸石沿及2dp阴面，38/42dp低矮宽肩页签接在沿上，不挖沿也不重复涂画。控件结构用石材本色明暗表现。默认、悬停、键盘focus、选中、按下及禁用在同一岩石材质上变化亮度与文字强调，避免大面积彩色底板；选中状态要与默认明显可辨。正文亮暖灰、次级文字灰色、标题亮字实际加粗，禁止残留浅石底的深棕/深红字。模态遮罩继续压暗场景。

普通实物图标采用48²逻辑像素，整数放大的96/192PNG和相同像素SVG，透明背景。物件外缘至少两逻辑像素深墨色，内部结构线粗重；主体每轴占画布至少75%，不是大透明留白中的小符号。常用48dp图标配60dp按钮。八分类使用独立48×28逻辑格的扁宽纯暖白剪影（#fff6df），不套彩边和圆形底盘；播放与暂停仅三角/双竖条，分类名称显示三语提示。图标保留蓝白橙红黄与物件固有色，鲜艳色保持饱和且稍暗；黄色本色`#ffaa00`。不增加白色立体亮边，无抗锯齿、模糊缩放和PBR。

常用动作文字24dp，标题24/36dp，事实正文12dp，使用实际Fusion Pixel字形。菜单宽度和创建动作按真实字宽决定；中文、英文、德文与小窗口重排和滚动，不裁掉动作。必要后果、状态与错误完整，装饰碎字不增加。纯材质没有模拟身份或资源。

创建只有平土/全海，窗口正中且受视口约束；五档512m至8.192km和独立长宽不改变。预览成功收为底托盘，支持360°相机；返回编辑或修改使旧预览失效，首档读回后发布。工具台固定两排，左侧播放/暂停、折叠速度、Age及世界信息跨分区常驻；竖线右侧只显示当前分区工具。窄视口保留两排、必要时横向滚动，八分类可达。速度展开七档0.5/1/1.5/2/3/5/10并在选择后收起；Age打开独立居中光明/黑暗与自动/手动页面。未实装操作真实禁用。模态输入隔离镜头，关闭后释放；键盘focus始终可见。

原生纹理最近点采样，512²材质纹素按1dp铺设，UV与边缘裂纹使用有界缓存几何。材质状态不修改World、不消费模拟RNG，Age不锁UI颜色。主页仍是深蓝原生闪星和流星。源件/hash/配方、程序包与真实画面一起验收。本批见[双排工具栏交付](../planning/COMPACT_TOOLBAR_DELIVERY.md)；[深灰石材交付](../planning/DARK_STONE_DELIVERY.md)为历史；[浅石碑交付](../planning/STONE_TABLET_DELIVERY.md)和[实物界面交付](../planning/PHYSICAL_PIXEL_DELIVERY.md)保留历史证据。人物、建筑与后续机制不因界面变化而提前宣称实现。
