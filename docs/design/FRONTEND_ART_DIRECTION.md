# Sonnheide 前端与初始世界美术规范

2026-10-10，按最新用户要求覆盖此前的平滑面板、描边与单套暖金 UI 路线。最新明确要求所有前端彻底复古街机像素化，主页也一并重做；五项必要操作仍保留。设计登记不等于 GPU 视觉验收。

## 高分辨率像素世界与界面

世界是真三维、高分辨率像素体块，顶面、侧面、投影、材质像素、实际深度和遮挡共同表现尺度；360°旋转与近地观察均真实。轮廓依靠光照与明暗辨认，禁止任何颜色的轮廓线、选择描边、格线或发光边线。Light/Darkness 是世界环境 Age，不建立太阳、天文或每日昼夜系统。

全部前端均复古街机像素化，包括主页、文字、面板、按钮、输入、下拉、滚动条、浮层和特殊图标。用户油画和Logo原件历史保留，不再用它们组织本批主菜单画面。用整数像素的双阶梯角、实心填充和偏移块状阴影形成层次；不得仅把平滑网页换色后称为像素 UI。文字使用正式开放的 Fusion Pixel 12px 像素字体，24/36/48/60dp整数倍排版；高DPI仍清晰，不能使用衬线艺术网站字体。画面精细、克制、庄严，不堆装饰小字或杂乱宗教符号。

## 两套权威 Age 配色

|状态|基底与文字|重点与选择|
|---|---|---|
|Age of Light|深蓝 #0c182a、白色，少量微暖金中性色|克制暖红 #773640；危险事实 #ff7777|
|Age of Darkness|黑 #080808、白色，中性灰次要事实|明确 #ffaa00；选中填充配黑字|

UI 禁止绿色、紫色，含图标、焦点和状态；世界植物可以自然绿色。颜色由应用每帧读取实际 World/创建预览 Age，设置和从世界打开的载入页随该世界；主菜单和无世界的创建草案默认 Light。载入恢复权威 Age，不另建 UI 时钟，不由未提交按钮先换色。点击手动 Age 切换必须通过单写者命令，并原子关闭自动交替。

所有按钮、输入和窗口零 border/outline/ring，无伪元素边框；焦点和悬停用整块明暗变化、字重，选中同时保留明确事实与控件状态。透明像素角不产生颜色描边。文字和重要后果可读，不能为了气氛把错误隐去。

## 结构、交互与图标

地图占主要空间，全局工具进固定底部八分区：观察、地形与生态、人物与动物、文明制度、建设资源、经济物品、世界、设置。S00/S01 尚无消费者的分区明确禁用；不会显示假成功。对象窗口只放局部信息、关系、草案、后果与关闭。创建草案在一侧，真实地图/三维预览占主区；窄屏折叠草案，底栏四列两行。三语、中文输入、德文长词、高 DPI 与键盘可见焦点均须实际核验。

特殊图标用 `tools/generate_visual_assets.py` 原创几何生成。先在24×24逻辑格中心生成二值像素轮廓和三档填充明暗，再整数最近邻复制为96/192像素；提供 Light/Dark 两套。SVG 作者源全部整数1格实心矩形，PNG alpha只含0/255；运行时图标点采样，字体单独保留平滑采样。禁止描边与超采样平滑图标。每项配方、源件与输出 hash 托管，原创不擅自开放许可。

主页标题 SONNHEIDE 为大像素标题，下方五项实体块文字按钮组成街机构图；宽屏两列、窄屏单列。背后为独立原创三维方块群岛背景，不创建World、不写个人存档；不沿用油画网站构图或旧右侧竖排。中文、英文、德文都用未修改的Fusion Pixel 12px Proportional zh-Hans，运行family alias为Sonn Arcade；全部原始OFL及贡献者许可、官方版本/commit/压缩原件hash保存。UI locale仍与模拟Language分离。

## Minecraft 式三维方块画面

风格目标是清晰精美的方块像素游戏。所有纹理、图标和几何均原创，不复制Minecraft或WorldBox素材。每2m核心格对应16×16离散像素tile；八主题有独立顶/侧图案与色簇，例如草顶/泥侧、雪顶/石侧、枫红/棕侧，沙/岩/高峰/海床另有tile。用简单方向光和硬像素阴影呈现真实三维，不再使用PBR、法线/粗糙度贴图、写实镜面高光、Fresnel海水、柔云或灰雾。

水面为静态蓝色像素图案，水位0，浅深颜色按实际核心水深离散取值；保护海与域外同深蓝避免显示方形海框。不做写实海洋反光或波法线，像素图案远处退为实心色免摩尔纹。天空为简洁蓝色/夜色，云为真正长方体几何。纹理点采样、顶侧面与遮挡真实；不把整个屏幕降为低分辨率再放大冒充像素。主菜单方块群岛属于表现背景；真实Blank/Earth仍同源core mesh，初始0人物0动物0建筑0机制树。
