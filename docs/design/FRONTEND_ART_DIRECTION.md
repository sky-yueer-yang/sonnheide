# Sonnheide：像素工具界面与深色半透明面板

2026-10-10，当前采用[ADR0021](../decisions/0021-large-world-micro-surfaces-and-worldbox-interface.md)。用户取消此前全部前端限制，并最新指定所有框为深色半透明。WorldBox实际截图用于工具层次、创建流程与像素窗口参考；原创图标、代码、字体来源独立，不复制品牌或贴图。此前卡其、实体金属、固定主题色、按钮边框禁令与主页位置限制均不再作为要求。[本批开发机统一验收已通过](../planning/LARGE_WORLD_MICRO_SURFACE_DELIVERY.md)，历史证据不充当本批结果。

地图占画面主体。底部128dp双层工具栏，上排八个48×44dp类别页签与32dp白色剪影，下排当前类别44×44dp工具槽、32dp彩图标。选中类别与重要操作用砖红、工具彩图标按功能区分，不把全界面染成同一色。工具全名在实际三语tooltip显示，未实现领域明确禁用；短标签不能替代功能语义。必要的状态、后果和错误在窗口内清楚展示，不添加无用副标题。

所有面板、弹窗和底栏用深青蓝半透明填色：面板`#082c3bcc`（80%）、底栏`#062b39c8`（78%）、输入`#0a2836b0`（69%）、tooltip `#092735e8`（91%）。像素切角与明暗外沿也保透明，外沿和内部不重叠，避免中心被重复混合而发黑。文本与图标保持清晰；按钮hover、pressed、focus与selected具有可识别状态，重点操作有足够命中面积。地图框选用可识别的细边和微弱透明暖色覆盖，不压暗选区。

创建窗口有五个可点的实际尺寸预设：512m、1.024km、2.048km、4.096km、8.192km。Blank长宽独立可编辑；Earth按地理纵横比派生高度，尺度显示准确。候选预览、创建和取消沿用真实隔离事务；不能以假的即时反馈冒充完成。底图只因视口或地理范围更新，拖动选框在每frame局部更新真实UI位置，不重建整页，不重采样GSHHG，不吞指针释放或失焦。

全界面使用实际Fusion Pixel字体及完整OFL；正文12dp、标题适量放大，未加载Bold不能伪造加粗。图标为32格代码生成的原创像素图，整数放大96/192px，二值alpha与GPU点采样；配方、全部123个输出和hash登记。用户不再限制只能用四种颜色；当前仍优先清楚白字、蓝红操作与金黄重点。中英德、中文IME、长德语、DPI1/2与最低640×480须实际可用。

主页保留深蓝星空、细星闪烁与偶发渐隐流星，原生GPU绘制，不创建World。世界为真实360°三维像素：2m管理/占地格与独立64²微表面分离，实际地表最小31.25mm，均匀区RLE与稀疏packed微片。soil/sand顶与水面同为0m，湿干由kind及微覆盖决定；水深与海床独立。远景用有实际微覆盖的全域概览，近景限额驻留真实细表面，不把缺少驻留的远岛画成海，不以材质噪声冒充几何。

细地皮为原创色簇和自然稀疏细节，世界空间64px/m取样；小草花粒为纯表现，不伪造机制树、食物或库存。水按实际覆盖互斥绘制、真实水深驱动细像素色纹，不使用写实镜面、Fresnel或PBR。薄云缓慢漂移，风动装饰有界。全部表现时间与仿真RNG独立，隐藏、降低动态和世界暂停冻结，恢复不跳时。

本批验收包含三语实际窗口、创建最大Blank和真实复杂Earth、最细地表/拾取/填海dry-preservation/存载、连续SDL拖动的多次实际UI几何及中间GPU图、源重采样次数为0、360°相机与输入隔离。星空运动与冻结读取实际GPU像素，冻结仅容UNORM通道1/255舍入差。记录当前源码、数据包、GPU和实际预算；文档、NullRenderer、CI均不作为Steam GPU运行证明。
