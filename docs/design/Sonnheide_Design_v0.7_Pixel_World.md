# SONNHEIDE · 三维像素世界完整设计 v0.7

2026-10-08。当前设计，生产重构待实现。原始[v0.6](Sonnheide_Complete_Design_v0.6.md)保留全部27章与源hash；本版逐章裁决旧要求，和此前ADR不一致处以[ADR0012](../decisions/0012-editable-3d-pixel-world.md)为准。本文不把WorldBox的表现机制称为其内部代码实现。

## 1. 游戏现在是什么

只有人类的真正三维像素文明沙盒。玩家能360°观察，亲自放置人物、塑造海陆和山川、编辑文明与观察历史。文明仍通过真实的人、物、钱、知识、产权、任务和空间发展。世界像素化后，文化/语言、国家/宗教、公司/建筑、所有者/保管者仍分别存在，复杂文明设计没有被画风替换掉。

“像素风”具体指方块/硬边体积、精细手绘像素贴图、受控色板、清楚的台阶/立面和简洁光照。所有地形、房屋、角色、树木、车船可从任意水平方向看到体积；人物不是面向镜头的2D纸片，也不是把旧写实画面缩小后放大。可平滑移动/旋转镜头和骨骼，像素是资产风格，不强迫镜头抖动。近看脸、衣服、窗格与材质应有细致像素层次，远看保持建筑剪影、道路、人流和国界可读。

自研C++20核心、场景与通道，沿用独立SDL3/bgfx/RmlUi/FreeType。唯一发行渠道Steam。建筑全部自制；人物本体、服装与正式像素材质也转为原创。可复用有理由、核验固定版本的独立开源库；不复制WorldBox/Minecraft模型、贴图、界面素材或商标。美术质量用正式样本与真实GPU验证，禁止空目录、纯色占位和贴滤镜冒充完成。

## 2. 地形：三维结构与生态分开

|工具|玩家看见/做出的结果|逻辑边界|
|---|---|---|
|Shallow Water / 浅水 / Flachwasser|能看到海床、浅色像素水与明确岸阶|实际水深派生，人物涉水有上限、船舶吃水检查|
|Close Ocean / 近海 / Küstenmeer|中等深度水面、岸到深海的可读过渡|名称是预设；内陆独立水体实际显示“湖”|
|Deep Ocean / 深海 / Tiefsee|深水与更深海床|深度不产生更多矿藏、免费航船或世界外航路|
|Sand / 沙地 / Sand|像素沙层、可形成海滩/沙漠地表|材料与高度分别可改；不是所有沙地都低海拔|
|Soil / 土地 / Boden|可承载植被、农田和建筑的土层|颜色不等于肥力、库存或已种植庄稼|
|Hill / 丘陵 / Hügel|低矮成片阶梯丘陵、有实际高差|刷宽/高度/坡型明确；不能把纹理凹凸当真山|
|Mountain / 山地 / Berg|岩质高山、陡壁、山口|高度影响可达、射界、车道和建址|
|High Peak / 高峰 / Hochgebirge|更高的峰顶及高差|上限有界；雪另由地表覆盖定义，不自动寒冻致死|

以上是八种常用预设，不是八种互斥“物理材料”。权威层分成`heightQ/topMaterial`、水体/深度派生、`biomeId/fertility/moisture/cover`、独立矿物速率与实体占用。道路、农田、城市边界、树木不是地形枚举。高度用确定量化值；渲染、碰撞、拾取、步行、车辆、船与建址必须一致。

首样本以2m地形格、0.5m高度级、64²chunk测试；人物与入口导航采用更细几何净空。每列一个顶面和可见侧面，按chunk稀疏/均匀存储；不分配整个世界的XYZ体素，不支持自然洞穴、地形悬挑、地下漫游。世界profile冻结，内容与修改可变；换格大小必须新建/显式迁移，不在玩到一半拉伸城市。

首版水位固定为0，海床低于0则为湿地表；水深是差值。水格四连通至外海源才为SEA，否则LAKE。填断海峡会使内海成为湖，开通后恢复海；水不会因改名凭空消失。浅/近/深预设都可以造湖，界面按实际连通报告。首版不做高位湖、瀑布、流体体积、侵蚀或潮汐。不同水深表现、净空、船舶吃水必须工作，不能只换三种蓝色。

生态首批采用草地、阔叶林、针叶林、热带林、稀树草原、沙漠、湿地、苔原、雪原、裸岩十类原创组合。森林是地表偏好＋真实树实体，涂森林不立即生成可售木材；植树/清树另有工具。湿地是湿润土层/浅水生态，不能把干地颜色改湿就允许船开过去。肥力影响可用产能上限，不生成粮食。Frozen类表现拆成雪/冻土覆盖，不引入太阳季节系统；Celestial、诅咒、糖果等奇幻地表保留研究比较，本版不自动加入魔法产出、异族或灾变。

## 3. 改地形的工具和操作

底部新增“地形与生态”分区，八种预设在第一组，另有抬高、降低、夷平、平滑、材料涂抹、生态涂抹、植树/植物及分类清理。预设只显示当前必需参数：半径、强度/目标高度、坡型，以及保护/破坏选择。吸取/复制仅高度、面层和生态字段，粘贴仍须完整后果预览，绝不复制人、楼、路、货物、矿物现货或法定关系。可选圆/方笔形；直线、矩形填充是同一稀疏stroke命令，不另造事务引擎。夷平在按下时锁目标高度；平滑读修改前的固定邻域、量化舍入有固定tie-break，结果不随鼠标帧数/LOD/线程顺序变化。

点选状态下左键对象开信息，空地拖动平移；工具状态下左键刷，空格临时平移、中键旋转、显式修饰滚轮缩放，普通滚轮调半径。文字输入/IME优先。底栏正常字号显示当前工具与必要参数，无多余细字；三语tooltip和键盘焦点必须可用。只有一个输入capture owner。Esc取消未提交stroke，失焦取消并释放capture，点窗口绝不穿透改地。

低风险空地stroke松开可直接提交；保护模式把会损坏对象的格明确标成跳过区域，不能静默漏刷；破坏模式显示实际影响范围和紧凑后果卡，再批准一次。无需每笔无意义弹窗。预览引用世界/session、实体与chunk修订、水域依赖、权利/容纳/库存关系、payload和定义hash；相关依赖变更须重预览，保留草稿。

Godterrain是真实的直接干预，可免费造岛或挖海；事件标`DIVINE_EDIT`，不冒充文明劳动。文明填海、平整场地、道路坡道另走有材料与劳动的工程。Godterrain不赠木材、矿石、建材或赔偿金，毁掉工程不全额退料；地形换回去不自动复活、修楼或恢复物资。空无占用且暂停的编辑可在全部依赖版本未变化时撤销；任何已发生人口/经济/施工/运输后果都只能反向新编辑。

## 4. 地变水以后，世界怎样继续

后果由[地形事务合同](../architecture/PIXEL_TERRAIN_TRANSACTIONS.md)统一定义，首个空世界工具也要具备占用后果接口，不能先写“刷格”再给城市补十个修补脚本。

|对象/情况|立即提交的变化|随后真实过程|
|---|---|---|
|人物脚下成浅水/深水或台阶抬升|更新支承与涉水/受困/坠落风险；停止非法移动/作业；记录来源|按能力、实际路径与时间走到安全地/获救；无安全条件可受伤、溺水死亡，不能全局瞬移到岸|
|建筑占地局部受水/塌空/埋入|固定楼板不随刷子升降；校验基础；标损坏/不可用，停新增入住/作业|实际转移住户/物品、修复/重建/拆除；已室内人物保留容纳ID与风险，不因为暂不可见而漏算|
|道路/桥/车道断开|撤销受影响证书，失效运营能力；仍保留路权与旧对象历史|可达部分继续，危险段前停下/改路；无替代是受困，不瞬移货车|
|港口水变陆/变浅/隔断海峡|泊位和吃水重新判定，停止无效航次；船搁浅/被困|现有船、乘客、货权、所属Port登记保留；实际修复航道/卸载/转运|
|城市广场被淹|同一CitySquare逻辑实体与账本保留；物理可用储位/入口失效|在合格地块设有界应急周转区或实际迁址；无地/无货/无路不能假装正常供给|
|树木/庄稼/矿洞受影响|植物按耐受/支承状态死亡或停产；矿洞停工，矿场真实库存另算|沉没木不是仓库木；矿物rate/stock独立保留，水下矿默认不可开采，不刷新库存|
|公司/教会/国家失去场所|法人、信仰、债务、存款、产权不因几何删除|行政迁址、员工失业/再安置、合同延期/损失、法定清算；不按像素格删除整个机构|
|城市陆地被完全挖去|当前可利用陆地面积归零，居民/财政/政治存在按实际状态记录|先应急/流离/迁移/废城；历史、名人、创新、债权与合法身份可追溯|

货物需区分楼内、露天、车船内、在途预约和货币账户。实物有损坏/漂浮/沉没/可回收状态；数量拆分有上限与明确损失分录，不为每粒碎片建实体。封存或沉没货不计可售库存，但保留货主、保管责任与保险/赔偿义务。货币不因仓库淹没自动清零，纸质档案毁坏也不删除别处副本。死亡走同一继承/服役/领导继任事务。不能为画面简便一并抹掉财产、亲属、作者或同名新建对象。

行政领土分法定主张、当前可用干陆、海域使用与实际控制。挖成海不把主权自动送给邻国；新增无主陆不自动建国，已有管辖的Godland按该地法域处理，不免费发产权。首都失效由现有合格城市/政府流程迁址，无可用地时进入流亡/无设施状态；不能生成一座新首都。山脉影响迁徙可达、语言隔离、文化接触、物流和军队射界，但不直接创造语言/文化或给予无来源加成。

## 5. 建房、路网与港口

每栋建筑一次批准完整SitePlan：占地/水平楼板、支承与必要矩形地基、每个人行入口、车库通道、现状前侧送货路线、施工/永久范围、预算材料及退出方案。平地无需额外找平；丘陵/山坡有实际高差时建原创矩形支撑、台阶或坡道，不自动把整山拍平。不可用薄柱跨深水假装陆地建筑；桥与港口设施需专门模板。

步行路线看步高/坡度/净宽，汽车看坡度/转弯半径/净空；“有路”不等于车能开上长阶梯。入口与永久通道保护域写入证书，后建楼仍不得堵旧人行、车道或接货。Godterrain可明确损坏这些证书，普通施工不可借神力权限绕过。地形恢复后重新核验，不免费修复已损建筑。

Port仍是原创正交矩形核心、直线海侧与连续泊位区；取消RECLAIMED-only。支承可来自初始陆地、Godland或已完工工程，必须干燥、稳固、完整；模板规定最低水深、泊位宽度、船体净空、航道与陆侧接广场能力。海港/湖港由实际水域决定，远洋资格需要连外海；外海表现域不产生航路。海岸退化后暂停服务，保留Port登记/船籍、财产和未结合同。

人物只把材料真实送到前侧，材料到齐启动自动工期；不做砌墙角色动画。矩形像素铁丝网逐层围起、期间全包围、完工后反向层层拆掉，约几秒围/拆；施工期间可播预制效果。网不控制投料/工期/死亡/碰撞，不成为城墙。不论画风或高度变化，已完成事实由仿真决定。

## 6. 原创高分辨率像素人物与服装

不再使用MakeHuman/MPFB生产身体、权重、fit、服装或生成器。原创头、躯干、四肢、手脚及少量脸部细节组成可蒙皮硬边体积；身体姿态不是把衣服直接画死在皮肤上。正式角色源、UV、骨架、动作、LOD与fit进入GitHub；已导入MakeHuman仅保留历史许可/完整源锁，不以旧资产转换冒充原创。

高分辨率优先精细贴图、清楚像素簇/颜色和少量几何细节。以人物128texels/m、约64texels头面样本试验，实际正式参数需近中远样本验收。共享图集与材质数组、稳定色板、离线mip、屏幕尺寸迟滞、远景实例化；不为每人复制4K纹理，不把贴图一个像素都建成立方体。360°背面/侧面和服装遮挡必须完成，不能只画正面好看。

人口只来自玩家18岁放置或合法繁衍0岁；全龄相同成人身体尺寸/骨架/碰撞/fit，不做儿童缩放。年龄仍决定学习、成年资格、服役、生育、衰老与死亡。编辑体态外观不改年龄、父母或法定身份。玩家放置不自动赠国籍、语言、宗教、军队或已生产衣物；最低遮盖可作非商品表现底层，不可出售/磨损/记产量。

服装业开局即有家庭/公共制衣，初期内裤、女性胸罩，文明早期T恤/短裤，成熟阶段逐步解锁外套、长裤、裙装、鞋帽和正装款式。需求先衣物基本覆盖/替换，再允许规范正装，再自由审美消费，保留粮食/住房预算。衣物必须有库存、支付、运输、真实穿着、耐久、有限修补与替换，衣服丢失/沉没后需求重新出现；不保证每家制衣企业永久盈利。

上古T恤主题色/白短裤规则保留，后期自由款式和配色不全部强制国色。军装各国同款原创，颜色绑定实际服役国，和国籍分开。雇主可以要求正装优先采购，但缺正装仍可上班、正常领薪/保岗位；不暗扣钱或免费换装。身上的服装和家里储存的衣物在地形灾损中分别处理。详见[像素资产](../architecture/PIXEL_RENDERING_AND_ASSETS.md)及[衣物经济](../architecture/CLOTHING_ECONOMY.md)。

## 7. 两条创建世界路径

“新建世界”先以两个清楚无框选项选择**空白地图**或**真实世界选区**。不要求新玩家先下载/选择全球包。空白可选全海或全平陆内域，后者仍生成预览可见的不规则边缘到纯海外圈；可以选择尺寸、名称和seed，0人0建筑，不随机生成文明。可复用的地图模板/程序化岛屿以后以独立可选草稿扩展，不挤占这两条必要路径。

真实选区复用固定GSHHG海陆包、岛/湖嵌套、投影、日期线处理和一致水平scale。在世界地图平移缩放/框选，然后给最终像素地图预览，量化会损失的狭岛/窄海峡明确显示差异，不用卫星图片或矢量光滑边冒充游戏输出。仅有海陆来源，默认陆台及按距离派生的浅/近/深水；丘陵山地可选“风格化生成”或由玩家画，均明确不是真实山脉/海拔，不重新默默采购DEM。初始来源核心和边缘自然化保真承诺限量化前/初始导入；玩家后续可自由改变有效地形。

两个入口产生同一种TerrainWorldDraft与PreviewDescriptor，最高预览与游戏共用量化格/高度、mesh、材质/seed、像素水和天空。预览可360°看并调镜头；创建前不能提前刷出生产World的事务。确认→隔离候选→规则/预算/来源校验→资源就绪→首存档写入并读回→发布活动World。取消、坏包、超预算、首存档失败和晚异步结果都保旧世界/继续指针；WorldId/SessionGeneration/DraftGeneration隔离。

可玩域外保留连续表现海、天空和视距效果，没有矩形围墙、海面尽头或现实外部人口。预算内权威海缓冲支持船运，最外保护海带防止实体陆地刷到硬截边；刷到此处显示当前可编辑范围/拒绝原因，不把点击clamp回可玩格，不假称无限世界。尺寸/格数/预计内存按需摘要，不添无必要小字。

## 8. WorldBox式直观前端，Sonnheide式文明

所有全局工具集中底栏八分区：观察、地形与生态、人物、文明制度、建设资源、经济物品、世界、设置。打开对象窗仍看见地图；目录/search按需，局部窗口只放对象动作/关系/编辑/关闭。主菜单保持已批准油画、SonnreichLogo静态光环、右下纯文字和无边框，游戏画风变更不擅改已认可主页。游戏内图标原创像素化且只用于清楚辨识，信息文字使用清晰常规字体；中文无需糟糕的点阵字来证明像素风。英文/简体中文/德文全部状态、错误和后果共key，UI语言不改仿真Language。

世界统计、跨对象同口径比较、World Laws、人物/物品/地图收藏、标记、历史及分类清理保留。近景点人→人物→国籍→国家→城市/法律；远景点激活区域→同对象页；地图格→地形/水体/地权/影响对象，一样使用稳定typed引用。新增TerrainCellRef与WaterBodyRef有明确世界/版本，split/merge水体旧引用通过变更历史跳到存续对象，不能把component临时编号当永久ID。
