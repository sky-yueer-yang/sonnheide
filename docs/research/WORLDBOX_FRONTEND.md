# WorldBox前端参考与Sonnheide迁移决策

核验日期2026-10-06。范围是信息组织、工具入口与操作链，不复用商业游戏代码、图标或截图作为游戏资产。本文件区分官方可核验功能与我们为本项目制定的布局。

## 证据与可迁移原则

主要证据为[官方更新日志](https://www.superworldbox.com/changelog)：底部power bar及tabs、滚动/缩放、提示和快捷键；元对象区域点选、窗口关联、收藏和浏览回退；统计入口与窗口更新；名称历史、属性编辑与世界规则。官网/Steam宣传资料较旧，不能凭旧图断言当前所有按钮的具体坐标。[开发者Steam展示页](https://store.steampowered.com/app/1206560/WorldBox__God_Simulator/)。

本轮实际查看了Steam页面公开DOM图片来源和官方地图宣传图：地图占主视觉，名称叠在世界空间；该图未显示工具栏，只作地图构图参考。底栏与最新元对象交互的依据是明确官方更新条目，而不是假称已经运行WorldBox所有商业版本。原始图片未下载入项目或作为原创资源使用。

## 结构对照与需要真正改的部分

|交互层|Sonnheide原型的问题|本轮采用的结构|生产依赖/验证|
|---|---|---|---|
|地图舞台|目录、卡片和按钮挤成管理网页|地图中心；HUD紧凑；目录按需打开|窗口viewport/DPI与真实拾取|
|工具定位|顶部全局按钮和地图工具分散|全局按钮全部底部；section→工具行|InputRouter捕获优先；不重复全局入口|
|工具分区|40实体类型像常驻菜单|7个领域section；实体目录为检索窗|工具ID/消息key/权限/模式注册表|
|当前工具|持续放置和瞬时按钮语义混合|持续工具醒目；换section回点选|不把打开窗口当世界命令|
|近/远点选|只有人物和一个国家示例|近人/建筑，远景按国家/其他激活图层|法定主权/实际控制/文化图层独立|
|标题与详情|人物事实堆满首屏|关键事实先显示，六页签下钻|只读快照/分页，不伪造未接入数据|
|关系导航|缺少实际关闭与焦点返回|同一对象窗关联跳转/回退/关闭|typed引用不以名字或显示索引寻址|
|对象列表|目录占地图，搜索没有统一归属|类型/关系口径筛选，收藏/档案同resolver|成员索引、稳定分页、死亡墓碑|
|编辑|大部分只读或只有名称|六轴、宗教地位/官方宗教、法条草案|明确预览、批准、陈旧拒绝、事件|
|危险动作|清理与观察很近，易误点|专用分类窗→依赖预览→明确执行范围|住户/库存/永久通行/人物档案保护|
|收藏与标记|与领域记录容易混成一层|观察资料单独保存，实物收藏指向真实记录|不改revision/RNG/经济资产|
|统计比较|所有类型直接相加容易误导|同口径/单位/时点；未知显示未接入|人群重叠/货主与保管/在途去重|
|提示与快捷键|缺乏一致退出/操作提示|当前工具提示、真实快捷键、焦点环|输入法/文本框不触发地图快捷键|
|三语|静态中文和代码内字面量耦合|稳定message key；en/zh/de完整同key|locale纯视图，字体/IME/长文本|
|窄屏|地图坐标受留白影响，页面纵向过长|固定底栏，工具横滚，对象抽屉独立滚动|320宽、短高度、德国长词、SVG逆变换|
|时间与保存|按钮很容易暗示并未运行的模拟|只显示实际运行时间；保存分领域与视图|正式World/回执/草稿跨保存协议|
|建筑与美术|基础体验与内容制作先后不明确|先主菜单/创建/初始地表/基础界面，验收后开始建筑与人物服装|基础体验门槛、艺术作者源、入口/地基/LOD、许可与pack；顺序按ADR 0007|

## 本项目的section，不照搬游戏机制

`observe / people / civilization / construction / economy / world / settings`是我们按文明、建设、实物经济与世界管理设计的七组，详见[UI_ARCHITECTURE](https://github.com/sky-yueer-yang/sonnheide/blob/b13f01890053bd58609af3366883c93ebef18e22/docs/architecture/UI_ARCHITECTURE.md)。每个工具有模式、对象目标和可用能力；未接入者显示具体依赖，禁止假提交。对象页可继续包含局部编辑/跳转按钮，用户不会为关闭人物窗去切工具栏分类。

不会迁移WorldBox的刷天然地形、幻想种族、灾害、现代爆炸武器或城防；原始人口来源、冻结真实海陆/岸线与派生岸坡、实物衣服、港口与原创建筑是本项目规则。地表按[ADR 0010](https://github.com/sky-yueer-yang/sonnheide/blob/b13f01890053bd58609af3366883c93ebef18e22/docs/decisions/0010-flat-land-and-coastal-transition.md)取消真实高程和内陆找平基；参考交互不能顺便改写这些因果不变量。施工与艺术的具体前置任务和贯穿门槛见[施工计划](../planning/IMPLEMENTATION_PLAN.md)。
