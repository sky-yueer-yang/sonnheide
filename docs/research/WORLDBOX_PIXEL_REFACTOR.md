## 2. 必须拆开的六种事实

|事实|Sonnheide权威含义|不会被它暗中改变的事实|
|---|---|---|
|地形高度|每列一个量化顶面，含真实立面；与水位共同决定干湿、深度和可支承空间|表层材质、人物身份、商品库存|
|表层材料|沙、土、岩石等面层；可仅换材质而保留高度|Biome、自动产出、免费施工材料|
|水域关系|低于首版静水位0的列为湿格；四连通到外海源为SEA，其余为LAKE|贴图叫什么、水波视觉、当前摄像机|
|Surface主题/生态|地皮主题、有界生态参数和装饰偏好；功能树为独立实体，依实际地面运行|不另造一层可站立“森林地面”，不抬高地面，不让地皮或装饰花草产仓库货|
|温度|未来若启用，须有独立单位、来源、时钟和生命影响合同；当前不作为地形工具首版承诺|不把生态刷当温度刷，不把Darkness当寒冷，不偷引结冰/灾害|
|矿物率|独立的有界产出率/容量字段；调高率不立即授予矿物库存|不因为把岩石刷成山便免费造矿，不靠像素材质认定矿权|

WorldBox外观可让这些操作靠近，Sonnheide的数据和命令仍须分开。否则“刷沙只改外观”会误排干湖，“复制一块地”会复制房屋人口，“改生态”会白送商品，这些都不是直观操作所必需的代价。

## 3. 首版地形工具完整登记

全部全局入口位于底部分区栏；地形与生态集中一分区，展开后才出现工具组与笔刷参数。默认一次只选一个活动工具；选择工具不会立即改世界。拖动预览→结束笔画→单写者重验→提交/拒绝→同一回执，右键/取消只取消未提交草案。每个工具都有英/汉/德名称、作用预览、越界/预算/陈旧原因，不要求玩家理解chunk或事务。

下表的八种预设为当前设计，参见ADR0012；英文标签是我们采用的面向玩家词汇。高度数值、宽度和阶梯坡型由版本化profile规定，在阶段0样本准入后锁定，不凭工具名字声称真实测量海拔。

|预设|组合意图|必须避免的误解|
|---|---|---|
|Shallow Water / 浅水|设置浅负高度及合适海床面层|内陆隔离水域仍是湖；名称不保证船舶可通行|
|Close Ocean / 近岸水|设置中等负高度，形成可读的近岸水深档|不会自动连接海洋或授予港口资格|
|Deep Ocean / 深水|设置更深负高度|封闭内陆深水仍是LAKE；深度由实际高差派生|
|Sand / 沙地|默认仅换沙质面层，保高度；另选“造沙地”预设才同时设干地高度|水下刷沙不自动填海，沙子不成为仓库商品|
|Soil / 土地|默认仅换土质面层，保高度；造陆模式明确显示高度变化|森林不是另一套土台，植树不免费给木材|
|Hill / 丘陵|有宽度的低丘与量化坡面|不以一根细柱冒充丘陵，也不保证人车自动能爬|
|Mountain / 山地|中高山体、岩石与阶梯过渡|画面能看见不代表全坡可走，不能穿过天然立面|
|High Peak / 高峰|有底宽和高点的山体，受世界高度/单笔预算限制|不加入冰雪气候、漂浮岛或洞穴，不以越界clamp造假|

|独立工具组|完整首版功能|采纳/限制|
|---|---|---|
|形变|抬高、降低、按选定标高夷平、确定性平滑；圆/方笔刷、半径/强度/阶梯坡型|各操作改变同一量化高度；夷平不自动代办付费地基，平滑不抹去材质/所有权|
|采样与复制|吸取高度/面层/主题参数；复制/粘贴限定地表字段模板|不复制人、楼、路、真树/附着果、账户库存、矿物现货或法定关系；边界/许可/预算重验|
|地表主题与植物|当前八主题+沙地选择、纯装饰小植物表现/清理、功能树种植/信息/任务；完整登记见下节|地皮保高度，装饰不产货不参与农业；功能树渐长/木材/熟果走独立实体与单写者。旧十自然或十四建议不再是首批菜单|
|资源|矿物率查看/绘制/清理；有界稀疏字段|一次笔画不赠现货，原有reservations不被偷删；按原矿率合同，不新加随机资源箱|

|撤销|取消草案；满足合同的有限撤销/重做|有死亡、消耗、交易、损坏结算或后续事件时不允许无条件回拨整个世界|

**首版不加入：** 漩涡式随机地面交换、无界体积岩浆/随机喷发、温度灾害笔刷、酸雨/地震/核爆/陨石/瘟疫、洞穴/高位湖/瀑布/体积流体、全世界稠密体素。炎地的火山/熔岩按ADR0013独立准入，不能借主题默默加灾害或树种。范围外按钮不制造假成功入口；其理由分别是破坏确定性、缺少生命/财产因果合同或既定产品边界，不是因为WorldBox存在便必须加入。

## 4. 用户确定的主题与三层结构

本表是用户最新决定，按[ADR0013](../decisions/0013-layered-surfaces-and-fruiting-trees.md)生效，**不是WorldBox名单的复制，也不声称已经运行**。八种地形几何预设继续存在；这里是另一组八个地表主题加沙地。此前十自然生态和十四扩展建议不作为当前首批，不擅自加主题或未指定植物。

|主题|用户指定的功能树|纯装饰/表现与边界|
|---|---|---|
|雪原|松树|雪色地皮；不自动结冰、改水位或加入寒冷死亡|
|花甸|多类果树|热带花为纯装饰；树渐长，果实逐渐成熟后才有可采量|
|枫原|枫树|暖土/落叶地被与有界低草只装饰，不能作农业产出|
|樱野|樱花树|落瓣为有界纯表现，不成为货物、果实或农业产出|
|湿地|菩提树|芦苇为纯装饰；主题颜色不改变干湿/船舶通行|
|荒原（Savanna参考）|胡杨|枯草为纯装饰，不复制WorldBox资源掉落或性状加成|
|Sonnheide圣原|发光树|圣光是主题表现，不产生宗教身份、魔法产出或免费能源|
|炎地|首版无树，用户尚未指定树种|火山岩/暗红裂隙及有界静态熔岩只表现，无小植物、流体、灼伤/焚楼或随机喷发，不擅配炎地树|
|沙地|椰子树|没有小植物；沙地地皮与功能椰子树分开|

**地皮层**决定主题/配色/纹理，和高度水陆分开；**纯装饰层**按持久seed/密度/清除mask复建，花/草/芦苇/落瓣有界，不采收、不扣库存、不做碰撞导航；**功能树层**保存稳定Tree引用、种类、生长、木材和成熟果实等真实状态，采伐采果须有人、时间、路径、容量及实物事务。农田和既有作物生产独立保留，不因为小植物纯装饰而删掉农业，也不把农作物归入装饰清理。

自然恢复开关仅控制新的野生萌发；关闭后已有树继续正常生长和已定义的果实成熟。手动种树与野生萌发分开授权，刷主题不立即生成成熟树/熟果/木材。树上果实逐渐成熟，采摘消耗真实可采量，视觉果子不能反向造库存。重复涂主题、重载、LOD切换不恢复已采果实、不重置树龄。

沙地是材质habitat，不是第九个soil主题；干沙优先使用无小植物/椰子新树池，水下沙仍为WATER不能新长陆生椰树。沙覆盖不抹掉原主题出处，既有树不免费变种。裸土/裸岩中性态不另造必选主题。花甸首样苹果/梨/桃/橙/芒果/石榴及沙地椰子是合同里的有界候选，不是已经量产或平衡完成；樱花树、松树等未定义可食果，不随花瓣变成水果。

阶段0锁三层、树果与预算合同；阶段1先地皮及纯装饰预览；阶段2先单写者占用与成熟/采收失败fixture；阶段3基础通过后尽早制作原创树果花、落瓣圣光熔岩代表件；阶段4真实采伐/采果消耗回种；阶段5完整公共经济与农业。基础阶段不提前制作功能树正式模型来掩盖创建/地表/存载未完成。

## 6. 真三维必须解决的非平凡差异

### 6.1 两个创建入口，一份量化结果

Blank是在明确尺寸/预算的有限可玩域里选择全海或平陆内域（明确外海保护带），Earth是从固定GSHHG海陆/岸线包选择并投影区域，转换为同一离散列与面层。Earth当前**没有真实DEM海拔或真实水深**；初始岸线来自地理源，高度/海床来自明示的像素化规则。来源证据不可变，之后玩家可改的是有效地表。未经许可/hash/完整覆盖的数据包不可列为可创建；历史25×25 ETOPO窗口不是全球地图。

二者共享 `参数准入→量化候选→水域拓扑→最高精度预览→最小首checkpoint写入/读回→原子发布`。预览不会提前创建生产WorldId、人口或机构；确认时复核DraftGeneration/来源版本。当前World与好存档直到候选可发布才替换，continue指针最后更新。普通chunk边不闭合成岸；有限可玩外沿及外海源明确显示，玩家不能刷改域外渲染海。

同一cell/profile/hash必须用于预览、三维顶面/立面、水深、CPU拾取、导航与存档。2m格、0.5m高量化、64×64格chunk只是待实验准入的起始profile。地表格≠脚步净空≠贴图texel；不能为画清人物脸把整片世界变成稠密细体素。

### 6.2 地形神力与文明施工是两条可解释入口

Godterrain不耗施工材料，但必须处置真实后果，不产商品、人口、矿物现货或退款。文明填海仍逐格四邻接、支付材料劳动、完成才改变有效支承；地基是已批准的实体工程，不靠刷地绕过造楼材料。Port改为检查实际支承/干湿/水深/正交连续泊位/净空与陆水路线，来源为GOD或ENGINEERED不自动授予或否决运营资格。

普通建房和分类清理继续保护既有合法接入。明确的破坏地形神力可以使原通路失效，却必须在同一次权威提交中撤销证书/运营、处置路楼任务与人口货物；异步mesh或寻路完成顺序不决定死亡或财产。保护模式显式跳过危险目标；破坏模式仅当存在具体损失时提供一次紧凑后果批准。没有安全路线/空间/容量时不能无偿瞬移居民、把落水者藏在旧位置或清空库存。

这些问题在空世界阶段就通过 `OccupiedTerrainAdapter` 与真实结构fixture证明强异常保证、库存位置和人物档案边界，随后接实际居民城。不能把“先地表后建筑”误解成“建筑完成后才补地形编辑因果”。

### 6.3 高分辨率像素人物与世界LOD

人物、衣物和建筑采用原创块状三维几何及精细像素贴图，360°旋转、透视、遮挡、背面、骨架动作都真实存在；不能用面向镜头的平面角色或全屏像素滤镜冒充。Minecraft只说明块状审美方向，不复制其模型、贴图、skin布局或品牌内容。MakeHuman/MPFB不进入新生产人体管线，其历史资源/许可记录保留。

人物同一成人骨架、fit和全龄尺寸；年龄影响生命周期资格，不产生儿童模型。服装依然是有限实物、层序/遮挡、穿耗/修补/替换、公共供给与购买需求；高分辨率外观不等于无限衣柜。原创建筑、原创军装和交通按功能合同分批制作，国家主题色/服役国色绑定真实身份字段。

旧Poly Haven/PBR/Hex/8K天空的可分发源、Release及验收历史全部保存；新像素地表/天空/水面独立预算和准入，不以下载过大资源为由删除发布历史。原创像素水的静水位、深度、岸界、透明拾取、明暗和GPU预算必须通过。固定Abyssal代码保留为可选数学参考/迁移；复用时只称其实际验过的范围，完整写实FFT/泡沫/折射不是基础体验或Steam发行门槛。像素水的原创表现不冒称已经移植Abyssal。

## 7. 验收与未核验项

必须分别记录：官方参考事实、我们采纳的设计、有限CPU fixture、原生GPU交互、实际城市贯穿和发行设备证据。当前研究及新版计划不实现像素渲染、Godterrain、主题/树果运行或存档迁移。

优先证据为：两来源同候选hash；360°地表立面/水深/拾取一致；海峡与远港同步失效；坡地楼基和邻楼接入；有人的保护/破坏/取消/预算失败；存载同revision与因果；人物/衣物预算；三层分别清理、农田生产不被主题或装饰清理偷改；恢复关闭后已有树继续生长；成熟/采果/伐木/回种与中途存载不复制木果。官方现行全按钮、所有Biome和内部高度/温度单位仍未完整核实，不由社区推测或本项目枚举填补。
