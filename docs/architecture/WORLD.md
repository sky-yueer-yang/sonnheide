# 世界、地球数据与动态空间

本文件规定待实施的生产世界管线，地表按 [ADR 0010](../decisions/0010-flat-land-and-coastal-transition.md)：保留真实全球海陆与岸线，内陆统一平坦，只有海岸窄带缓慢下降入水；不再导入真实高程。现有 `FrozenWorld` 仅使用合成LAND/WATER格作为事务与连通oracle；不包含真实地球转换器或新的海岸表面。地图权威事实与视觉/导航缓存必须分清。本轮只更新合同，不执行全球包导入或创建世界。

## 1. 数据源到离线全球包

固定GSHHG2.3.7源，保存官方原包、SHA-256、LGPL原文、源版本与转换配方。原稿需要全球闭合岸线及正确岛/湖嵌套层级，不能仅保留L1并把湖全填陆；不能注入现实国界、地名、道路、人口或文化。具体开放许可与托管见 [资产来源](../research/ASSET_SOURCES.md)。

预处理：原格式解码→坐标/环方向校验→跨日期变更线拆分→层级与孔洞保留→瓦片裁切（带共享边与halo）→多个独立视觉LOD→空间索引→压缩包。简化必须保护拓扑与瓦片边接缝；小岛/狭窄海峡丢失作为质量报告，不静默用粗LOD决定世界事实。

`EarthLandWater.pack` 包头包含magic、schema、字节序、数据版本、源哈希、配方哈希、目录offset/length、LOD列表和每块checksum。块目录含经纬包围框、几何级别、嵌套父子关系、原始环ID和压缩方式。初版每块独立压缩、按范围读取，不运行时解压全地球。世界创建不依赖网络；全球预览只读视窗所需LOD。

## 2. 世界创建与冻结

`CreateEarthWorld` 在可信调度器中验证WGS84选择框、投影可定义、唯一worldScale、逻辑格预算、所需源块齐全。GPU预览不作为最终生成器。创建完成后保存EarthMapSelection、GeoSourceManifest、投影参数、cellSize、worldScale、栅格算法版本、最终天然mask与hash。

采用局部方位等距投影（AEQD），中心距离/方位的保证不等于整个选区无形变。[PROJ官方AEQD定义](https://proj.org/en/stable/operations/projections/aeqd.html)。经纬坐标不是米；先投影再等比例缩放到目标游戏长边，X/Z不可分别拉伸。投影中心、椭球/球模型和库版本必须冻结。接近对跖奇点的选区拒绝；大选区显示距离/面积形变估计，临时警示门槛例如5%需实测，不暗中换投影或收窄选区。

跨180°选择采用中心经度展开及两个源查询窗，不能把170°E到170°W误算成340°宽。极区用投影多边形包围框，不能直接按经纬宽高比建世界。边界裁切、闭环、孔洞、岛国、湖中岛、选区仅水、仅陆、相同选区不同scale都是离线fixtures。

## 3. 矢量岸线和逻辑格的缝隙

天然水陆仍为独立LAND/WATER掩码，权威mask按格心分类，并同时生成只读 `CoastCoverageIndex` 保留天然岸线相交信息。按ADR 0010取消真实高程场、DEM/DTM创建依赖、垂直datum转换和山地坡度；相对静水面的统一内陆平台与窄岸带是确定性的游戏几何。天然岸线、水陆来源和冻结参数决定海岸表面，表面Y坐标的正负、浅水可见性或海浪波峰不能反推LAND/WATER。最终建筑、可选沿海地基和接入通道须检查完整几何支持，不能把“格心是LAND”当整栋建筑不悬海的证明。

初步决定：天然地面建筑的主体/基础 footprint 必须完全位于天然陆地轮廓或已完成人工陆地的联合地面内；边界epsilon统一成地图精度参数，覆盖率仅作快速预检，不用“99%陆地”放行剩余1%悬海。临海行走/水路在相交格使用带clearance的局部裁切多边形/子格导航；它是派生索引，不改天然mask。首个真实地理实验必须证明人/船不会走到视觉错误的一侧。

这一决定需要A2的精确几何验证后冻结算法版本：对各LOD一致、格心落边界有确定tie-break、裁切不裂缝、不同世界scale产生明确的分辨率变化而非岸线编辑。资料虽保留真实岸线，粗逻辑格仍可能损失小海峡，创建界面必须显示分辨率/通航损失报告。

## 4. 格网与Chunk

每格最小权威数据：`naturalSurface`只读、`reclaimed`稀疏、建筑/道路占用、领土引用、矿物速率。世界定义保存冻结海陆/岸线哈希、统一平台相对高度、窄岸带参数、岸线距离/表面生成算法版本与精度；只在需要的岸带缓存确定性表面，不再保存全球真实高度网格。建筑保存固定楼板标高、可选沿海地基、入口和接入保护域，普通内陆建址无独立找平地基，详见[地形与建址](TERRAIN_AND_SITES.md)。effectiveSurface和landOrigin可重建。首轮Chunk为64×64格；天然mask bit-pack、造陆sparse页、矿种仅分配有值页；热移动用空间桶/道路段。Chunk大小与物理格大小不同。

`NaturalLandWaterMask` hash在任何命令、存档往返与人工造陆后不变。矿物编辑只改速率场，不给库存立刻补矿。BridgeSegment属于跨水道路基础设施，其桥面/净空可阻挡船，但不改天然水陆和造陆层。

## 5. 造陆事务

规划逐格拆解；每格必须天然WATER、未完成/未冲突、四邻接天然LAND或已完成人工LAND。规划/预约不能支撑下一格。材料从实名CitySquare库存预约，施工合同占用真实劳动。生产完整状态为PLANNED→RESERVED→UNDER_CONSTRUCTION→COMPLETE；取消结算已发生投入并释放未发生部分。

完工同一事务：扣已完成投入→更新ReclaimedLandMask→关闭任务→发布历史/版本→导航和渲染dirty。未完成仍是WATER，工地占用可能阻航；船在进入受影响段之前二次验证，不能因为异步索引未重建而穿过施工。完工造陆首版不还原为海。人工陆地的工程表面与边缘另有冻结定义，不能重算天然岸带来移动已建天然地面、建筑或旧接入；海陆状态变更不等于全海岸地形自动重建。

当前内核从RESERVED开始，只有一种通用材料，5单位劳动由测试Scheduler注入，材料到完工一次性消耗，取消返还全部尚未消耗材料、已花劳动不退款。它没有真实人员/运输/部分材料投入，不可冒充生产施工完整流程。

## 6. 港区与保护区域

PortCore每格完成且来源RECLAIMED；0/90/180/270；同一离散变换同时旋转core、海侧边、BerthWaterZone、陆侧入口。水区是水，不能用悬水QuayPlatform替代造陆。主体、装卸区、屋檐/碰撞不得侵入泊位。

本内核旋转角按地图顺时针，90°使EAST(+X)转SOUTH(+Z)；右手+Y数学yaw取负角。模型中心pivot与整数锚点转换由同一放置适配器实现。

空间合法性之外仍需科技、城市/产权/法域、预算、施工、船clearance、陆侧道路连接广场、航道等级。`KernelPlacePort`只检查其中几何、直接背侧道路和水域连接；它没有生产`PlacePort`的全套授权/经济验证。

现有港口强制泊位区进入禁止造陆/放建筑的空间约束；若要改建先依法停用/清航次。远处填海封闭海峡仍可能让港口失去远洋连接，此时暂停相关服务并显示瓶颈，不必删除港口、船或货物。

## 7. 水域拓扑的正确性与性能

填海/施工删除water节点时，原组件可能在任意远处分裂。生产需局部Chunk重建边界门户/clearance，然后更新全局粗门户图及受影响组件；不能只改某格的海洋标记。具体算法详见 [仿真导航章节](SIMULATION.md)。

路径证书携带effectiveSurfaceEpoch、障碍/Chunk版本、粗图版本、船clearance与权限版本。查询三态：ReadyPath / ReadyNoPath / Pending。dirty区域不返回有效旧路径；沿未dirty部分可继续，在段入口暂停/重验。后台结果附输入generation，版本过期丢弃；禁止结果到达顺序修改权威事实。

内核同步全图flood-fill为correctness oracle：对小图随机逐格施工/取消，与生产分块连通比较；重点海峡删除、海峡恢复施工取消、湖/海区别、边界连通、港口四旋转与多个泊位冲突。规模证明必须在真实选择区域和密集港区上测，不用空水图掩盖坏情况。

## 8. 矿物曲面

数据为非负有限速率，capacity=rate×1day，库存按上次积分时间lazy更新并封顶。增rate不立即增存量；夷平stroke保存首次锚值。矿物显示高度相对统一平台/冻结岸带表面，编辑raycast命中权威表面，不命中特效曲面；同一世界点落同一格，任意相机旋转不改变stroke落格。资源曲面的“夷平”只编辑矿物速率，不改变地表。撤销只针对未提交预览/允许的矿物编辑，不撤销已消耗的真实矿石。

## 9. 统一平台、窄岸带与可选沿海地基

全球生产输入仅为经过许可、版本和哈希核验的海陆/岸线包；NOAA ETOPO样本、原始TIFF窗口和解码工具保留为历史研究证据，不再是创建器的必需数据，也不继续扩展全球DEM/DTM。海陆资料不能携带现代建筑、道路、国家或人口。

静水面为固定相对基准；普通内陆采用统一的略高平台，平台高度与岸带宽度为游戏米参数，不从现实海拔导出。窄岸带按完整岸线的有符号距离平滑降低到岸线水面，水侧可继续生成水下浅滩，但始终保持WATER；细岛可能全部处于岸带而没有平台区，不准因此抹掉小岛。边块halo必须覆盖岸带宽度，选区边界本身不是海岸，具体算法/精度随生成配方冻结。

建筑完整footprint位于已支持陆地上。普通内陆楼板直接绑定统一平台，不生成找平地基实体或额外地基配方；只有footprint涉及下降岸带并需要水平承托时，才允许原创长方体地基和必要的局部接入构件。不得用该地基盖过天然WATER或未完工填海。完整SitePlan仍联合批准人行入口、车库通道、前侧现状接货路线与施工罩范围，保留旧接入，不因陆地平坦而省略道路净宽、转弯、净空、权利与材料的验证。

当前旧高程 `TerrainGrid`/SiteRegistry oracle 已从kernel链接图隔离为test-only `sonnheide_legacy_slope_oracle`，仍只验证历史四向直线坡道与保守预约；它不是新地表的运行时实现，也未接入现有world/填海/存档。新平台/岸带算法、可选沿海地基、真实全球海陆包与创建器均待实施，不能将文档更新称为已生成地图。

## ADR 0005：分类清理和远近地图入口

地图近景对象与远景政治区域输出相同typed EntityRef，不通过颜色/当前位置猜国籍。清理工具分树木、植物、矿物层、建筑、道路、生命，逐目标给合法预览；天然水陆/岸线、统一平台/岸带参数、worldScale以及已完成造陆不进入擦除mask。矿物清理只改变资源层，矿场/库存/在途矿石分别结算。已有接入证书引用的道路不能在无替代通道时删除；有人/货建筑须完成同一事务的安置/移交方案，否则保留并解释。生命神力清除记录死亡来源、继承/机构代管与任务停止，不删除稳定身份、亲属、作者和历史引用。详情见[INTERACTION](INTERACTION.md)。
