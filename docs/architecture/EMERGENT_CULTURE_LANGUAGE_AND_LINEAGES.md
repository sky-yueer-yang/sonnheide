# 文化创生、语言分化与自然亚种：稀疏证据上的涌现

2026-10-09，v0.9 / ADR0018。设计待实现。机器定义为 [emergence_algorithms_v1.json](../../data/contracts/emergence_algorithms_v1.json)；它完整接续旧来源的 Genesis 场和语言谱系设想，覆盖旧源中尚未定义的 `mu/kappa/sigmaEff`、候选分合与长期条件。旧 v0.6 不改字，不作为本算法的隐式补充代码。这里只有游戏模型，未声称复现真实语言学、民族起源或生物分类。

## 1. 三种涌现的共同边界与不同因果

文化是**共同实践得到承认**；语言分支是**同一批含义被持续用不同形式传授**；亚种是**同物种遗传群形成持续繁育联系**。政治边界、颜色、国籍、名字、图标和单纯等待不能替它们生成对象。三者分别有自己的来源、证据、候选、迟滞和一次结算，不共用一根“文明进度条”。

共同基础只是一张有限的真实事件接触图。每个 Actor 最多保存12个显著伙伴；每条边保存90日的双方合作日位集、8个共同实践分量、最多16个来源回执和真实接触时间。合作、共同照护、已完成教学、共同应急/防御、实际议事、语义传授可以形成边；单纯站得近、命令未完成、God强制改籍、换颜色、复制地图、基因编辑不能。

回执键是 `(rootEffectId,orderedActorPair,category,calendarDay)`；同一真实根效应跨经济/政治/宗教转述不再算一次。重复命令/读档不增加合作。伙伴满时以互惠日数、实际接触日数、最后接触时间排序保留，平手按Ref；被舍弃的旧汇总只能留历史，不重新拿来生成创生证据。全域保留稀疏索引，不建立 Person×Culture 或 Person×Language 的矩阵。

整数 Q=10000；日=12000 SimTick，运动秒=20tick。正数除法向下，积分余数保存；负场值除法明确向零截断。随机按领域、节点、dayIndex、保存counter派生，采用拒绝采样获得无偏有界整数；预览/镜头/线程/查询不消耗流。固定日递推可以分片，但跳过平静日时仍要积分同一串日状态，不把60天改成一次不同的噪声。

## 2. 文化核先来自互惠，再可能发生相变

8个实践维度为共同饮食、照护义务、劳动交换、资源分享、冲突解决、集体仪式、教学实践、符号意义情境。每项来自实际履行与本人接受；未知不填0。至少实际观察过3项才可比较。

对一对主体：

```text
reciprocalQ = min(10000,1000 × min(A帮助B的不同日数,B帮助A的不同日数))
practiceAgreementQ = 10000 − sum(abs(A实践Q[k]−B实践Q[k])) / 实际共同已知项数
```

一个人长期单向命令、另一个人被迫全盘服从，不能仅凭任务数形成强互惠核。边需90日内至少4个不同接触日和互惠Q≥3000。实际求助/被帮助都可以使双方承担不同的合作，不要求每人拥有相同职业或财产。

每聚落最多一个Primary节点、四个Secondary候选。确定性只扫描合格人类子图的连通分量；至少6名实际参与的人类、至少一名愿意且成年的人类创始候选、至少两类事件、三项已知实践才建核。动物可以参与现有共同体，但不填人类创生核人数，不能作为两群互不交流人类之间唯一的创生桥。Primary核所有参与者都无既有文化和正式语言；Secondary核以实际已有文化/语言的人类组成。单有6个人站在一起永远不够。

节点 roster 首样128名显著参与者，大群体的其余成员保存在真实分量索引中；不能把128人当合法共同体人口上限或省掉最终身份验证。节点分合按成员交集/较大成员集≥6000Q匹配既有节点，平手最早节点再Ref；一份创生回执不能因分拆再生成。失去条件进入休眠而非删掉已有文化。

场从实际核统计而来：

```text
coherenceQ = 合格核边实践一致度的平均
reciprocityQ = 合格核边互惠Q的平均
isolationQ = 10000 × 内部实际联系工作 / max(1,内部+外部实际联系工作)
muQ = clamp(6000 − coherenceQ − reciprocityQ/2
            − recoveryReservoirQ/4 + conflictReservoirQ/4,−10000,10000)
noiseCoeff = trunc((2000+reciprocityQ/2)×coherenceQ×max(0,−muQ)/100000000)
phiNext = clamp(trunc(9000×phi/10000) + actualEventPulse
                + trunc(noiseCoeff×Noise[−400,400]/10000),−10000,10000)
```

事件脉冲不是实现者猜一个正数。以下表中的量都来自已收到且被核验的实际结果；各自冻结target必须同单位且正数，未知/未完成/God直接改籍事件不入表。

|实际事件类别|basePulseQ|actualQuantity / frozenTarget|
|---|---:|---|
|兑现共同工程|+800|实际验收产出 / 批准工程产出|
|完成共同救援恢复|+1000|真正恢复安全的原危险成员 / 事前真实危险成员|
|履行共同制度|+600|本服务期实际履行义务 / 真正到期义务；机构期一根|
|解决内部冲突|+700|实际执行的双方接受补偿修复措施 / 约定真实措施|
|未解决内部侵害|−1000|已知确证受侵害核成员 / 实际核成员|
|共同实际损失|−800|已确认损失量 / 事前实际承诺目标量|
|兑现群间交换|+300|实际验收交货量 / 冻结匹配契约量|

`ratioQ=min(10000,actualQuantity×10000/target)`；`amount=trunc(base×ratioQ×actualQualityQ/100000000)`，质量来自实际验收/可靠证据，不是“文化喜欢”权重。同一canonical实际类别每节点每日至多绝对1000，总和夹到±2000；同一根只记一次，跨域复述不能换类别补一份。普通重复接触只改变共同实践，不每天送重大事件。

`recoveryReservoirNext=clamp(old×9500/10000+实际恢复正脉冲,0,10000)`；`conflictReservoirNext=clamp(old×9800/10000+实际未解决侵害绝对脉冲−实际解决冲突正脉冲,0,10000)`。两库的衰减是明确逐日定点递推，初值0。近30日还需至少两根真实正事件、合计≥1000Q。纯噪声每步绝对≤280，在0.9保留率下稳定绝对幅度<2800，不能自己凑出4000的创生。高一致、互惠的群体更容易把同一事件理解为“我们共同经历的事”；未解决分歧反向作用。噪声会有波峰，但没有实际核的人群只波动，不诞生文化。

进入条件：一致度≥6500、互惠≥6000、mu<0，实际人类核和多类实践成立。需30个**有新实践证据的日子**；每天至少3条核边有新来源才积一日，单纯日历经过不算。维持阈值放宽为一致≥5500、互惠≥4500、4名活人类；10个实际证据日低于维持条件即休眠候选。只有已满足进入历史且 `abs(phi)>=4000`，才发起真实创生会合/同意任务；会合未实际完成不提交。

## 3. 创始人、Primary、Secondary与成员接纳

创始人从实际提名、本人愿意、实际在场的成年合格人类中选：不同参与日多者、已履行教学/照护回执多者、最早实际提名、ActorRef。人格影响是否参与、提议和接受，不代替来源资格，也不硬指定最聪明者。

Primary要求创始人无Culture且无正式LanguageSkills。一次原子提交建立 Culture、RootLanguage、共同起源回执、实际接受首批成员和创始人命名来源。根语言的16个基础含义必须各有创始人及至少3名核成员在至少3个不同证据日真实互认的primitiveMeaningContext回执；缺一项返回GENESIS_MEANING_CONTEXT_MISSING，不用未知fallback补齐。起源会合实际付出的传授工作使实际接受成员获得对应条目的基本互通Q3000，**不赠完整语言10000、识字、科技或任何物资**。其余人仍需实际接触教学。正式City/State允许提出正式化，是否真正升格由原城市/政治的同意、功能、语言和章程条件决定；不能文化诞生即免费造广场。

Secondary要求实际已有文化/语言的人类核、与母实践原型距离≥2500Q、内部联系占比≥6000，并有90个实际证据日的稳定差异。只建Culture，LanguageRefs不变。迁民与军人共同体可以形成它；国家改界不会直接触发。

每人最多8个活跃CultureAffinities。真实接受实践的更新为 `(7×old+3×observedPracticeQ)/10`；长期未实践每实际日衰减20Q，保前名与来源。达到3000Q且本人接受、实际掌握可交流基础语言后正式加入；低于1500持续30个实际证据日可以提出退出。臣籍、居城和文化分别保存，不用改籍刷洗文化。

## 4. 用少量可传授形式表现语言

首样固定16含义：问候、食物、水、照护、居所、交换、人物、地方、群体、是、否、数量、工具、危险、去、返。每个词有4个发音特征（起始部位、浊音偏好、元音高度、词尾类），每特征4个变体频率，整数和=10000。一个人最多4个活跃语言、64个稀疏词条；这不是自然语言理解器，也不声称模拟任意句法。

根语言从合同8套有限C/V字母盘及起源seed生成CV(C)词形；同形冲突按含义索引添加第二音节。规则有限且确定，不依赖网络或真实古语言包。名字和后缀由这个已存在词形系统派生，世界专名不随UI的中文/英文/德文切换。

每次真实语义教学/交流要有双方、已知词义、真实可交流位置或已送达文书、情境和实际学习工作。传授者从自己的频率分布掷本次发音，不能读接收者隐藏状态。听者确实识别到意义才融合：

```text
alpha = min(1200,actualLearningWork × learningEfficiencyQ/10000)
newFrequency[j] = floor((old[j]×(10000−alpha)+observedOneHot[j]×alpha)/10000)
```

除法余量先补本次所听变体，再按variantId；每特征总和仍10000。借助真实上下文可以学词，单纯站近不会得到语言。知识进度、语言频率和信念来源分开，错误消息不是免费正确技能。

## 5. 接触收敛、隔离漂移、真正分支

语言共同体由实际语义交流/教学图形成，不由文化或国境复制。每父语言最多8个活跃候选；实际token使用按参与工作加权成为原型。

隔离比例≥6000Q、稳定说话群体且实际教给至少2名新学习者的共同体，每180个有持续使用证据的游戏日可提出一次新发音实践。必须有实际成年人类创新/实践任务；一次只改一个词的一项特征，把最多1000Q从最多旧变体转向另一个支持变体；同量平手按variantId。创新先发生在实际实践者，只有之后真实话语传播才改变其他人。动物可延续、教学和使用已有形式，但动物独立群永远不登记新的正式语言分支。

互通度是16词×4特征的实际重叠：每项 `sum_j min(Afreq[j],Bfreq[j])`，平均后得到Q；未掌握意义贡献0。同一个Culture可以产生语言分支，两个不同Culture也可继续讲同一语言。

正式分支进入条件：互通≤6000、内部联系≥6500、6名持续参与的成熟人类、至少12含义实际使用、3项不同特征已经改变、两批真实新学习者至少跨360日教学历史。需要实际合格人类组织者与接受者同意的起源会合。互通回到7500以上、隔离低于5000或人类核低于4，持续60个实际证据日则休眠未成形候选。这两个阈值防止边境往返一周就换一门语言。

真正成形一次新建Language及无环parentRefs、冻结分支回执和实际SoundChange版本；不自动建Culture，不删除旧语言，不改死者旧名和旧文献。重新接触可以使说话形式收敛，已经登记的谱系历史仍存在。SoundChange每版本有限顺序执行一次，禁止递归替换和字符串爆炸。

## 6. 自然亚种以遗传和繁育图辨认，不以地图颜色

每个同物种主体取12个遗传原始表达分量：寒/热、基础代谢、力量、地速、游泳、飞行耐力、免疫、生育、寿命、储能、吸收。只用原始等位基因Q，**不把共享profile加成当新的遗传差异**；不使用毛色、国籍、文化、当前人格和高级意识。

```text
distance = sum(abs(actorAlleleQ[k]−prototypeQ[k]))/12
prototype[k] = 实际成员该分量的中位数（偶数取较低中位）
```

每物种最多8个prototype，候选公平样本首样64个；以相对于既有prototype最远的真实合格主体为种子，平手出生tick/ActorRef。发布时必须核完整实际成员，不把样本中64个当全部成员。

进入需要8名实际成熟同物种成员、与母prototype距离≥2500、簇半径≤1800；最近720日真实亲缘/繁育图至少2次已完成繁育、4名不同成熟参与者。`withinBirthQ=10000×簇内繁育边/max(1,簇内+跨簇繁育边)`需≥6500。再有90个真实繁育/接触与群体延续证据日才形成候选起源，不用站在雪贴图上90天代替生殖联系。

混合个体到最近原型距离≤1800且比第二近至少近500，才提出所属修改；模糊者保留原亲代亚种归属、实际Genome/谱系照常，不硬捏“兔牛混种”。保持阈值距离1500、至少6成员、繁育内联系5000；持续30证据日不够则未发布候选休眠。已发布亚种不会因几次混血删除，零活成员且无已承诺胎体才归档。

第一次新分支共享profile**逐字复制母分支**，成员只改变所属Ref；实际Genome、现容量、能量/伤势、亲缘和身份不变。于是分类本身不涨属性。后续玩家明确typed改新profile才改变未来有界容量。species/器官/身体/高级意识与高峰规则永不被自然分支改写。

## 7. 微型贯穿例与失败例

六名人类长期实际互助送粮、照护与共同劳动。六人的实践趋于相近、双向互助增加，使mu进入负区；完成共同工程后的真实脉冲和随机波峰可能使核成形。实际会合与同意后共同符号取得正式形式，Primary创建Culture和RootLanguage。若只是六名人物被玩家画笔统一国籍，每个root都是God事件而非共同实践，场没有合格边，不发生创生。

边地人群仍使用母语言；隔离后的少量实际创新经真实教学逐渐传给新学习者，某些词的发音分布偏向另一形式。直到两个学习者群体、多词、多特征、低互通和真实人类起源均成立才登记分支。若渡船恢复贸易，真实接触可拉近形式，未成形候选休眠；不用政治吞并直接抹旧语言。

同一species的两个真实繁育群遗传分量逐渐不同；繁育图确实更内聚，一簇形成分支。首次分类前后同一人的61项容量完全相同。若仅玩家把一半动物涂红，距离输入没有颜色，绝不形成亚种。

## 8. 单写者、迟到工作与保存

节点计划使用自己的Belief与实际已接触事件；起源提交必须完整核World/Session/定义版本、全部实际人类核、最终活集合、资格/本人同意/位置、节点未使用回执及成员实际证据。失败不先建Culture后才发现无语言；同Ref/回执重试返回原结果。God事件不伪造普通同意。

保存图位集/来源去重、实践/频率、节点phi/mu/证据日/成员分量/逻辑cursor、逐day随机counter、真实传授学习者批、prototype快照/谱系和共享profile版本。载入不重抽噪声/生成名字，不重置持久窗口，不把休眠候选直接复活。高层搜索共用决策核心的配额；合法起源的最终验证必须完整，耗尽可延迟墙钟发布，不能发布半个实体。

[emergence_life_combat_reference_model.py](../research/models/emergence_life_combat_reference_model.py)检验有限真实计算；未来EM/LP/CP场景不是生产游戏验收，也没有全球容量或画面证据。


## 9. ADR0018 起源会期与随机字节权威

创生不是一tick免费语言包。根语言每学习者16意义×3实际认可传授／使用×100专用工作tick＝4800tick；每组最多4名实际学习者，教师同时支付4800自己的专用tick和实际工作能量，学习者分别占自己的时间／付自己的工作能量。同一场通信需真实无遮挡8m或真正送达消息。创始者与至少3成熟同意人类完成所有意义工作才可正式提交；其他候选成员只保其实际学过项，不自动获得全部3000技能。meaning已有至少3证据日相互理解仍是独立门，工作不能把未知意义变成已知。次文化／正式语言分支需要发起者和至少3同意成熟人类各600专用实际通信工作tick，不替代既有持续证据。中断会期保存实际教学收据、余量、知识／候选revision、真实可用性和能量；不可反复创建实体套取技能。

随机完全引用 [runtime_foundation_v1.counter_rng](../../data/contracts/runtime_foundation_v1.json)：SONNRNG1、32bytes WorldSeed、域UTF8长度＋ASCII、canonical Ref 的world/kind/id/generation、32bytes定义hash、eventCounter／drawIndex／rejectionAttempt 固定小端编码，SHA256前8bytes作uint64，拒绝采样。所有真实事件 freeze 收据一次发布计数，预览无抽样。每日field调用是实际到期事件，不因worker切片改变域或counter；保存resume沿同定义版本字节与counter继续。有限模型用明确零seed／零worldfixture及实际合同hash复制该纯函数，不使用LCG、Python hash或渲染RNG。

亚种的2500分离／1800半径／1500持有距离全部在上述0…10000归一继承Q上计算；共享profile不入原型和距离。模型 `Actor.genome=(3500,…)/(7500,…)` 是已经归一的继承Q，`expression` 参数同为归一alleleQ/sharedQ；生产等位编辑仍raw0…1000，不混两种单位。
