# 文明、元控制、继任与集中信息空间

日期：2026-10-09。状态：**新版设计决定；生产代码未实现**。本文与 `data/contracts/civic_control_v1.json` 配套，不恢复清空的旧程序。政治八轴、爵位、帝国神授、文化/语言独立及真实产权继承来自逐字保留的[原始 v0.6](../design/Sonnheide_Complete_Design_v0.6.md)；具体首次选君、长子序、摄政、票数及界面合同是本轮补全的首版默认，可以通过合法程序调整，不声称旧稿已规定。

WorldBox 已发行的底部快捷信息、多选、地图元对象选择、数字控制组、Family/Clan、城市边界画笔及边界桶作为交互参考；Meta Control/ChessBox 在本轮官方证据中仍是预告。这里决定设计同类能力，不能把它们写成 WorldBox 已发行或 Sonnheide 已实现。来源和全部比较编号见[248 项研究](../research/WORLDBOX_FULL_COMPARISON_2026-10-09.md)及[官方更新记录](https://www.superworldbox.com/changelog)。

## 1. 必须同时成立的边界

最难的点是：给动物公民身份、画城市边界、接管人物和更换君主，看起来都只是改一个“所属”，实际上会改变四组不同的关系。任何入口都必须保持它们分开：

|关系|含义|不能顺带发生的改变|
|---|---|---|
|物种/亚种/个体|物种固有能力、亚种规则、实际基因与身体|入籍、加入家族或受圣光不改物种，不刷基因、不变成人手|
|亲缘/共同生活/王朝|生物亲缘、法定收养、共同预算、王冠组织|换住址不改父母；入王朝不改基因；继王位不继所有居民的财产|
|主权/行政/控制|国家法定主权、城市服务辖区、军事实际控制|占领不完成割让；城市刷边不把私人楼货变为国家财产|
|所有者/控制者/保管者/位置|法定产权、操作权、实际保管、真实所在|接管某公司不拥有其存款；货经过他国不改变货主|

只读查询、镜头、图层、浏览历史和 UI 语言不会消耗模拟随机数、推进忠诚或增加技能。名称编辑追加新 NameRecord 并保留原名/历史名；本地观察笔记与世界历史事实分开，不覆写既有事件。所有仿真变更通过单写者提交，命令包含 `commandId/worldId/expectedRevision/payload`；预览另带定义集、规则、目标、范围和后果 hash。相同命令最多生效一次，过期预览不自动替用户重写输入。

## 2. 公民、物种与文化资格

### 2.1 文明之光不是生成新人物

动物受光后，沿用原 `ActorId`、年龄、基因、亲缘、身体、位置、受伤、食物欠账与已有真实财物。它取得高级意识和文明主体资格，没有免费文化、语言、信仰、国籍、住房、衣物、职业或王冠。天降圣光是这个提交结果的表现；粒子命中、动画结束、LOD 或画面关闭不能决定启智是否发生。高级意识在受孕快照固定：同物种亲代至少一方已启智则后代继承，事后照光不回改已有胎体；成熟阈值和具体基因编辑由[生命合同](GENETICS_ANIMALS_AND_UPLIFT.md)负责，本域不另写第二个繁育算法。

人类法律成年为 18 游戏岁。启智动物的公民成年由物种成熟与认知成熟联合判定，采用生命合同公布的物种参数；成熟动物受光立即取得成年意识资格，未成熟后代随该物种成熟取得，不另加语言或文化门禁，不要求短寿命兔犬先活到 18 年。所有高级意识主体全龄保持各自物种成人身体规格。关闭衰老损害不暂停日历年龄或成熟，未成年仍会依法成长为成年。成人外形不赋予未成熟者劳动、军役、表决和独立签约资格；合法未成熟继承人可以持王冠，执行权交摄政。

物种不成为公职禁令：兔可参加教育、经营、信仰、参军及治理，牛也可以当公民或君主。每个具体工作检查工具接口、载荷、净空、移动方式、训练和真实工作时间；高级意识不会为四足动物赠一双手。允许经过真实发明与生产制作适配工具、衣物及建筑入口。没有私家马、骑乘、马匹运输、马厩或马具产业；动物中的马即便出现在物种资料中也不是交通工具、私家车辆或免费运力。

### 2.2 人类原创、所有文明主体学习

只有真实、存活、具备资格的人类创始群体可以触发 Primary/Secondary Cultural Genesis 或创建正式语言分支。创生场的人类核人数与条件只计合格人类；动物人口不能填满门槛，再借一个无实际参与的人类引用自动生成文化。高级意识、聪明基因、王冠、旧书或宗教编辑都不能绕过这个来源约束。

启智动物可以学习人类已有语言，加入人类已有文化，传播、教学、写书、创新、保持历史传统、发展信仰、治理城市与国家。仅由动物构成的群体不会新建 Culture/Language 实体；它们可延续已学会的文化语言，即使人类创始者后来死亡。不能把“方言”“动物族风”暗中登记为一门新正式语言或新文化。文化/语言编辑改变既有对象的合法实践参数，不伪造创始事实。

未学习现有文化语言的启智动物与前文化人一样使用稳定原始代号、组成 Household/Settlement/PRE_CULTURAL State，不能凭启智直接登记正式 City、称王或申请帝国。高级意识动物不是他人的牲畜产权：既有保管记录在启智时改为不等于财产所有权的关系，旧押品、商品或预约必须具体预览后撤销或结算；不凭空补偿、复制原动物或重置既有合同。

## 3. Family、Household 与 Dynasty

**Family** 保存跨代的生物父母与出生事实，另存明确标注的法定收养边，不改写 DNA 父母。婚姻/伴侣关系与生物繁育兼容性是不同字段；跨物种法律家庭或收养不会发生跨物种基因繁育。族谱可以沿生物或法定关系切换，显示存活/死亡、出生来源、代际、祖先、迁居和重要事件。所有节点使用真实稳定引用，未知父母显示未知，不能编造。

**Household** 是共同生活和预算主体，可包含非亲属；同一家族可分许多 Household，一个 Household 也可以跨 Family。家庭迁移和住房预约使用真实成员名单，不以“家族人口”复制一组居民。分户要拆预算、住房和真实物品保管；不复制食物、衣物或账户余额。

**Dynasty（王朝/王室）** 适配 WorldBox 的 Royal Clan：保存创立者、认定成员、传承根、历任家主、执掌王冠、政治规范、支持关系和成员/领土分布。它可以包含合法收养者和不同物种公民，并可统治多个彼此独立的国家。一个人可在多个国家持王冠，但首版最多执掌一个 Dynasty 的家主职务；每顶王冠的财政、继任和帝国凭证独立。

王朝可编辑名称、色彩、标志、入会/收养政策、教育偏好、服务义务、婚配/继位章程与继任顺序。所谓“共有特性”是会造成实际教育、预算、法律或关系后果的规则：教育需真实教师时间，礼仪需实际衣物，成员支持基于真实经历。不提供所有成员免费力量、产粮、法术、永生或军队倍率；血缘基因只能通过生命域遗传。

Family/Dynasty 无存活成员时变为 `EXTINCT` 档案，保留历史和收藏；有成员但无现任家主为 `HEAD_VACANT`，两者不同。Household 无活成员进入清算，不连带删除 Family。物种定义永不因最后一个个体死亡从目录消失。

## 4. 宪制八轴与爵位

保留原设计八轴，并提供可编辑组合，禁止用一个“国家类型”标签代替法律：

|轴 ID|可选值|初建公国默认|
|---|---|---|
|`crown_source`|世袭 / 选举 / 限定候选选举|世袭|
|`administrative_distribution`|中央 / 地方自治 / 成员联合|地方自治|
|`legislative_gate`|君主法令 / 等级会议 / 宪章会议 / 议会批准|君主法令|
|`fiscal_authority`|地方优先 / 固定分成 / 中央预算|地方优先|
|`religious_status`|无官方宗教 / 官方但容忍 / 国教约束 / 神圣王冠|无官方宗教|
|`property_regime`|公共主导 / 混合 / 私人开放|混合，前文化只启用最低土地与生存规则|
|`local_charters`|一致法 / 有限自治 / 成员保留法|有限自治|
|`subject_admission`|居留/定居/臣籍三套准入和权利记录|保护已有居民；新准入须真实接纳能力|

这些默认是本轮选择，初建时保存具体版本。以住民保护为默认不代表免费住宅、无工资劳动、自动批准所有移民、无偿私有化或开局开放成熟公司/银行制度。每轴的具体法律具有主体、条件、作用地、生效日、审批和优先级。

`rank` 仅有 DUCHY、GRAND_DUCHY、KINGDOM、EMPIRE，与宪制和从属条约分别保存。所有普通国家先为公国。第二座真实完成正式归属的**直属 City**触发大公国；Settlement、占领城市、附属/殖民国家的城市不计。随后丢城不反复自动降爵。文化国家称王走本国法定加冕行动、真实费用与审批；前文化国家不能称王。

帝国必须有官方文化、官方 Religion 根和有效 DivineGrant。申请显示真实国家/成员/领土、章程、根宗教、同意、财政和稳定性，玩家批准前再次验证。凭证默认绑定国家、王冠、根宗教与冻结的 founding_charter_version，正常换皇帝不再弹请求；换根宗教、强改成立成员集合或根本成立条件须重新申请。取消官方宗教须同时退回王国或解散联合帝国，不能留下无宗教帝国。编辑“宗教绑定”不是直接写 EMPIRE 或伪造旧凭证。

合法兼容的后续宪章修订保存独立 amendment 链并引用冻结成立宪章；不改旧 DivineGrant 批准事实，不因普通章程修正使帝国凭证突然失效。涉及根宗教/根本成立条件改变仍必须重审。

法律顺序为世界不可变约束 → 明确授予/保留权的条约及帝国宪章 → 当地宪制 → 合法法律 → 行政规则。官方宗教不自动等于居民强制改信，王冠神圣化也不自动改统治者个人信仰。法律和国旗名称、模板/颜色/国家主题色只改变其真实对应事实，不给经济军力魔法加成。

## 5. 首次统治者与继位状态机

### 5.1 立国与首任

登记中的真实 Settlement、至少一位成年高级意识居民、合法的集体土地/共同事务基础才可发起普通立国，不生成居民、国家库存、王室私产或凭空城市。创立人自愿接受且取得有效成年住民过半支持时成为首任；否则同一真实住民集合按下述选举规则选出首任。前文化支持可以记作非正式语言的集体认可事件，不创造一门语言。无人满足资格或无人过半支持则保持 Settlement，不刷“默认国王”。

首任持冠时建立 Dynasty、合法传承根和 CrownOffice，但 Dynasty 不是新的生物 Family。正式臣籍承认只覆盖真实接受立国的居民；在场游客/动物保管对象不是自动臣籍。首次王室私产只能来自首任原财产或实际、合法的转让。

### 5.2 共用生命周期

王冠职位状态为 `OCCUPIED → REGENCY`（暂时不能执行）或 `VACANT → RESOLVING → OCCUPIED/REGENCY/CARETAKER`。死亡、合法退位、法定废黜使王冠真正空缺；一次疲劳、附身、被抓起、短期伤势或军队移动不会重新选君。任何时刻每个 State 最多一个 incumbent 和一个有效代理权记录，历任记录只追加。

空缺提交先冻结既有职权授权，保存该刻的王冠政策和亲缘/资格版本；将公共职权与私人遗产分两个流程。继任候选、摄政或选举必须已有真实 Actor。继位不会瞬移候选，不回满健康/食物/体力，不创建卫兵或军装；远处继承人依法接任，实际抵达/工作/仪典另走路径、时间与资源任务。合法摄政可在受托期间签署限定事务。

### 5.3 世袭默认：绝对长子序

默认不按性别、物种、外观、力气或贫富排血统。从保存的 Dynasty 传承根按**出生 tick、ActorId**稳定排列法定认可的子女，深度优先遍历“长子分支全部合法后代 → 次子分支 → 后续分支”；生物子女与合法收养子女均可纳入，但编辑收养/排除会预览继承序变化，不伪造出生或基因。已经去世或当前无资格的祖先仍可作为通向后代的分支，不因为父亲早死就抹掉其孩子。

存活、未拒位、具有该王冠合法臣籍及未被有效排除的第一个人继位；未成熟可持冠并进入摄政。谱系可能有多条亲缘路径，访问集按 ActorId 去重，不能获得两次继承名额。批量死亡/地形损坏先以全事务最终存活集合排除所有同批死者，再确定继任者，不按逐个死亡回调次序选中即将死亡的人。合法在任者、已退位且被本轮政策标记退出者与真实死者不得重复选中。资格排除是具体法律事实，不能靠改 Dynasty 颜色或 Subspecies 特性剥夺王位。

默认法定子女序只用于本王冠；私人遗产按遗产法分配。可调选项包括生物/法定子女范围、指定合法继承人、成员资格、成年限制、特定合法宗教/臣籍条件、分支排除、稳定排序和无候选后备程序，均必须有宪制授权和过渡预览。初建默认无性别/物种限制、不要求国教个人信仰。

血统无候选时先检查**已有且仍有效的指定后备继承人**；没有则进入成年主体的限定候选选举，默认候选为现 Dynasty 合格成员；若 Dynasty 全灭或完全无合格候选，再开放全体合格成年臣民选举。不会自动构造新王子或克隆旧国王。新王朝建立另记政治事实，不重写旧 Family。

### 5.4 选举与限定候选选举

普通国家默认每个真实直属 City/Settlement 一席，由当地有资格的现任代表持有；没有现任代表的地区通过现存成年住民选出，不能因为多了一个席位新增 Person。前文化一聚落立国时成年认可者为初始议事集合。席位、候选、投票者是三个独立集合；一个人合法兼代表多席仍按席位各记一票，不重复同一席。

普通选举候选默认所有成年合格臣民；限定候选选举按宪制的现 Dynasty、指定成员组、现任公职或有效登记提名谓词过滤，不改变投票者集合。帝国选帝侯预设每个真实成员国一席，由该国现任统治者或其有效摄政代表行使；候选默认成年合格帝国臣民、获一名选帝侯真实提名，不把“选帝侯”自动等同于“只能选选帝侯”。宪章可依法收窄。

首版调参默认：国内每轮 7 游戏日，联合帝国 14 游戏日；法定人数为章程席位数的 `ceil(2N/3)`，胜选为有效票过半。第一轮无人过半时取票数最高两位进入一次决选；入决选的同票以提名 tick、ActorId 定序。决选仍同票时，依章程以真实行政服务天数多者 → 较早出生者 → ActorId 定序决定，并记录 `CONSTITUTIONAL_TIEBREAK`。以上规则开票前可查，不能在结果出来后换成有利算法。

每席最多一张有效票，可以在截止前合法改投；死亡不凭空删除已经由仍存在席位合法签出的票，合法席位继任者可改投。退出帝国、席位被合法撤销、候选死去/失格须更新候选/席位版本并重验，不悄悄改票。无候选或不足法定人数则 `NO_RESULT`，进入/维持摄政式临时管理，30 日后开启未来的新一轮，不补算缺席票、不无限在同 tick 循环、不制造候选。

### 5.5 摄政、临时管理与断代

摄政顺序默认：已有合法指定摄政 → 有资格的现任议事主持人 → 按继承序首位成年王朝成员 → 真实服务任期最长的合格公共官员（ActorId 定序）。候选接受，不能强制把拒绝者变成摄政。无人具备资格则 `REGENT_VACANT`；地方既有必要行政规则仍可用真实人员执行，但冠级新战争、改宪、处置大额国资和授予新特权暂停。不能借自动管理造一个摄政、搬运工或教师。

摄政可以支付既定工资、履行既有条约、维持基础供给和既有防御；不得默认改继承序、收自己为继承人、挪用国库或申请新帝国。君主满足成熟/恢复执行资格后，单次事务撤销代理并交还权力，摄政不自动获王冠/私产。未成熟者无摄政时保留合法王冠但不能执行受限命令。

国家不是君主一死就灭亡；没有现任者不等于没有国家，既有城市、债务、库存和居民保留。彻底无人且不再有有效继承/居留共同体的国家依明确终结流程归档，领土权和剩余财产分别清算，不能直接删行或转给路过的任何人。分裂国家也只从已有真实组织/居民/土地形成，仍先为公国。

## 6. 私人遗产、公共财产与服装

`Estate` 冻结死者真正拥有的财物/债权/债务；第三方寄存、公司法人资产、CitySquare 库存、王冠国库和借用装备不进入个人遗产。先处理有优先序的债务及真实遗产税，剩余才转所有权。继位事务只换 CrownOffice 权限，既有国家账户和军队责任 City 不改成新君主私账。

首版默认净遗产：有合法伴侣且有法定子女时各分 50%，子女份额均分；只有子女则子女均分；只有伴侣则伴侣全部；都没有则最近法定亲属按亲缘距离、ActorId 定序，同层均分；无合格个人受益人则按遗产法移交公共遗产账户。份额量化余数按受益人 ActorId 分配到最小计量单位。未成熟受益人可以拥有财产，但保管/签约权限归受托监护，不把财产所有权转给监护人。债务不自动无限倒灌亲人。

实物可以在原容器中完成产权交接，再经真实搬运；不能继承即瞬移、复制或翻新。死亡者的真实衣物保留耐久、污染/损坏、所有权和尺寸兼容性；军装依据实际服役国家，不按新国籍/王朝自动生一套。衣物购买、正装优先与基本食物预算遵循主设计，王朝/公司要求正装也不剥夺缺正装者上班、工资与岗位。

## 7. 元控制、附身与决策观察

### 7.1 三种分开的模式

默认是全知观察/神力。**元对象控制**锁定 State/City/Alliance/Army/Culture/Language/Religion/Family/Dynasty/Subspecies/Enterprise 等真实对象，选中范围明确显示成员；成员随提交后新版本更新，旧命令仍复核当前资格。**仅视野观察**使用同一视野而不取得下令模式。**单体附身**把输入转换为一个 Actor 的移动、使用物品、工作、交互或攻击意图，不能瞬移/穿墙/上高峰/填满物资。

Culture 多重归属用明确显示的有效成员阈值；语言按真实熟练资格，亲缘按注册边，联盟按有效成员国家，企业按实际劳动/授权关系，亚种按稳定 SubspeciesRef。多对象联合选择做 ActorId 去重，单个人不会领两次工资/命令/运输预约。选 Family 或 Religion 的成员不使其财物变成公共所有；下令者仍须有实际角色权限或明确神意委托，物理能力和真实材料永远不能跳过。

元命令可移动、排队途经点、采果/伐木、农耕、搬运、送建材、开工批准、训练、防御、撤退、供给、学习、救助/安置。建筑人物只负责实际材料送前侧接货区，本体按工期自动建造及铁丝网围起/撤下；元控制不得重引入人站在现场砌墙动画。采果/采伐互斥预约、工作时长、双岗位冲突、工具/训练、可达性、食物与冷暴露持续有效。启智牛即使能搬重物，也不会获得不存在的车库车道或穿门净空。

### 7.1a 单一有效控制租约

选中 State、Family 或 Army 只改变本地观察/候选范围，**不会取得 Actor 控制权**。真正下令/附身必须在单写者屏障取得 `ControlLease`，租约持有者为当前合法控制来源和会话，不是 Actor/财物所有者。World 维护唯一索引 `ActorId → activeLeaseId`：一个活 Actor 任一时刻最多受一个有效租约约束。一般自主 AI 没有占满这个玩家输入索引，租约只替换高层输入来源，不关闭生理/生命/物理更新。

租约保存 `LeaseId/WorldId/SessionGeneration/holderPermissionRef/mode/scopeRef/scopeMembershipRevision/actorRefs/leaseRevision/grantedTick/expiresTick`。取租约前按当前真实成员去重并预览可控与已被占用者；已占用者明确列出，默认排除已预览的占用者。不能在提交时静默扩大/改目标，若预览中的空闲者被另一租约占用、成员/权限/版本改变，整笔重新预览；一个也没有可控则拒绝。**任何已有有效持有人都不被新选择抢占**，同一玩家切到另一个群或附身也需显式释放/转换，或明确引用兼容的同一 LeaseId，而不是按“玩家同名”冒用。

获取与首条实际命令可以同一事务完成；若资源/路线/任务校验失败，整笔拒绝、不遗留空租约。`IssueMetaOrder`、`PossessActor` 和 `ReleasePossession` 必须提交当前 lease ID、会话、持有人和 lease revision；命令复核独占索引、截止 tick、目标 membership revision、实体存活与原民事/物理权限。租约不授权给非成员下令，也不授权花成员私人财产、代签选票、伪造同意或绕过摄政权限。

首样租期为 600 个权威 SimTick，允许范围 1—3600 tick，均为待测输入参数。续期必须由当前持有人在租约仍有效时提出，设置为 `now + requestedDuration`，不叠加成无限未来时间；需重新核验会话、范围、成员、权限和独占索引。世界暂停时 SimTick 和剩余租期一起暂停，界面刷新/鼠标动作/墙钟不能推进到期；保存记录精确剩余量，不只保存一个已经过期的绝对期限。

到期、显式释放、退出控制模式、退出世界/应用、Actor 死亡或失去控制资格通过一次屏障撤销索引和高层输入权，恢复同一 Actor 的自主规划。成员死亡只移除真实死者，余下成员租期不回满；若范围/资格变化，则使旧命令失效并显式缩减或撤销租约。已经送到的货、消耗的果/弹药、真实伤害与完成的劳动保留；尚未执行的合法任务按同一任务系统继续/暂停/取消，不退还已花物资或增加收入。

读档换 SessionGeneration 时，旧会话租约立即失效并恢复 AI，保留租约历史与未完成真实任务；旧迟到输入不能再次激活它。界面可以恢复控制组/观察范围，继续控制必须按新会话重新申请并核验，不能加载即抢占或延长原租期。跨 WorldId 的 LeaseId 无效。

附身退出恢复该 Actor 原自动计划，不复原已经消耗的物品、战伤、劳动或犯罪/法律事件。附身者死亡即退出并打开真实死亡档案，不能将控制转到偷偷生成的替身。支持切换到另一个现存有资格对象。

### 7.2 战雾与已知外交

默认玩家全知；可选元控制战雾将成员实际视域与合法共享视域联合。三态为当前可见、曾见最后已知、未知，保存发现与最后已知记录。地形、山体、建筑、身体高度及视距参与权威遮挡；地平线/LOD/镜头角度不改变认知结果。查看历史/收藏不会泄露未发现的现行敌军位置，档案显示旧时间戳。

`diplomacy_requires_discovery` 可开启：文明外交 AI/受限元控制只对实际认识的国家发出新外交计划，可由真实接触、使者、合法共享资料或接收文献建立认识；玩家全知仍可观察其存在。它不撤销开关前已有条约和战争。神力是否可在控制期间使用由独立 World Law 限制，不通过小图标隐藏实现。

展示正在考虑的需求、可行行动、实际分数因素、被拒原因、执行中任务与可调 AI 行为类别，不模仿生物神经科学模型。可逐个暂停/恢复“自主迁居、社会接触、探索、投产申请、主动交战、选举提名”等高级规划；默认不关闭食物消化、 aging、冷暴露、死亡或必要物理约束。只暂停规划不擦文化、记忆、技能或高级意识，不把人自动变成动物/奴隶。管理员可以取消尚未执行的动作，已发生的搬运/伤害不能回滚成免费物品。

## 8. 城市边界画笔与领土后果

默认画**城市服务辖区**，另可选国家主权调整或未归属领土申领；这三层不能用一个颜色字段代替。圆/方画笔、笔宽、擦除、四连通填充桶、吸取目标支持暂停预览。桶遇既有其他城市/国家边界停止；跨既有边界使用明确的刷划模式，显示被影响对象。可以划飞地但应显示不可达/服务断联，首版默认需与既有核心或有效交通走廊连通。

辖区刷默认同国转服务归属，不改变个人臣籍、住所、公司注册主体、私人地产产权、宗教或军队归属。城市中心/CitySquare、完整设施占地和入口不能被刷成半个归属；受影响楼地以全占地规则归一处理或拒绝分割。必须保留至少一个真实核心和完整可达服务方案；空白辖区不自动生成 City、楼、人口或仓库。城市国税/关税/服务责任按地点事实重新评估，已签税务/合同不重复结算。

跨国主权模式走明确 `TerritorialTransition`：有效和约/割让/帝国授权，或单独标注的玩家神意主权调整。神意事件不伪造当事人同意或历史和约，也不免除居民/财产/条约的后果。目标必须真实存在；行政框、土地私人产权、军事实际控制、税务作用域与合法军队通行分别更新。新取得土地不算已经有正式 City，私人货经过新边境只按清关记录结算一次。

预览显示迁变的居民、地块/楼/农田、住房和劳动可达性、预算与税务、旧人行/车库/送货通道证书、在途货与预约、Army 供给、从属/帝国/宗教资格、正式直属 City 计数。提交锁定最小影响闭包，同屏范围变化或第三方晚结果使预览过期。一次提交处理所有依赖，不能先刷国色后再在下几帧补税和国籍。

地形神力造成的淹没、坡道移除或高峰化不自动改主权；真实住房和服务损失触发修复、真实迁居与政治风险。被水没的城市可以保留残存行政与历史，不空刷居民重建。峰顶也不能靠画城市边界获得建筑/通行资格。具体空间和冷暴露见[地形与坡道](ALTITUDE_RAMPS_AND_THERMAL_EXPOSURE.md)。

## 9. 外交计划、联盟、战争与防御

建立独立 `PoliticalPlot`：发起者、参与者、目标、动机证据、准备工作、真实资源承诺、批准、期限、失败/取消/泄漏和成果。类型覆盖结盟、战争、和平、分离/叛乱、从属重议、继位争议、领土调整和制度改革。进度展示已办事实，不是每帧自然涨的成功条；失业、食价、欠薪、征兵、实际占领和宗教压迫分别作为风险账，按仿真计划更新，打开城市窗口不触发新的忠诚计算。

战争/友好工具适配为方向性干预：玩家可以让合法主体提出/优先准备和平、盟约、开战，或明确提交神意外交事件；这不创造 Army、征兵名额、武器、同意或条约付款。和平须处理现有当事人及占领/俘虏/在途合同，不能把所有战争实体删除来伪装和解。

联盟独立保存成员、条约、会费、信息/通行/补给协定、共同战争、历史和实际声誉。联盟成长体现可执行的互信、组织权限、共同标准和真实公共投资，不给成员自动产粮/力量倍率。每项军事承诺有真实城市、真实居民与拨款合同，联合预算不把所有成员账户合并。

首版只有单层 Army；多 Army 可临时共同命令并各自保留队列，不造 Corps 层级。军人均为现有合法成年主体，职业时间与家庭预算真实改变，缺口不刷新兵。前现代原创建模武器、训练、真实弹药和装备耐久门控；不纳入现代军备、核弹、UFO、毁世工具、随机灾害。私家马/骑乘及骑兵能力不作为新系统保留。

本轮适配加入**可选防御墙与门**：原创可建维护实体，真实材料、通行净空、开闭门权限、占地和耐久；不可在一条边界颜色线上自动冒出城墙。建墙同样不能堵掉已有民居人行/车辆/送货接入，封城须显式战争/封锁行为及其后果。受地形或战损损坏撤销真实阻挡/通道证书，废墟不在加载时回满。城墙不会以一个“城市防御分”代替真实空间、守军、补给与路口控制。

## 10. 八底栏与统一信息页

全部全局入口在最下八分区：**观察、地形与生态、人物与动物、文明制度、建设资源、经济物品、世界、设置**。第三分区扩展动物/基因/文明之光，不添第九层杂乱栏。每区仅当前工具组与必需参数；对象局部关系、返回、页签、编辑、提交/取消在对象窗口。窗口不遮住底栏，点窗口不向地图泄漏放置/清理。

近景点 Actor/物品/楼树；远景按当前国家、城市或成员分布层点元对象。同名、改名、死亡、灭绝、拆分物批仍按稳定 Ref 打开。统一信息窗顺序为概览、关系、任务/资产、统计、历史、编辑；概览最多四项主要事实加最重要的问题，其他展开。多选快速条显示数量、成员切换、共有动作和不同值，不用共值误覆盖差异。

全域登记页包括原人物/Household/聚落/城市/国家/帝国/联盟、文化/语言/宗教/教派/教会、企业/楼/港/Army/车船/衣物/实物批/合同/工程/创新/文献/植物/矿床/道路/世界/标记/账户/预约/运输/生产线/设施/知识许可/研究/战争/条约/创生节点/姓名/历史事件，并补齐 **Actor 动物视图、Species、Subspecies、Genome、Family、Dynasty、Estate、CrownOffice、CrownElection、Regency、PoliticalPlot、WorldRule、Ramp、AccessCertificate、ThermalExposure、Skill**，以及城市广场、船舶、树上果批、真实地表食源/花蜜、蜂巢、冻结教会章程、帝国申请、神授凭证、控制组/控制授权、实物容器、装备、税务评估、本地存档，共 **70 类页、466 条类型化关系**。帝国、港口与动物可为底层真实对象的特化页，不复制同一实体。

每页有明确可编辑字段、只读历史/能力和合法动作，而非全部裸 JSON。Species 固有能力只能查；Subspecies 范围内特性、Person 性格/基因、国家宗教地位/法规、王朝章程等提供类型化表单、约束和具体后果。财物 quantity/余额、出生事实、过去死亡、根来源、冻结教会性质、帝国批准不是可任意输入字段。

## 11. World Laws、统计、收藏与清理

### 11.1 规则是具体门控

规则值和生效 tick 保存；关闭新行动不取消既有事实，开启不补算累计出生/战争/木果/收入。World Laws 不替国家法、不跳科技、不改 Species 固有能力、不关高峰禁止、不取消物质守恒。`civ_reproduction` 管高级意识主体的新配对/受孕，`animal_reproduction` 管所有非人主体的新配对/受孕；高级意识动物须同时过两门。中文标签为“允许文明新繁育/允许动物新繁育”，只门控未来配对/受孕；已承诺的孕期/蛋继续正常完成，保存真实到期状态，不冻结或抹掉胎体，不复开集中补生。

aging 仅抑制自然衰老损伤及该原因的死亡；日历年龄、成熟、孕期继续，出生日期、既有死亡和其他伤亡不倒退。恢复按当前年龄及未来 tick 限幅处理，不回春，也不补算关闭期间历史损伤。`hunger_consequences` 仅抑制直接饥饿健康伤害及该原因死亡；绝对 energy/fat/hunger_debt、食物需要、购买/消耗、基本预算和真实行为弱化继续记账，不赠能量或食物。复开只按当前状态和未来 tick 有界结算，不一次补算关闭期间的历史伤亡。`thermal_consequences` 同时覆盖寒冷与过热：关闭仅抑制直接热环境生命损伤，真实能量、疲劳、体湿和 cold/heat exposureDebt 继续更新，不抹掉高度气温、衣物/住所需求、真实消费或高峰不可达。复开只按当前状态及新 tick 限幅结算，不补算关闭期间的历史伤亡；饥饿后果开关独立，不赠能量。

感染传播只门控新的真实感染源/接触传播；现有感染、伤口、营养、免疫病程和护理继续，关闭不治愈/清账，开启也不随机生成感染。

新增门控覆盖动物新繁育、冷热后果、真实感染传播、自主征募、自主外交计划/叛乱/领土申领/建聚落/公建、人类文化创生与语言分化、自然新植株恢复/生态传播、有限矿源自然再生、总体/物种/亚种入场上限、元控制范围/战雾/神力限制、外交需发现。默认与精确作用范围见契约。总体/物种/各亚种成员数量上限只阻止新 Actor 的受孕/放置槽预约，不杀现存生命；已承诺胎/蛋的预约保留，降低上限不取消生命。亚种成员上限按稳定 SubspeciesRef 配置非负数量，空 map 无额外限额，与亚种目录条目数量是两个不同参数。启智不新建 Actor，不能为了人口上限拒绝身份升级或删除个体。亚种目录上限只限制创建新亚种条目，不改写现存基因、不禁合理个体变异。

普通动物捕食规则只门控非高级意识动物的新猎杀目标/任务，既有真实战斗和摄入尸体继续，不赠食物；启智主体按公民冲突/合法狩猎行动处理，不走牲畜捕食 AI。

共 28 条首版规则（含数值上限）。规则列表可搜索、按组、收藏和重排；排列存在玩家界面偏好，不改变规则执行优先级或 World revision。矿源再生默认关闭，启用也仅消耗有限地质预算生成可采源，不把矿料塞进库存；不提供生物/人口最低值的后台补刷规则。

### 11.2 统计不是一串总数

所有曲线及比较带指标 ID、时期、单位、分母、地理/身份/产权口径、快照 revision、来源和缺测标记。国籍人口、居住人口、当前位置人口、劳动人口、作战人数、动物总量和高级意识人数分别统计；启智算“意识转换”事件，不算出生或从虚空迁入人口。人口变动满足 `期末 = 期初 + 出生 + 玩家放置 − 死亡 + 真实净迁居`，跨 sapience 分类另加转换项，世界总 Actor 数不因启智变化。

Family/Dynasty/Subspecies/国家/城市等可以比较出生死亡、寿命、温度暴露、营养、实际技能/劳动、食物/木果/纤维产消、工资税务、住房、衣物耐久与购买、战争/供给等。非同口径不可相加；所属交叉比较以 ActorId 去重。库内与在途按所有权和状态分组，单批不能双计。数据零与未知不同，缺测不画伪造零线，历史降采样保留极值与实际事件。

长史记录重要因果事件及真实对象引用，可从曲线变化点跳到战争、死亡、继任、领土/地形事务、启智或具体批次。关闭图表采样只停止未来可选高频记录，不能删除法定账本、出生死亡和事务审计；重新启用标明数据空段，不补造历史。

收藏涵盖所有真实对象、物品、灭绝档案与地图标记。观察笔记与世界事实分开；玩家账户的跨世界观察里程碑和单世界历史分开，数据不可用于生成基因/财物或强制工具解锁。重要人物发现页按已有事实排序和解释“为什么突出”，不是给人物补一个神选属性。

分类清理选择地皮主题、纯装饰花草、机制植物/树、矿源、楼、路、坡道、未回收废墟、普通动物或高级意识生命。默认保留生命/真实货物/旧接入；不能清主题顺便杀树、清花草顺便删粮田。普通楼路清除必须安全安置真实居民货物及维持邻楼接入，不能办到则拒绝；明确地形神力与生命清除才按预览执行损坏/死亡。死亡一人一次，释放/重路由真实预约，遗产和王位各自结算，历史与第三方财产保留。

## 12. 本地存载、设置与范围

本地多槽存档、手动/自动/退出保存和独立自动档列表有预览图、时间、地图名、描述、规模与错误状态；用户可以文件导入/导出，解析隔离、版本/ID/合同校验成功后才发布。保存只取已提交世界；草稿另在当前会话保存恢复，不将预览当世界。先写临时、校验持久读回、原子替换 Continue 指针，失败留原档；新世界发布也遵守同一门槛。

保存元控制范围、最后已知视野、控制组、真实席位/票/摄政/王冠/私人遗产、待办政治计划、规则及履约/库存/运输。镜头可单独保存，读档不推进脑/忠诚/遗传或补出生。死亡/灭绝对象以真实档案恢复，公共国库不会跟“当前统治者”重建。

设置包括底栏/窗口/工具提示/地图名独立尺度、快捷键重映射、界面隐藏、音乐/音效独立音量、镜头惯性与降低动态、射线/光/粒子质量、材质预加载、图表记录、自动档频率、帧率上限、帮助/教程和本地更新日志。表现开关不关闭冷伤、物品耗损、启智或树果权威逻辑。音轨选择与界面动效不消耗模拟 RNG。新工具不以成就解锁阻挡玩家编辑；可选观察里程碑不给库存、基因或隐性强制进度。

明确不制作程序世界模板库、Steam Workshop/Steam Cloud 及其社区订阅入口；不建设其他商店流程。保留 Blank/Earth 两入口和局部圆/方笔刷，不把模板库换个名字加回来。禁止免费克隆、复活、Loot Rain 刷物、脑编辑洗状态、地图交换抹身份，以及盲目引入幻想世界或全套毁世工具。

## 13. 贯穿验收场景

以下是未来实现必须证明的场景，当前仅合同一致性检查，不冒充运行测试：

1. 神光照已有兔，Actor 总数不变，启智年龄/食物/基因保留；未学文化语言不能登记 City；学习后可担任有效公职，仍不能在人类缺席时新创文化语言。
2. 老国王死亡，先长子分支的未成熟后代持冠、成年摄政执政；国库和公有 Army 不成其个人遗产，私人衣物不翻新，死亡重放不重复分产。
3. 全 Dynasty 死亡，只剩真实普通成年臣民；后备选举产生新王室，不产生新 Actor；无人可选时合法空位和工资债务保留。
4. 选帝侯在投票后死亡，继任席位可合法改投但不得多投；候选死亡/成员退出使版本重验，30 日重开不得同 tick 死循环；普通皇位继任不重复请求神授。
5. 边界刷跨一家私营仓储与在途货物，主权/税务转换不转货主、不给新库存、不双收关税；外城楼的全占地和旧车库入口不可被颜色刷断。
6. 移除坡道后真实人/启智动物/Army 都失去相同通道，命令暂停/重路由；没有控制方式或耐寒基因能登高峰，不能自动瞬移修路或生成移民。
7. 附身采果转真实批次，退出不回果；附身开火消耗真实弹药；切镜头/图层/语种不改变仿真 hash/RNG。
8. 关动物新繁育阻止新的非人配对/受孕，但既有胎/蛋正常到期；关 civ 新繁育也门控高级意识动物的新受孕；开关反复/存读无补出生。关饥饿/热环境后果不改变真实食物/衣物成交，热暴露债仍按实际环境更新；关衰老损害不冻结成年，关感染传播不治疗已有感染。
9. 关闭图表只出现缺测段，合法事件仍存；比较同一兔所在 Family/Subspecies/State 不重复加人口；收藏死者能跳回真实死亡、Estate 和历任记录。
10. 德文长文本、中文 IME、窄窗八分区、键盘焦点与草稿跨页恢复可用；没有纯装饰小字/按钮边框，主页仍为批准的纯文字菜单。
11. 同一真实公民同时属于 State、Family、Army；从 State 取租约后，Family 群命令和 Army 附身不能取得第二租约。预览列出占用者，提交前新冲突使原预览拒绝；显式释放后再获取，旧 lease revision/session 的晚输入被拒绝。到期/死亡/读档恢复 AI，已送货与真实战伤不撤销。

工程施工时按所有高风险边界做跨模块审查，整批修改后统一构建验收。不得重新执行已删除的旧构建入口或用历史 headless 记录表示这些功能完成。
