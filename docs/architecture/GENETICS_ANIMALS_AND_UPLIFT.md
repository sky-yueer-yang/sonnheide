# Sonnheide 生命、全面遗传、动物与文明之光

日期：2026-10-09。状态：v0.8 新设计规范，**生产实现尚不存在**。本规范由本轮用户明确要求启动，取代旧设计中“无动物、无基因、马仅交通资产”的范围决定；原始 v0.6 仅作历史来源。新版总入口：[v0.8](../design/Sonnheide_Design_v0.8_Living_Pixel_World.md)。配套机器合同：[life_genetics_v1.json](../../data/contracts/life_genetics_v1.json)。温度与通行由 [地形、坡道与暴露规范](ALTITUDE_RAMPS_AND_THERMAL_EXPOSURE.md) 及 [terrain_access_v1.json](../../data/contracts/terrain_access_v1.json) 收口；法律、成年与统治资格由 [政治与元控制规范](CIVIC_CONTROL_AND_SUCCESSION.md) 及 [civic_control_v1.json](../../data/contracts/civic_control_v1.json) 收口。

## 1. 新要求与明确设计选择

用户要求：基因全面影响耐寒、耐饿、力量等；动物进入世界；玩家以“文明之光”使现有动物取得高级意识；这些动物能够学习人类语言、加入人类文化，但不能自行诞生文化或语言；亚种特性可编辑，物种固有差异不可编辑；私家马删除；高峰任何生命都不能到达。

以下是为形成可施工机制作出的**新设计选择，不冒充用户原话**：

- 启智不可逆；不通过普通基因编辑或亚种修改绕过文明之光。一次光照仅影响实际选中的主体，不把整个亚种自动启智。
- 合法同物种繁育时，受孕时任一亲代已具高级意识，后代出生时继承高级意识。未启智亲代的既有孕体不被后来光照追溯改写；其出生后仍可由玩家照光。
- 一切主体全龄保持自己物种的固定成人身体规格；出生仍为 0 岁，不缩放成幼体。蛋／巢可表现孕育过程，出壳后仍采用该物种成人体规。人类法定成年固定 18；动物按物种固定成熟龄取得成年资格，不要求兔或蜂等待 18 年。
- 启智主体成为独立的民事个人，不能继续作为牲畜财产交易；撤销原牲畜产权与不再适用的处理预约，记录损失，无自动赔偿或退款。实际携带物和第三方货物保管关系保留。
- 马可保留为真实动物物种，但新工程范围一并停用骑乘、骑兵、马驱动力车辆和私家马槽，避免残留交通资产模型。用户直接要求删除的是私家马；额外停用项目是本轮一致性设计。
- 野生动物来源为创建时明确选择的有界初始生态、玩家放置或合法繁育。灭绝、人口变少、地图重新可见、载入存档不会自动补动物。

这些选择都在合同中有单独来源字段。尚未确定的最终产量、温度系数、孕期、寿命和移动速度不作为科学事实或已平衡数值；首样参数只为验证工程不变量。

## 2. 真正需要突破的五个边界

1. **遗传不是人格换名。** 遗传能力必须落到真实耗能、运动、冷暴露、健康和生育；人格只影响选择，不能代替物理能力、岗位工具、货物和法律。
2. **可编辑不等于可越过物种。** 基因和亚种变化都必须受物种固定包络与能力掩码约束；兔仍不是牛、鱼仍没有腿、启智仍不会长出手。
3. **高级意识不是凭空生成一位人类。** 原动物的 ID、年龄、身体、基因、伤势、能量、位置、亲缘和实物都要连续；新增的是同一主体的民事／认知方面。
4. **生态和经济共用真实数量。** 装饰草花不可变成食物，神力放动物不可刷肉／皮／奶／毛／蛋，捕食、畜产、果实和尸体不能在两个账本重复存在。
5. **世界修改必须一次结算。** 坡道删除、地形淹没、动物启智、基因编辑和岗位失效都要在同一世界写者的事务中完成，不能等渲染或另一个系统随后修正。

上述五条缺一不可。例如只增加 61 个滑块、没有冷热和耗能后果，仍不构成基因机制；只给动物贴一个 PersonId、未处理牲畜产权和未完成捕食预约，会同时出现人和货物两种身份。

## 3. 同一个生命主体，分开的事实

### 3.1 稳定主体与能力方面

`ActorRef` 是人的身体和动物身体共用的生命主体引用，从放置／出生到死亡归档永不复用。`AnimalRef` 表示物种为动物的 Actor；`PersonRef` 表示拥有高级意识、附带 `CivicAgent` 民事／认知记录的同一个 Actor。它们不是三份可复制实体。

主体保存：origin、species、subspecies、出生 tick、存活状态、空间容器／位置、双亲与遗传、高级意识来源、绝对生理数量、衣物／工具、实际货物保管、关系和历史。移动权限、所有权、保管权和民事资格分开：普通养牛可有产权和照料人；启智牛有自主个人身份，可照料别人或受雇，绝不成为车辆或他人的可交易人身资产。

人类新主体只允许玩家放置（18 岁）或合法出生（0 岁）。不会因企业缺员、国家成立、任务启动、移民申请、Army 编制或文化生成而造人。动物启智不触发 `CreateHuman`，也不把来源改成“玩家放置人类”。

物种固定的是功能包络，不是每只个体的数值相同。合同首样中，兔最低裸载速度 4 大于牛最高裸载速度 2.8；牛最低可支承携带载荷 24 大于兔最高 0.65。单位是本游戏校准单位，目的在于保证所有合法亚种／个体编辑后仍保留“兔快、牛强”的标志差异。最终调参也要保持这些顺序不变量。真实载物、伤势、泥地和疲劳可使某只兔实际慢于健康牛，那是当前条件的后果，不是物种被改成牛。

人类没有飞行器官，所以 `flight_speed=0`；鱼没有地面运动功能，所以 `ground_speed=0`；山羊有限攀越也不豁免高峰；任何外貌基因不改变身体尺寸、门口净空和楼内 fit。毛皮保温只在物种已有毛皮／羽毛／皮肤结构内变化，人类不能凭毛皮基因长出牛皮。

### 5.2 遗传是游戏模型，公式公开

本项目使用有界定量二倍体游戏模型，**不是人类 DNA、真实染色体、真实医疗或遗传学模拟**。每项两个 `uint16` 等位值，范围 0…1000；指标方向明确：更高孕期／睡眠需求意味着更长实际时间，不伪装成全部“越大越好”的 buff；61 项原始等位数据为每主体 244 字节，不为每人创建全基因组字符串。

```text
individualScore = (alleleA + alleleB) / 2000
profileScore    = subspecies.sharedTrait / 1000
effectiveScore  = clamp(0.7 * individualScore + 0.3 * profileScore, 0, 1)
capacity        = species.min + effectiveScore * (species.max - species.min)
```

0.7／0.3 为首样可调工程参数。若缺少物种必需器官／功能，则该能力输出直接为 0，先于上述插值。外观用有限原创色板／纹样映射；人格输出为倾向，不强行覆盖已发展出的当前人格。

成对等位值以稳定性状顺序分组；受孕时按保存的链接组交叉计数产生一个母方和一个父方等位值。分组图只表达本游戏链接关系，不画成未经依据的真实人类染色体图。孕体保存双亲基因快照，因此怀孕后编辑父母不能悄悄改变已经承诺的孩子。

增加力量／吞吐需更多真实活动能量；保温毛皮减少冷负担却增加散热负担；提高储能只增加一个空的容量，填满需真实食物且有转换损耗；提高生育机会仍需更多真实孕育和照护。这些代价在消费者结算，不是 UI 放一个“平衡”标签。少量突变只在受孕时产生，使用 `BirthEventId + savedCounter` 的仿真随机源。首样每性状概率 0.001、最大改变量 50 都明确标为工程测试参数。突变不能改 species、器官类型、繁殖方式、高峰规则、高级意识或 Culture/Language 创始资格。

同物种跨亚种合法繁育；不同物种在受孕前拒绝。没有兔牛杂交、人与动物生物杂交、复制身体、分裂生人或免费死者重生。养育／收养和法律亲属关系可跨物种，绝不伪造生物父母。

### 5.3 亚种编辑、分化和灭绝

亚种可改名称、显示色、说明、共享特性、创始基因分布、包络内突变预算、可选数量策略。修改共享特性会影响所有现存成员的派生容量，因此必须在预览中列出确切成员集、冷热／路线／岗位变化和容量损失；同一提交原子更换共享 profile，不逐个异步改主体。

共享编辑不改各人的等位值；个体基因编辑不改全亚种。玩家可选择建立新的亚种分支，原主体转入新分支的来源和历史保留；不因此获得额外生命或新的实物。自动分化采用持续基因差异形成的有界候选，首个新 profile 复制原分支的表达规则，避免“重新分类一次就涨属性”。不采用被官方撤回的“出生数满了→亚种升级自动送 trait”。共享 profile 编辑还应预览未出生、已经预约到该亚种的孕体未来容量；等位值快照和受孕时保存的孕育工作／时限不被重抽。

`subspecies_population_limits` 是按 SubspeciesRef 指定的成员入场上限（默认空表），与世界／物种 Actor 配额一起约束新放置和新受孕；`subspecies_catalogue_limit` 只限制亚种定义条目数量，两者不混用。亚种数量限制是新放置／新受孕预约检查，**不是删掉超额成员**。孕期开始时预留后代容量；后来把上限调低不杀人、不抹蛋、不取消已经承诺的正常出生。共享亚种的基因池展示从实际成员采样聚合；零存活成员时标记消亡并保留谱系／档案，不删除 species 定义，不在载入时补种。

## 6. 真实冷热、饥饿、力量、睡眠与健康

### 6.1 容量不是状态

保存的量为绝对血量、既有伤势记录、非可回收维持能量、真实食物来源的生产能量、疲劳债、冷／热暴露债、饥饿债、疾病负担、孕育和商品 reserve。百分比只是显示。

- 提高健康容量不提高已有血量；降低容量时只向下截断超额血量，记录容量损失，之后再调高也不恢复这部分血量。
- 增加耐饿或储能容量不补能量、不清饥饿债。降低储能容量保留绝对 reserve 和明确超容量状态，后续按有界过程耗散，不形成可领取商品或退款。
- 增加耐寒不清暴露债、不去掉冻伤；改变的是后续暴露／恢复速率。加强力量不赠工具，不将货物瞬间运到目的地。
- 年龄以出生以来的仿真时间计；关闭衰老后果仍计日历年龄并正常达到成熟，但不累计关闭期间的衰老损害，重新开启不回放。遗传寿命以固定 species 包络内的潜力决定后续健康退化阈值／速率，已有生物衰老工作保持。改遗传寿命不将年龄改成 18，不复活已死主体，不清既有衰老／疾病损伤。改恢复性状需要真实时间和营养才能恢复。
- 当前人格编辑独立改变六轴偏好；不会被下次基因缓存重建无声恢复。人格发展记录保留，不在每次保存／载入重新抽取。

### 6.2 固定能量结算顺序

```text
真实食物吸收 → 能量入账 → 基础代谢 → 温度调节 → 移动／劳动
→ 有界健康后果 → 恢复与孕育／产品进度
```

食物只能来自真实可食批次；按食性、质量和营养计量转入吸收量，消耗源批次并产生一次收据。`dietary_flexibility` 只在物种许可食类内调整利用率，不能让牛吃矿石、鱼靠纸张生存或狼直接吃装饰草。

耐饿表示在同等真实缺能下更晚／更缓慢产生组织损伤，不是无食也能无限搬砖。能量不足导致劳动降速／暂停；关闭 `hunger_consequences` 只抑制直接饥饿伤害，不能赠卡路里、劳动或商品。筋力收益必须同时满足真实工具、任务工艺、荷重／净空、路径、疲劳、能量及合法身份。

越往上越冷由权威有效海拔决定，不由贴图、镜头或显示 LOD 决定。耐寒、物种毛皮、实际衣物覆盖／耐久／湿度、避风场所与耗能共同决定冷暴露。衣物缺失不是“立即死亡”开关，长期真实冷暴露可造成伤害；低地温和环境仍允许没有完整衣物的人继续生存。缺正装仍可上班、领薪、保留岗位，正装仅提高购买优先，不挤占基本生活预算。

`thermal_consequences` 与饥饿后果独立。关闭仍保存能量／疲劳／冷债，重新开启只结算当前新 tick 的有界后果，绝不回放关闭期间的累计死伤。环境仍只有 Light／Darkness 两个光照 age，无季节／自转／公转或真实天气灾变模型；暗处视力作用于人物 AI 感知，不让神光／圣树额外补能量。

### 6.3 感知、睡眠和疾病负担

感知以真实可达空间和局部视／听／嗅索引为输入。人格和遗传感知影响选择目标，但不能神奇知道地图另一侧仓库的私人信息；玩家上帝模式仍可查看全域权威信息，文明观察视图则尊重实际知识。

`pain_sensitivity` 将真实伤势变成主观痛觉警示和避险／寻求休息倾向，不消除断腿、伤口或物理劳动上限；痛觉低可少报警，但仍承担真实损伤。`sleep_requirement` 在物种固定上下限内决定每日需要的真实休息时长，与 Light/Darkness 独立；缺睡累积绝对 `sleep_debt`，影响注意、反应、学习和劳动。`rest_recovery_efficiency` 只改变真实安全休息对 sleep_debt 的恢复，另有 `fatigue_recovery` 处理实际身体疲劳，两者不重复消同一债。改这些基因不清已有睡眠／疲劳债，不重新完成半截睡眠。

休息／睡眠需要实际位置、安全条件和 SimTick，降低疲劳、支出基础维持能量；打开菜单、镜头离开、动画闲置都不算休息。是否只能在床上休息由场所能力决定；无住房者可以较差的真实露宿兜底，不能因没有楼而没有任何休息动作。

免疫／耐毒／寄生抵抗在有限的真实来源健康负担上有作用：受污或腐坏食物、实际伤口感染、实际寄生来源。每个负担保存来源、程度、后续损害与恢复；不会随机凭空刷一场瘟疫，不自动引入群体灾变或疾病武器。可适配有限的非随机接触传染：必须有已感染来源主体及真实接触／摄入事件，按实际剂量与物种敏感性增加有界负担，不能从镜头或日历随机生成感染。`infection_spread` 默认开启，只门控有真实来源的新增传播；关闭不抹已有病负担、伤口、免疫病程或真实营养，护理仍可继续；最初来源若由世界创建提供，必须明确预览并计来源预算，不作为隐蔽灾变。处理需要真实照料／用品／时间，隔离要实际阻断接触并提供食物／照料，清理尸体也要保留实际物损和劳动。首样不宣称完整临床病理或精确物理体温。


生理保存还必须包含权威 `body_wetness` 与 `next_physiology_tick`，与冷热消费者共用；暂停/载入不能免费变干或重排到期获得额外恢复。脂肪/糖储备是 `productive_energy_from_real_food` 内不重复计算的储能分区，不是另增一份能量源；扩大储能容量不填满分区。

## 7. 三层地表上的真实动物生态

### 7.1 装饰层不升级成食物层

既定地表仍是地皮＋纯装饰小植物＋机制树木。樱野深绿草、花甸热带花、湿地芦苇、荒原枯草、枫原红落叶都没有库存／采集任务／碰撞／导航成本。动物不能吃一个渲染实例并得到营养，也不能将装饰花朵颜色当作花蜜量。

为支持草食与授粉，增加**真实生态资源 reserve**，与装饰配方分离：

- `GroundResourceRef`（觅食子类又称 `ForagePatch`，不是第二份库存）在可生产地皮记录有限牧草／种子等觅食量、肥力、湿度、增长余量和预约；不是每棵草一个主体。道路、楼、施工接货区、矿场和不适合的地面不产牧草。
- 树的真实开花容量或耕种作物批次可有有限花蜜／花粉 reserve；装饰花不能替代。蜂的拜访按真实 bloom、时间、载量和消耗结算，授粉只改善后续有限结果／种子效率，不立即送果。
- 果树仍只由 `TreeRef` 的绝对果批库存提供果实；动物直接吃果也必须消耗同一个果批。采果预约、动物取食与砍树共享树 revision 和互斥许可。
- 炎地已死树不长果／不长新木，不进野生萌发和种苗池。死树神力放置木果为 0，世界初始残木必须来自已预览的有界 reserve；动物／蜂不从静态熔岩取得热量、肉、能源或新商品。

这些 reserve 属于实际生态生产，不改变“装饰小植物只是摆设”。清装饰只改装饰 mask；清真实觅食 reserve 是独立后果，需要预览现有动物口粮与物损。地表换主题影响未来资源生产生境，不回满当前储量，不偷偷把已有树换种或赠成熟果实。

### 7.2 动物活动与群体

动物行为包括真实觅食、饮食类选择、休息、温度避险、寻找巢／水域、有限探索、同物种交流、繁育、逃避／追猎、群体跟随和照顾后代。路径由同一地形／坡道／水域图验证，不用“动物能过去”颜色通道。

兽群、狼群、鸟巢和蜂群是有界真实成员索引，不是一个虚构动物或隐藏无限人口。蜜蜂按小规模游戏族群处理，每个存活蜂有稳定 ActorId，群落内生育角色固定于 species 定义；基因编辑不让任意工蜂忽然生出无限新蜂。画笔可以选择真实蜂个体，神光不会从蜂蜜计数临时捏一只新蜂。

生境从当前有效地形、支承、水深、温度、食物、栖身条件推导；主题只提供候选偏好。玩家把林地画成湿地不会把地上的兔改成鱼；突然变水需真实逃逸／困住／溺水／死亡判定。所有移动生命 Actor，包括人类、动物、启智动物、能飞的鹰和蜂，其身体扫掠体积不能进入高峰禁区；Plant 树木由真实冷热／生境限制，不因“不可通行”被直接删掉，但采收者同样无法上峰。高峰规则先于任何基因、衣物、训练和动物天性。

`animal_predation` 默认开启，只门控普通动物发起新的捕猎，不倒退已经形成的伤害、消耗或猎物尸体；高级意识者的暴力行为仍走民事／战争规则。捕食需要发现真实目标、接近／追击、实际攻击和消耗目标已有可回收储量，受路线与体力约束。死亡事件只发生一次；肉食者、猎人和清理工具不能分别得到一份完整尸体。高级意识主体按个人冲突／防卫／法律处理，不继续成为自动牧畜屠宰任务目标。

### 7.3 产出不从体型或放置产生

`bodyPresence` 用于碰撞、身体表现和移动成本；`harvestableReserve` 才是可处理成商品的实际量。成人体型不是免费肉量。

玩家放置动物可以获得一次有界、不可转成产品的初始维持能量，以避免刚放下便饿死；其肉／骨／皮／乳／羊毛／蛋／蜂蜜 reserve 均为 0。只有真实摄食或有记录的初始生态预算才可形成可回收 reserve。初始维持能量独立来源账户，可维持生命／调温／移动以及有限直接觅食以取得已有真实食物；不能转给新增生物产出／商品生产或孕育材料。出生也不能因采用成人模型直接授予成年肉量。

合法孕育用真实亲代营养分配到孕体／蛋；乳、毛、蛋和蜂蜜通过具体营养／工作转换缓慢形成有限 reserve。神光、改名、换主题、基因编辑、保存／载入和更换 LOD 不增长 reserve。普通死亡保留实际尸体，处理者经真实路径、权利、工具、时间和载量将可回收部分转成唯一 StockBatch，腐败／遗失记录明确。高级意识者死亡进入民事死亡档案及遗产流程，不作为牲畜处理。

牛奶／羊毛可以形成真实经济，但启智牛羊不能被强制作为拥有的产出机器；若其身体有可合法提供的产品，可以自愿参与有报酬合同，使用同一真实 reserve，不因“Person”标签关闭身体原有功能，也不在合同签订时凭空增产。

## 8. 合法繁育、孕期、蛋和后代

### 8.1 受孕必须先满足依赖

同物种、亲代存活、固定生理成熟、真实生殖健康、真实营养、当前繁育规则、实际接触、巢／孕母支承与有界后代容纳预约都满足后，才能建立受孕记录。高级意识亲代还遵守自愿关系与该民事体系的有效规则；普通动物不被伪装成人类婚姻，但其生物双亲同样保存。

人类新受孕查 `civ_reproduction`；普通动物查 `animal_reproduction`；高级意识动物查两者。**关闭只禁止新配对／受孕，已经承诺的孕体和蛋继续正常到期**，不能冻结母体吃饭、衰老和生育的因果关系，也不会开关一次瞬间补出一批欠生人口。界面写“允许新繁育”，清楚说明已在孕育中的后代继续。

受孕时固定：BirthEventId、父母、基因快照、后代预测意识、孕体营养 reserve、孕期／孵化剩余工作、位置／巢依赖和数量预约。生育能力基因只改变合法受孕与进度参数，不保证无营养、无位置、无亲代也能出生。

### 8.2 蛋不是两种可复制资产

未受精的食用蛋与有孕体的活蛋分开；活蛋是一份有唯一身份和 reserve 的孕育记录。吃掉／损毁则失去孕体并记录损失，不能吃一份食物又孵出一个动物。巢淹没、母体死亡、载体搬迁或捕食需明确结算已分配营养：可存活的既有蛋可以继续，条件不成立则发生有来源的损失，绝不自动替换成一份完整蛋或一只新动物。

新生后代均年龄 0，身体为 species 成人规格，营养能力和成年／照护行为依年龄与成熟而变。死亡／繁育过程不由生长动画决定；动画暂停不会冻结孕期；存档暂停保存余量且不靠墙钟补生。

## 9. 文明之光：升级已有生命，接入完整社会

### 9.1 简便画笔与权威效果

全局画笔位于底栏生命／文明工具分区；名称中英德为“文明之光 / Light of Civilization / Licht der Zivilisation”。玩家选择范围，地面出现洁净暖白金色投影，确认后天空降下一束有柔边的圣光。光束只表现一次已提交的事件，粒子数量、曝光、相机、阴影品质不决定启智名单。

文明之光依据玩家能力和通用工具权限使用，进入受限元控制时再检查 `restrict_god_tools_during_metacontrol`；不增设名为 civilization_light 的独立 World Law。预览由真实空间索引选出范围内活着、尚未启智的动物 ActorIds；封闭不透明室内容器被排除并说明，可先真正移动到露天。正常水中动物也可被神光触及，不需改变水深／呼吸规则。不会穿过多个主体时额外生成“光之动物”，不会让树／花／尸体成为新个人。高峰内不允许放生命，当然也不能借这支笔刷绕过放置限制。

提交要重验世界、会话、草稿代、主体 revision、位置／容器、规则、牲畜产权和预约。晚到结果、已死主体、已搬走动物、玩家取消都不能只执行半份启智。相同 CommandId 重试仅返回原收据，不再授任何收益。

### 9.2 一次事务的效果和保留

```text
现有 Animal ActorId
→ set sapient + attach civil-person facet
→ revoke livestock title and invalid livestock-processing jobs
→ preserve actual owned / held / third-party goods
→ revalidate animal routines and real civil task eligibility
→ initialize empty formal language and culture skills
→ append AwakenEvent with exact actor IDs and origin
```

保持：身体、species、subspecies、基因、年龄、双亲、孕体快照、伤势、能量、疲劳、寒热债、疾病负担、位置、真实货物。**不赠**国籍、国家、公司、工资、工作、技能、科技、宗教、先知、正式姓名、文化实体或语言实体。

被照到的成年动物立即具高级认知和该物种成年资格；新生／未成熟动物不会被改成年。它们可以先像原始人一样协作、住居、耕作、采果、搬运、组成前文化聚落和公国；能力取决于真实器官与场所，而不是“动物文明低一级”的制度限制。

### 9.3 文化、语言与高级能力的唯一差异

新 Culture / Language 实体的创始资格仅 Human：Primary Genesis、Secondary Culture Genesis、独立 Language 分化都要有实际合格人类创始主体。高级意识动物可以参与共同生活，却不能用一群动物的生成场临界值自动创建新文化／新 root Language，也不能长期独立演化出一个新的 LanguageId。

通过真实接触、学习和教学，它们能掌握人类已有语言并加入已有文化。名称、文化强度和语言熟练度使用同一真实规则；UI 中文／英文／德文不是模拟语言。它们可保存／传播既有文化、教已有语言、研发现有体系允许的知识、信教、参与法律、拥有财产、成立企业、担任领导和继承职位。除文化／语言创始资格外，不另设“人类专属的大学、王位、公司或知识”门槛。

语言技能是共同符号／语义能力，表达使用该物种原有声／姿态／信号通道，采用原创表达表现；不会把兔的嘴变成人的声带。无手个体不能在没有器材时做需要手指的实际工艺，但可口述、使用合适的真实辅助器具或与实际伙伴协作。任务合法性检查功能，不以物种名称直接禁止社会职务；设备也需真实建造和采购，不能在启智瞬间免费出现。

一个从未遇见人类的纯启智动物群可以长期有前文化社会，却不会自行生成 CultureId/LanguageId；已学习群体隔离后可以继续传承现存文化语言，但不自动创建新分支实体。这个限制是用户要求的游戏世界规则，不伪装成自然科学结论。

## 10. 统一信息页、比较与编辑

地图点动物打开主体页，页内 Species → 只读物种页，Subspecies → 可编辑亚种页，双亲 → 族谱，当前群体 → 群体页，财产／住居／国家／文化／语言 → 各相应页；个人页与普通动物页共享生命事实区。启智后页不会突然换 ID，原动物历史仍可点击。

基因页清楚区分父母等位值、共享亚种特性、当前派生能力、实际生理状态；编辑耐寒时可看到当前环境、衣物保温、能量与暴露后果。物种不可改的区域为明确只读信息，无假按钮。查看“力量大”可进入载重、工具、可接受任务、真实路径的原因；查看“饥饿”可进入实际缺食批次和最近消耗。

特性笔刷与单个基因编辑使用同一 typed 命令。批量工具先列实际选中集合、能力变化、岗位／路线失效与容量损失，再一次提交；不得点击一次连续丢多个无预览事务。生物比较遵守同一量纲，区分裸载容量与当前实际表现，不能把不同 species 的同名归一化值冒充科学排名。

所有全局功能入口在底栏；对象页只保留当前对象关系／编辑／关闭。简体中文、英文、德文标签完整；按钮无边框／outline／ring，焦点靠色和亮度可见；不用装饰性小字、杂乱图标或神圣口号。必要后果和错误可清楚显示，无须为极简藏掉死亡、物损或不可编辑原因。

## 11. 新工程域、保存与性能边界

生命子域分为固定 `SpeciesRegistry`、可变 `SubspeciesIndex`、`GeneticsService`、`PhenotypeCache`、`NeedsAndHealth`、`BreedingScheduler`、`AnimalBehavior`、`EcologyStock`、`UpliftPolicy`。不是新建一套旁路 World：读同一 Actor、空间、库存、规则、事务和历史。

`PhenotypeCapacities` 统一导出 `agility`（物种包络内无量纲控制容量系数）、`fatigue_recovery`（species 固定每 SimTick 疲劳债恢复基准的有界倍率）；`strength` 性状只映射为 `maximum_supported_load`（游戏 kg 支承载荷），不让导航／冷热／岗位消费者另读 allele 重算力量。恢复导出是潜力速率，实际减债仍需真实安全休息、时间及代谢能量，不因 gene edit 清债。

`PhenotypeCapacities` 带 speciesVersion / subspeciesRevision / genomeRevision / equipmentRevision / physiologyRevision；运动、冷暴露、岗位、生育和渲染读同一版本，不分别重复计算不一致能力。缓存无权回填血量、年龄、食物或高级意识。普通移动不重新生成基因；固定 profile 更新可标记相关成员缓存过期，但新 world root 发布前全部对外读取须一致。

大范围共享亚种编辑先在隔离候选中分片准备容量和后果，预算不足时显示需缩小范围／继续准备，不允许将一半成员先发布。成员集合和因果 revision 在最后提交重验；期间世界继续变化导致 stale 必须重新预览。没有以“分片”取消单写者原子提交。

动物索引按空间与行为类别查询，群体邻域有有限候选；每个行为 tick 不扫描全地图。基因池／人口图低频聚合，亚种分化候选有界；果批、牧草、病负担、孕期和 product reserve 用事件／有限工作余量，不给每粒花粉或每片草创建实体。蜂群成员数量必须有实际预算，不能以蜂巢“代表无限蜂”偷偷越过实体约束。

保存：Actor 身份／来源／年龄／死亡档案、物种内容版本、亚种与谱系、完整等位值、受孕双亲快照、高级意识来源和继承、绝对健康／能量／债／疾病、孕体和蛋、食物和畜产 reserve、群体真实成员、全部预约／任务／规则、仿真计数器、文化／语言技能与创始资格。重建：像素 mesh LOD、光束、声音代理、基因可视图和动画。保存／载入不是复活、补食、剪毛冷却重置或基因重抽。

## 12. 贯穿验收：必须看到结果，而不是仅看到字段

|场景|必须成立|
|---|---|
|兔／牛基因与亚种拉满或拉低|仍保留物种裸载速度／载重顺序；物种字段不可编辑|
|伤者提高健康、耐寒、耐饿|不回血、不加能量、不清既有伤势和寒债；只改变容量／后续速率|
|父母孕后改基因／启智|既有孕体基因与意识快照保持；下一次受孕读取新状态|
|纯启智动物独居多代|不生成文化／语言；真实人类教学后可学习、传播、科研、从政|
|一只老牛被照光，携货且已怀孕|ID／年龄／伤势／货物／孕体连续，牲畜产权撤销，无新人口、补偿或第二份货|
|新放动物立即屠宰／挤奶／剪毛|产出 reserve 为 0，初始维持能量不能转换商品|
|牧草／花蜜／果实被多消费者取用|同一绝对 reserve 不超取，不从装饰草花取食，不重复结算|
|最高耐寒、攀越或飞行进入峰禁区|导航／放置／神力搬运全部拒绝，不靠 trait 绕过|
|山坡改海、移除坡道、摧毁巢|同一事务给出路断、实际逃逸／受困、孕体和物损后果；不靠视觉完成|
|繁育关掉时已有蛋到期|蛋正常继续，禁止新受孕；没有冻结生命、无补生、无吃蛋同时孵化|
|免饥饿／免冷热后果切换|不赠真实能量，不免费劳动，重新开不回放历史损伤突发|
|暂停／换镜头／保存载入|基因、reserve、冷债、孕期余量和结果同 tick 连续，无补动物或重抽|
|同 CommandId 重试，旧草稿晚到，取消共享编辑|幂等／拒绝／原世界保持；无部分成员生效|
|交通目录检查|没有私家马、马槽、MountAsset、骑乘／骑兵／马驱动力生产入口|

这些是未来实现的行为验收合同。本轮只验证规格与跨域一致性，不将 JSON 存在、图表漂亮或旧 headless 验收称为动物／遗传／启智已经实现。
