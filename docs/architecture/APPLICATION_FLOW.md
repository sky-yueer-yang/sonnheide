# 应用启动、主页面、创建世界与可靠返回

2026-10-07。本文是创建世界和可靠交接的生产合同。当前原生主菜单、三语设置、窗口/输入/字体与GPU主页面已经接入；创建World、原生地图、完整IME与生产存载/断电恢复仍未实现。本轮只修订合同，不启动地理数据工程。最新顺序见 [ADR 0007](../decisions/0007-foundation-experience-first.md)和 [施工计划](../planning/IMPLEMENTATION_PLAN.md)：阶段 0 主菜单与应用，阶段 1 创建与真实岸线平面初始地表，阶段 2 基础游戏界面及存载返回；通过后阶段 3 才开始新的建筑、统一成人角色和服装作者源及建设工程。地表按[ADR 0010](../decisions/0010-flat-land-and-coastal-transition.md)，取消真实高程输入，保留全球真实海陆/岸线、统一陆台和狭窄沿海过渡。视觉与两种环境遵循[ADR 0008](../decisions/0008-sacred-interface-and-light-ages.md)，不引入太阳昼夜循环；唯一发行渠道是Steam。

## 1. 最先闭合的四个因果边界

**菜单不假定已有世界。** 世界创建之前只有应用偏好、地理来源元数据和创建草稿。没有 Person/State/City/World 的 EntityRef，没有可提交的世界工具，也不拿浏览器示例人物填初始世界。进入新世界时文明对象为空；放人和建设在后续接入。

**预览与最终海陆/表面必须来自同一合同。** 预览可以用低LOD；选区最终生成必须读取齐全且固定版本的真实海陆/岸线源，以同一水平投影、地图比例和版本化陆台/海岸profile形成可校验的天然mask与派生表面。普通陆台统一略高于固定海平面；只有岸边窄带下降并没入海中，不导入现实山脉、高程或水深。低LOD不证明窄海峡或临水建址边界准确。未知海陆、覆盖/halo不足、岸线拓扑或投影非法、预算过量时，在进入世界前解释并拒绝；平坦不等于可以伪造源缺口。profile从天然岸线冻结生成，填海和水波不触发天然面重算。

**新世界的成功不以先破坏旧世界为代价。** 新建和加载先在私有候选区验证，不接受领域命令和仿真调度。旧世界保留至候选全验、必要内容准备和持久化门槛通过。失败/取消回到来源页面或旧世界，原存档不改。应用只在交接时发布一个活动 World；私有候选不是第二套生产领域事实。

**同一世界重载也必须撤掉旧会话。** worldId 是存档中稳定身份；SessionGeneration 是每次进入时的新会话标识。旧查询、GPU 回读、保存通知、表单和内容加载结果即使 worldId 相同，也不能投到新会话。创建预览另外绑定 DraftGeneration，编辑选区后旧预算/地图预览自动失效。

## 2. 最少有效状态与允许操作

`WorldSetup` 是创建草稿；`PreparingWorld` 同时覆盖 New/Load 两类带类型作业，避免另建一套加载状态机。设置、存档列表和确认框是覆盖窗口，不各造一个模拟世界。

|状态|可见与允许操作|进入/离开条件|
|---|---|---|
|Boot|应用启动画面、字体/固定内容清单检查、最近存档索引；不生成 World|基本 UI 能工作便进 MainMenu；致命运行依赖缺失给可读原因与退出，不无限 loading|
|MainMenu|新建世界、继续、加载、设置、退出；无地图工具栏|新建→WorldSetup；继续/选定加载→PreparingWorld(Load)；设置返回同菜单|
|WorldSetup|世界名、海陆/岸线GeoPack、合法区域、陆台/岸线预览、水平尺度/预算、返回、创建|只生成草稿；全前置通过才允许创建→PreparingWorld(New)|
|PreparingWorld|分阶段进度、具体错误、取消；旧世界若存在则冻结保留|候选验证和内容准备；New 另要求首 checkpoint durable；成功才交接 InWorld，失败返回来源或 LoadFailure|
|InWorld|地图、镜头、底部七组栏、真实接入工具、对象窗口、保存/返回/设置|操作绑定活动会话；返菜单或切世界先解决未保存表单/世界，再进入 Returning 或 WorldSetup|
|Returning|按玩家选项保存、释放订阅和 GPU/世界会话；明确进度|保存失败仍留 InWorld 可重试；完成才 MainMenu；不显示已返回却仍接旧命令|
|LoadFailure|选定存档/版本、缺包或不兼容/损坏主因；重试、明确选择恢复代、返回|不改文件；旧世界存在则可直接恢复；没有旧世界则回 MainMenu/存档列表|

主链：`Boot → MainMenu → WorldSetup → PreparingWorld(New) → InWorld → Returning → MainMenu`。载入链：`MainMenu → PreparingWorld(Load) → InWorld / LoadFailure`。创建或加载失败保留一个确定的来源页面，不以递归弹窗或空地图伪装成功。应用状态与仿真暂停分开：创建/加载覆盖旧世界时暂停其推进，取消恢复先前暂停/速度设置，不补算这段真实等待时间。

## 3. 主页面与三语设置

主页面只围绕开始、恢复和设置；使用用户提供油画、原创UI构图和英汉德消息 key，不放 40 类对象目录。小中央亮焦点/大部分渐暗、极慢微移和逐幅交叠按ADR 0008；最新布局按[ADR 0009](../decisions/0009-monumental-minimal-interface.md)：Sonnreich原创Logo品牌中心左上向内，完整多圈内环/无射线环带/2—3道边外圈/仅从外圈发出的密集长短粗细射线，远端可越屏，整组以该中心共用固定轻微顺时针倾角，柔光静止；SONNHEIDE右移、主页字体较上一轮略小，右下菜单保持紧凑行距，保持右对齐、纯文字、无图标/边框且点击区域不重叠；主页文字/射线/光晕统一#fff6df、亮而有静态柔光，无按钮ring。整体是纪念性极简的新古典/金色/未来感艺术网站构图，禁止不必要小字。画作换页不生成World、不驱动环境Age，仅小中央焦点保留原画亮部/颜色/笔触，周围大部分平滑渐暗，不随World相位变化；Logo/钟盘/柔光不持续转动。画作decode/上传失败保留旧画或静态暗底，不阻塞操作。主操作按固定顺序：**新建世界、继续、加载世界、设置、退出**。继续对应上次完整保存记录；摘要按需进入存档窗口展示，不在主页面常驻细碎小字，无记录在操作时给正常字号原因。读取索引仅用于摘要，点击后仍完整加载校验。

全路径按钮无边框，文字按钮不强制附图标；主菜单明确不用图标。其他密集工具仅在图标解释功能时使用，并保留三语tooltip/accessible name，不能用图标装饰“神圣”。键盘focus以文字/背景明暗与字重可见，禁止outline/ring充当边框。禁止不必要小字；危险确认和必要错误保留完整后果，使用正常可读字号。降低动态可关闭油画持续移动和自动切换。此规则适用创建/载入/设置/错误/返回弹窗。

设置包含 English / 中文 / Deutsch、音量、画质/分辨率及输入；先接入的设置明确列出，未接入项禁用说明。切 UI locale 当场重排菜单、标签和错误，不刷新世界、不改仿真 Language。默认值不创建新的 Country/Language。创建名/存档名支持中文输入与德语字符；原生 IME、字体 fallback、DPI 和长德语仍需真实设备验证。

游戏内“返回主页面”从底部设置组打开应用窗口；世界七组工具栏保持 [UI_ARCHITECTURE](UI_ARCHITECTURE.md) 的地图中心结构。主页面和创建页有自己的局部继续/返回按钮，尚未进入世界时不展示可执行世界栏。退出菜单无需世界保存；在世界内退出使用和返回同一未保存处理，操作最终返回退出回执后再关闭。

## 4. 创建世界：少量参数，真实约束看得懂

### 4.1 首屏结构

左/上方是固定海陆/岸线来源包和地区选择，中间是可平移缩放的地理预览，旁边显示选区摘要，底部是“返回”与“创建世界”。常用参数只有名称、来源包、区域和一个水平地图比例预设；陆台离水面高度和窄海岸过渡是统一版本化规则，不增加玩家高程导入或地形高度调节。技术细节可展开，但阻止创建的主因必须在首屏看见。

|字段/摘要|行为与证据|
|---|---|
|世界名称|玩家文字，不作为 World ID；长度/字符范围可读校验，默认建议可改|
|固定海陆/岸线GeoPack|显示数据名/版本、合法覆盖范围、离线就绪、岸线分辨率/拓扑限制和许可来源；不存在的全球包不作为可用选项；不要求ETOPO/DEM/DTM|
|选区|地图框选/具名已准入地区；仅在 pack 完整覆盖与投影有效域内，显示真实 km 宽高/陆地覆盖|
|水平worldScale|用于X/Z地理投影与地图距离；默认与有限合法预设由岸线分辨率、可玩尺寸和预算决定。Y来自统一陆台/海岸规则，没有真实高程缩放；人物、建筑与表面仍使用一致的场景单位|
|分辨率/格预算|显示岸线源分辨率、输出逻辑格/地表预算、小岛/窄海峡拓扑损失风险和投影误差；创建峰值计入旧世界+候选+最低GPU资源，超预算给减小范围/改有效预设的选择|
|最终初始状态|明确“没有人物、国家、城市和建筑”；自然地表不是玩家事后可刷改的层|

选区须含可进入的合法陆地，不能把全水或源缺失选区当可生活地图。首个基础验收选区含陆海，另验证小岛、窄海峡和湖岸；来源分辨率不能表达的边界须披露或拒绝，不能靠海岸过渡吞掉窄岛。创建界面只允许现有pack确定的数据，不运行时临时联网补源。25×25阿尔卑斯ETOPO窗口仅历史研究，不是海陆/岸线GeoPack，也不再是创建前置。

### 4.2 冻结与误差

发布之前可修改选择和水平地图比例；每次修改递增DraftGeneration并重做对应预览/预算/校验。确认时把GeoSourceManifest、海陆/岸线源及配方hash、WGS84 selection、水平投影、cellSize、水平worldScale、固定海平面/陆台高度、海岸profile及算法版本、天然mask与派生表面摘要写入创建记录；不保存现实正高、垂直datum或DEM高度缩放。发布后这些天然事实冻结；镜头缩放只是view state，不能再次改变地图比例或陆台/海岸形状。填海只改变工程层，不重算天然海岸面。

必须按[WORLD](WORLD.md)和[ADR 0010](../decisions/0010-flat-land-and-coastal-transition.md)验证岸线、未知海陆、日期线/极区、水平投影有效域、岛屿/孔洞与跨块一致性；ADR 0003的真实高程/垂直datum/DTM前置已被覆盖，其人车接入保护仍保留。海岸过渡计算取得选区之外足够halo，裁切框不当海岸，湖岸默认使用同一水边过渡。阶段1从完整已核验真实区域开始，阶段9才完成完整全球可选覆盖。细于源分辨率的网格只是采样，不能宣传新增岸线精度。

### 4.3 明确的空世界

`CreateEarthWorld` 发布零人物、零国家、零城市、零企业、零建筑、零建设任务、零人物货物的初始 World；世界时间/规则采用可追溯的固定初始配置。环境默认Age of Light、手动、自动关闭，Light/Darkness时长调参初值各30游戏日，计时/元数据见[LIGHT_AGES](LIGHT_AGES.md)。这不是科技时代；日历日/月/年、人物年龄与工期仍用原SimTick/TimeConfig，不因删除天文昼夜而删除日长。不得为了底栏有内容赠送创始人、工人、城市广场或样例国家。自然植物/矿源若后续引入，来自另行固定的资源合同，不混入免费文明物资；阶段 0—2 不要求接入其领域生成。只有玩家亲自放置 18 岁人物或合法出生 0 岁人物才能增加人口，接入安排在后续生活阶段。

新建在私有候选阶段分配一次新的稳定 worldId，两个同地区、同参数的新世界也不共用身份；预览不分配生产实体引用。加载保留存档原 worldId，依靠每次新 SessionGeneration 区分运行会话。模拟seed若保留，只决定后续允许的确定性过程，不改变固定天然海陆、岸线或陆台/海岸profile，不生成现实人口或国界。

## 5. 创建与加载的安全交接

下面是因果顺序，不要求每一步增加线程或库；文件持久化实现在 [PERSISTENCE](PERSISTENCE.md) 中落实。

1. **预检。** 保留活动世界及其会话；解决未提交表单和未保存世界的选择，记录来源页面/暂停状态。生成独立 jobId 和 candidate token，后台只读固定来源。
2. **准备。** New 从已准入地理创建冻结自然层与空 World；Load 从选定不可变 checkpoint 读取。源/格式/大小/依赖/ID/领域不变量完整校验，不把列表摘要当通过。
3. **最低内容就绪。** 准备初始可见真实地表和 UI 必需资源。不能在新世界已发布后才发现没有可画地面；不预载全部未来建筑角色。准入预算包含旧会话、私有候选和最低 GPU 资源的交接峰值，不能只报新世界稳态内存。超预算有明确失败，不先释放旧 World 强求成功；内容来源包保持固定版本和有效引用到使用者退出。
4. **持久化门槛。** New 写同目录临时文件/受限区块、校验、flush+平台 durability、原子发布首 checkpoint。Load 不覆盖来源档；需要格式迁移时先产生新的派生版本，保留原件，明确提示迁移结果。具体平台 fsync/replace 尚未实现，不把现有 stream flush 当断电保证。
5. **单次发布。** 确认 token 未取消且候选仍符合输入版本，撤旧订阅，分配新 SessionGeneration，一次替换活动根/只读快照/视图会话。随后才开放世界工具和仿真；Continue 指针最后指向完整 checkpoint。旧资源按 worker/GPU fence 安全释放。
6. **反馈。** InWorld 显示真正已进入的世界名/地区和零文明状态；设置初始合理相机，不把低 LOD 预览纹理充作唯一地面。保存/继续索引发布失败单列报告，旧指针保留；不得称失败保存已成功。

阶段1因此必须实现最小首checkpoint writer、元数据的持久化/原子发布和回读校验，作为首次进入真实岸线平面空世界的前置。阶段2在此之上完成玩家保存、加载/继续、返回、恢复代和重复往返；不能把首保存也推到阶段2，再让阶段1等待尚不存在的门槛。水体阶段1可用受限静态mean-water pass先验证固定游戏海平面/湖面、天然mask、派生海岸及水下深度与地表遮挡；只声称真实海陆/岸线，不声称真实海拔、湖面海拔或海底测深。必须标明静态，不能声称固定Abyssal已原生移植。阶段3接固定Abyssal波谱/FFT并与CPU对照，泡沫/折射/水下及完整后端规模后续收口；不另加替代动态水算法。

取消仅在发布前可接受；接受后 token 作废，后台晚结果被丢弃，临时文件可清理。发布不可分割：完成后按钮明确变为“返回主页面”，不再叫“取消创建”。已生成但未进入的孤立 checkpoint 不成为 Continue 目标；可在存档列表中明确作为未打开的有效记录或清理，不覆盖其他世界。候选失败和图形内容失败不改变旧 World、旧 checkpoint 或原始来源包。

## 6. 保存、继续、加载与返回

**保存读取完整已提交 revision。** 保存动作不替玩家提交字段草稿，不把未批准法规或视图数据写成领域事实。写入成功后才标“已保存”，进度的阶段名不冒充 durable。存档保存 `worldId`、地理/定义/pack 证据及核心 revision；profile 单独按世界保存镜头、窗口和收藏。UI locale/音量/键位是全局应用偏好，不成为 World 的仿真 Language。

**继续只指向完整记录。** 初始创建保存和后续保存均以不可变 checkpoint 代或原子替换保留上代；最近记录索引最后发布。坏索引、断电临时文件不能把半个存档变成 Continue 目标。继续加载最新成功记录；失败列出主因及可选上代，不默默回滚几小时、不换成示例世界。

**加载不触发人口或时间补偿。** 同 worldId 保留原有稳定实体 ID，重新进入更换 SessionGeneration。加载不自动离线演算、不赠工人/粮衣、不更改冻结地表；缺固定 pack 明确指出包/版本，允许返回或安装被允许的精确包后重试。核心 checksum、受限解压、迁移与领域验证都由生产持久化层负责。

**环境自动余量属于World。** checkpoint保存当前Light/Darkness、自动模式、两种有界duration、实际环境进入tick、独立自动计时锚点/deadline/generation；载入不从墙钟推断、不重新赠送完整时段、不重复注册到期任务。手动切换原子关闭自动；开启/编辑时长才明确重新计满。旧无环境段档生成带迁移报告的Light/manual派生版本，不重解释TimeConfig/年龄或伪补历史灯光；新schema损坏拒载。详情按LIGHT_AGES，同World重载也拒旧环境与图形回调。

**返回先处理两种未保存。** 对象 editDraft 和已提交 World 未保存是两件事：有草稿时提供继续编辑或明确丢弃；有 World 差异时默认“保存并返回”，另有明确“不保存返回”和取消。联合对话可减少操作，但文案必须说明保存 World 不会提交草稿。联合离开意图中的丢弃在成功离开时才执行，不能先删草稿再发现保存失败；失败停留 InWorld、保留草稿/世界并可重试。成功返回后撤订阅/工具/窗口引用，释放会话，主菜单不运行旧仿真。进入或返回期间禁重复触发，但保持进度和可取消边界可见。

视图存储失败不能逆改核心 checkpoint；告诉玩家世界已保存、视图偏好未保存，并提供重试/明确继续。profile 损坏可恢复默认镜头/窗口，不能因此重置人物、天然层或法规。首次空世界虽无对象草稿，仍建立这套离开协议，后续编辑不重新发明切换行为。

## 7. 异步结果与输入隔离

|结果类型|必须绑定|不匹配时|
|---|---|---|
|地理预览/预算|jobId、DraftGeneration、海陆/岸线GeoPack hash、selection/水平scale/profile hash|丢弃；当前创建按钮继续等待当前结果|
|世界准备/迁移|candidate token、源/格式版本、来源文件代|丢弃；不替换活动根或继续指针|
|查询/寻路/统计|worldId、SessionGeneration、sourceRevision 与查询 generation|丢弃或重新请求；不可投进新世界|
|GPU 拾取/内容完成|会话 generation、frame/camera/snapshot、资源 generation|复核/重采；绝不直接领域提交|
|保存/通知|世界与会话、请求 ID、目标 revision/checkpoint 代|可更新该世界保存记录，不向当前其他世界显示成功或覆盖其dirty状态|

模态创建/加载/返回窗口取得焦点，地图拾取和世界快捷键暂停；文本组合输入优先。Esc 按 IME→顶层弹窗→地图笔划的顺序处理，未保存草稿确认不静默丢失。固定七组栏仍在 InWorld 底部；只显示工具意图不等于生产接入。初期人口/建设/国家/法规项未接入时明确说明，不能点击生成 fixture 或返回假的成功回执。
