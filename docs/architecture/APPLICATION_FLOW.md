# 主页面、双路径创建与可靠世界交接

2026-10-08。当前合同按[ADR0012](../decisions/0012-editable-3d-pixel-world.md)。已实现的原生油画菜单、三语设置、旧Earth导航/PBR候选/空档发布是可复用旧基线；空白创建、新像素/高度候选、完整主动存载与新规则迁移尚待实现。详见[新版计划](../planning/IMPLEMENTATION_PLAN.md)。

## 1. 应用与世界各自有状态

|状态|允许动作|离开条件|
|---|---|---|
|Boot|核固定运行内容/字体与存档索引|UI可用→MainMenu；错误给主因/退出|
|MainMenu|新建、继续、载入、设置、退出|无World引用/工具；新建→WorldSetup|
|WorldSetup|Blank/Earth二选一、名称/尺寸/profile/seed，返回|只读草稿；参数完整→PreparingWorld(New)|
|PreparingWorld|候选生成/读取/验证/资源准备/首档，进度/取消|成功才替活动世界；失败保原世界/文件|
|InWorld|真3D地图、底部八组、当前可用工具、typed对象窗|保存/返回/切世界先处理脏草稿与未保存事实|
|Returning|按选项保存并释放会话|保存失败留原世界；成功才回菜单/退出|
|LoadFailure|损坏/缺包/不兼容主因，重试/恢复代/返回|不改原档；不以空图假装恢复成功|

旧活动World在准备期间冻结保留，取消恢复原暂停/速度，绝不补墙钟时间。`WorldId`稳定，`SessionGeneration`每次进入新建；`DraftGeneration`每次草案改变。查询、GPU结果、保存通知和表单必须匹配三者适用域，相同WorldId重载也不能接旧session结果。

## 2. 主菜单与设置

保留批准油画/Logo/静态仪表光环、SONNHEIDE与右下右对齐纯文字菜单；禁止多余小字、边框和无意义icon。色/行距/移动/降低动态按[视觉合同](VISUAL_STYLE.md)，不因世界转像素而改用户已经认可的艺术主页。菜单绘画不创建World、不消费模拟RNG、不跟环境Age。

继续读取最近完整记录，索引仅作选择摘要，实际载入仍完整核验。旧规则存档注明旧版，普通继续不自动转像素；可选“复制转换”单独进入迁移候选，不能把未知schema当新地图。菜单无存档时给正常禁用原因。

全应用English/简体中文/Deutsch，key/错误/参数一致，设置变locale保持草稿/世界；模拟Language不变。字体字形、中文IME、ÄÖÜß、长德语、DPI/窄窗及键盘焦点需实机验证。所有按钮无border/outline/ring，焦点以字重/亮度/实心底可見。

## 3. 新建第一屏

两个纯文字无框选项：空白地图、真实世界选区，说明只在需要理解时出现。Blank提供全海/全平陆内域、尺寸/profile、名称/seed；Earth提供全球浏览/选区/唯一水平比例，然后转最终像素预览。隐藏技术细节不能隐藏缺包、超预算、量化丢失和非法选区主因。

Blank不依赖地理资源，没有联网/地理包阻塞；两个预设都0人0楼，不随机生成国家/工人或现实城市。全平陆边缘如何变海在预览准确显示。Earth只导入固定海陆、岛/湖，真实高程关闭；可选风格化高地必须明示，默认平陆与三水深派生不冒称DEM。

全球浏览可渐进矢量LOD，不代表游戏最终像素精度。选区生成后，最高预览使用与游戏同一TerrainProfile/量化数据、地形/水体/天空、材质、seed与GPU路径；可从360°检查高差、岸线和台阶。不用光滑矢量/卫星照片/PBR旧画面作为pixel最高预览。

## 4. 发布门槛

参数/预算→固定来源与转换→生成隔离TerrainWorld→水域/空间/定义验证→渲染资源就绪→最高预览descriptor校验→首checkpoint持久写并读回→一次发布。失败任何阶段保持原World/继续指针，不先删旧世界、显示假成功或赠补默认资源。个人存档不用于测试fixture。

PreviewDescriptor冻结来源、scale/profile、量化/边缘算法与seed、初始height/material/biome/water hash、画质及资源recipe。创建提交校验相同descriptor；草案更改使旧预算与GPU结果过期。不把“每次生成随机结果再看一遍”当同路径。

异步线程只读取候选页并返回带generation结果，发布单写者处理。取消有界退出，候选GPU资源延后安全退役，已发结果丢弃；不留半档/锁/重复world。首档失败恢复入口可重试，原档和继续指针各自在其原状态。

## 5. 完整保存、返回与载入

InWorld底部世界组打开保存/载入/返回窗口。未提交terrain stroke可取消/保草稿但不成为World事实；对象编辑表单需明确保留/丢弃，不能靠换locale或回菜单默默清空。保存只取一致已提交revision；载入新版pixel包必须含有效terrain edits，不从Earth源重建覆盖。

主动保存/自动保存与返回共享持久化流程；失败显示重试/另存/明确不保存退出，不把用户锁死或假称已保存。载入候选完整核验坏档/缺定义/关系/货物/损坏状态，再交接。损坏建筑或受困人物是合法已提交状态，不能为了“完整接入”在载入时免费修好。

## 6. 验收

Blank全海/平陆、Earth全水/全陆/群岛/湖/日期线/极区；360°最高预览与最终同hash/同像素风；0人0楼；无源/坏包/预算/首档写失败保旧；取消/晚结果/反复创建无残留；同World重载session隔离；三语/IME/键盘无框焦点；Godterrain后保存/返回/载入有效地形与已发生损失相同；旧档复制转换保原件。完整生产存载门槛通过后，按计划开始正式人/楼/服装制作。
