# SONNHEIDE 视觉合同

2026-10-07。用户最新要求由[ADR 0009](../decisions/0009-monumental-minimal-interface.md)覆盖此前按钮必须带icon的规定。[ADR 0008](../decisions/0008-sacred-interface-and-light-ages.md)的油画与光暗规则继续生效。浏览器页面是可审阅设计与交互原型；原生客户端仍按阶段0—2实现。

## 1. 减法是硬约束

**绝对不添加无必要的小字。** 不加装饰口号、副标题、英文眉题、画注、序号、页脚、版本碎片、计时器或重复的操作提示。每段可见文字必须回答正在进行的操作需要知道的内容；“营造气氛”不是增加说明文字的理由。主页面只保留品牌、SONNHEIDE标题和主要菜单。工程接入状态放入实际打开的关于/创建/载入窗口；真实错误、编辑后果、资产权利和禁用原因按需清楚呈现，不能为了简洁误导玩家。

极简不等于把字缩小。菜单有舒展可读的字号和点击空间；正文至少约16px，错误和数值与所解释的操作就近。缩小窗口先重排与滚动，不靠缩小字体塞入全部信息。

## 2. 主页面构图

油画覆盖整幅画布，保留人物、笔触、空间和中央光束，不放入卡片、图库框或边框。大面积使用温黑、深褐、石墨；文字采用柔和温白/旧金。神圣、辉煌和未来感来自尺度、秩序、留白、沉静节奏和细线的精度；不添加宗教图标、粒子、闪烁、耀眼外发光或大量金色装饰。

左上采用用户提供的原始Sonnreich标志。弱静态光位于标志背后，周围原创细放射线长短、粗细和明暗有别，呈钟盘般有秩序的辐射；它们始终静止且不接受点击，不变成太阳钟或游戏相位指示器。标志源文件逐字节保留，CSS呈现不改图片原件。

标题固定为全大写 **SONNHEIDE**，使用本地Cinzel字体的罗马碑铭比例、克制字距和柔和旧金。标题与菜单形成大尺度的视觉关系，不再堆副标题。主页面的所有按钮集中在右下，逐项右对齐，**必须纯文字，不带任何icon**。继续不可用时保留真实禁用状态，不伪造存档；设置内承载语言、降低动态、换画与关于，主页面不另设散落控件。

英/德文菜单采用Cinzel，中文采用宋体衬线回退；中文原生发行字体的逐项许可、打包与整形仍待阶段0确定。当前实际打包的字体只有Cinzel，来源、许可与hash见[界面资产清单](../../assets/manifests/interface_assets.json)和[OFL原文](../../assets/source/ui/fonts/OFL-Cinzel.txt)。不从网络请求字体。

## 3. 油画节奏与资产

五幅用户提供的JPEG未改字节，见[油画manifest](../../assets/manifests/menu_paintings.json)。初值为约68秒停留、12秒交叠；120秒内总位移约1%、缩放约2%。避免整体过亮，也不把全部细节压成黑块。下一幅实际DOM图片加载和解码完成后才交叠；失败保留上一幅完整可见。陈旧异步结果不能撤销当前候选或露出失败图。

降低动态停止持续微移和自动轮播，设置内仍可手动换画；系统prefers-reduced-motion生效。隐藏窗口暂停，恢复不补演后台时间。油画使用应用可见时间，不消耗模拟RNG、不创建World、不跟随Light/Darkness相位。标志、光和细线在任何模式均静止。

公司标志与油画都属于用户提供内容，不擅授CC0或其他开放许可。五幅油画、199KB标志与125KB字体是有界小型界面源文件，随普通Git检出离线可用；后续大纹理、DCC作者文件继续使用LFS/Releases预算。

## 4. 无框交互与游戏界面

所有按钮在默认、hover、focus、选中和禁用状态均禁止border、outline、ring阴影或围框伪元素。键盘焦点必须可见，用明确文字亮度/字重或克制实心底表现，不删掉focus反馈。桌面约36px、触摸约44px的可点空间不能被极简视觉牺牲。

主页面以外，**文字按钮允许纯文字，不强制icon**。图标只用于确实更易识别的功能，如底栏分区、画笔或播放；不把同一个符号贴到每个关系、页签和编辑动作旁。纯图标须三语accessible name及焦点/悬停/触摸可用提示。高影响操作必须给出可读后果，不能靠猜图。保留正常领域字段和必要事实，避免同一信息在HUD、页脚、tooltip反复出现。

游戏底栏七分区保持固定，地图仍是主体。石墨底、温白信息、旧金当前动作构成界面；国家主题色继续是对象事实。对象窗口按需展开，关系跳转和编辑预览清楚，删除常驻revision/计数/调试碎片。Light/Darkness状态简明显示，控制仍在底栏世界分区；不在地图四角散落操作按钮。暗纪元UI仍可读，已有合法灯具表现局部暖光。

## 5. 验收边界

实际核验主页面纯文字按钮/右下对齐、标志原件、静态放射线、本地字体、无装饰小字和全部按钮无框焦点；检查英汉德、键盘、320px窄屏。保留真实图片失败、迟到解码、隐藏恢复、降低动态的回归；对象信息与三语合同不能因改样式退化。

浏览器截图只证明浏览器呈现。原生字体/DPI/IME、GPU色彩、纹理寿命、创建世界与保存返回，以及权威Light/Darkness事务仍须通过原生阶段0—2门槛。
