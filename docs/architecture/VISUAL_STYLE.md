# SONNHEIDE 视觉合同

2026-10-07，同日最新修订：品牌中心在左上区域向内移动，SONNHEIDE标题与五项菜单统一18px字号及0.01em字距，右侧整组右对齐；标题顶部位置保持，下面菜单向上收紧，菜单行高24px、标题到菜单间隙12px；文字/射线/光晕共用暖白微黄#fff6df。结构固定为完整多圈内环→无射线窄空隙→几乎贴着内环的细三层外圈→低亮密集外射线；外圈大幅缩小、边缘减细，射线再次降低不透明度与辉光，字体和Logo柔光不变；远端可越屏裁切、整组固定轻微顺时针倾斜。小中央亮焦点/大部分渐暗不变，右侧文字组保持紧凑。[ADR 0009](../decisions/0009-monumental-minimal-interface.md)覆盖此前按钮必须带icon的规定，[ADR 0008](../decisions/0008-sacred-interface-and-light-ages.md)的68秒停留/12秒交叠与光暗规则继续生效，本轮四向随机微移及微放大替代旧120秒往返。浏览器页面是可审阅设计与交互原型；原生客户端仍按阶段0—2实现。

## 1. 减法是硬约束

**绝对不添加无必要的小字。** 不加装饰口号、副标题、英文眉题、画注、序号、页脚、版本碎片、计时器或重复的操作提示。每段可见文字必须回答正在进行的操作需要知道的内容；“营造气氛”不是增加说明文字的理由。主页面只保留品牌、SONNHEIDE标题和主要菜单。工程接入状态放入实际打开的关于/创建/载入窗口；真实错误、编辑后果、资产权利和禁用原因按需清楚呈现，不能为了简洁误导玩家。

本轮主页标题和五项菜单统一18px字号与0.01em字距，菜单行高24px、点击区域不重叠；正文至少约16px，错误和数值与所解释的操作就近。缩小窗口先重排与滚动，不靠缩小字体塞入全部信息。

## 2. 主页面构图

油画覆盖整幅画布，不放入卡片、图库框或边框。**亮部仅限小范围中央视觉焦点，大部分画面通过连续渐变暗化，越接近边缘越深**；取消上一版大范围明亮中心。小焦点可保留原画亮度、颜色和笔触，暗部仍保有层次；原始JPEG不改字节，禁止以整幅统一约半亮度或统一去饱和替代局部渐变。主页文字、射线和光晕共用**暖白微黄`#fff6df`**基色；字体和Logo的柔和静态发光保持，射线单独再次降低不透明度与辉光，不使用昏暗旧金文字或分别调成不同基色。神圣、辉煌和未来感来自明暗对比、尺度、秩序与精密细线，不加宗教功能图标、粒子或闪烁。复杂钟盘装饰集中于品牌构图，不扩散成按钮和信息页的装饰堆积。

用户原始Sonnreich标志的**品牌中心留在左上区域并向内移动，减少贴角感**。由内向外结构必须清楚：**完整的多圈同心内环→无射线的窄空隙→几乎贴着内环的细三层外圈→只从外圈向外发出的大量低亮密集射线**。内环保持，外圈大幅缩小、三层边缘减细；窄空隙不被针线穿过。外射线再次降低不透明度与辉光，保留长短差异和粗细变化，不用稀疏游离束线替代。远端射线仍允许越屏裁切。文字/射线/光晕基色同为#fff6df；字体和Logo柔光保持，射线辉光减弱；Logo/圆环/射线以品牌中心共同固定轻微顺时针倾斜，禁止持续旋转/呼吸/闪烁。整体不接受点击、不显示真实时钟或World相位，标志原件不改字节。

标题固定为全大写 **SONNHEIDE**，与五项菜单统一为**18px**字号和**0.01em**字距，使用本地Cinzel的罗马碑铭比例、明亮暖白微黄与静态柔光。最上方标题顶部保持调整前位置，菜单从上往下向标题收紧：标题到菜单间隙**12px**，菜单行高**24px**。右侧整组右对齐，由顶部位置定位，不能在缩小行距后因底部锚定而向下移动；颜色与文字光保持，保留键盘焦点，菜单纯文字、不带icon、无边框。三语与窗口比例下不能让点击区域重叠。继续不可用时保留真实禁用状态，不伪造存档；语言、降低动态、换画与关于仍在设置内，主页面不另设散落控件或副标题。

英/德文菜单采用Cinzel，中文采用宋体衬线回退；中文原生发行字体的逐项许可、打包与整形仍待阶段0确定。当前实际打包的字体只有Cinzel，来源、许可与hash见[界面资产清单](../../assets/manifests/interface_assets.json)和[OFL原文](../../assets/source/ui/fonts/OFL-Cinzel.txt)。不从网络请求字体。

## 3. 油画节奏与资产

五幅用户提供的JPEG未改字节，见[油画manifest](../../assets/manifests/menu_paintings.json)。68秒停留、12秒交叠不变。微移只用于本地呈现：以140—200秒缓动段随机交替向四个对角方向漂移，平移幅度x≤0.55%、y≤0.4%；每幅画在240秒内从1.018极缓慢微放大到1.036，替代旧120秒往返。两幅共用屏幕渐变层，只放开小范围中央焦点，周围大部分暗而有层次；交叠不叠两层暗幕，不随油画微移改变渐变覆盖范围。下一幅实际DOM图片加载和解码完成后才交叠；失败保留上一幅完整可见。陈旧异步结果不能撤销当前候选或露出失败图。

隐藏/暂停/降低动态时停止微移和微放大；降低动态还停止自动轮播，设置内仍可手动换画；系统prefers-reduced-motion生效。隐藏窗口暂停，恢复不补演后台时间。油画使用应用可见时间，不消耗模拟RNG、不创建World、不跟随Light/Darkness相位。标志、光和细线在任何模式均静止。

公司标志与油画都属于用户提供内容，不擅授CC0或其他开放许可。五幅油画、199KB标志与125KB字体是有界小型界面源文件，随普通Git检出离线可用；后续大纹理、DCC作者文件继续使用LFS/Releases预算。

## 4. 无框交互与游戏界面

所有按钮在默认、hover、focus、选中和禁用状态均禁止border、outline、ring阴影或围框伪元素。**允许文字本身的柔和静态text glow，禁止按钮盒子的环形阴影或发光边框**；两者不能混用。键盘焦点通过文字亮度/字重或克制实心底可见，不删反馈、不令文字光呼吸闪烁。主菜单本轮统一24px行高，点击区域不能重叠；其他界面的可点空间不随本轮排版改变。

主页面以外，**文字按钮允许纯文字，不强制icon**。图标只用于确实更易识别的功能，如底栏分区、画笔或播放；不把同一个符号贴到每个关系、页签和编辑动作旁。纯图标须三语accessible name及焦点/悬停/触摸可用提示。高影响操作必须给出可读后果，不能靠猜图。保留正常领域字段和必要事实，避免同一信息在HUD、页脚、tooltip反复出现。

游戏底栏七分区保持固定，地图仍是主体。石墨底、温白信息、旧金当前动作构成界面；国家主题色继续是对象事实。对象窗口按需展开，关系跳转和编辑预览清楚，删除常驻revision/计数/调试碎片。Light/Darkness状态简明显示，控制仍在底栏世界分区；不在地图四角散落操作按钮。暗纪元UI仍可读，已有合法灯具表现局部暖光。

## 5. 验收边界

实际核验SONNHEIDE标题和五项菜单均为18px及0.01em字距、右侧整组右对齐；原标题顶部位置保持，下面菜单上收，标题到菜单间隙12px、菜单行高24px，点击区域不重叠且为纯文字；文字/射线/光晕基色同为#fff6df，字体和Logo静态柔光保持、射线再次降低不透明度与辉光，无按钮ring。品牌中心左上向内，完整多圈内环/无射线窄空隙/几乎贴着内环的细三层外圈/外圈起点的低亮密集长短粗细射线顺序正确，远端可越屏裁切、整组固定轻微倾斜且不转动。检查中央亮焦点确实小、大部分平滑渐暗且保有画作层次，不能只查平均亮度；实际核验四向随机140—200秒缓动、平移与240秒微放大边界，以及隐藏/暂停/降低动态时停止。再核原始标志/本地字体、无装饰小字、无框焦点、英汉德/键盘/320px窄屏；保留图片失败、迟到解码、隐藏恢复、降低动态回归，对象信息与三语合同不退化。

浏览器截图只证明浏览器呈现。原生字体/DPI/IME、GPU色彩、纹理寿命、创建世界与保存返回，以及权威Light/Darkness事务仍须通过原生阶段0—2门槛。
