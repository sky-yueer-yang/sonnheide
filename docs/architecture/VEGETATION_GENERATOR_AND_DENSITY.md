# 自然植被生成画笔与有界密度

2026-10-09，ADR0015设计补充；**生产未实现**。接续[v0.8](../design/Sonnheide_Design_v0.8_Living_Pixel_World.md)、[地表合同](../../data/contracts/surface_ecology.json)，机器合同为[vegetation_generator_v1](../../data/contracts/vegetation_generator_v1.json)。本设计只改变生态生成，不改变八soil主题或人物来源规则。

## 1. 要突破的实际问题

逐帧随机撒点会随帧率改变结果、在笔刷边缘形成圆斑、在chunk缝上长双树，并使停留变成无上限森林。单纯均匀Poisson点又会像规则果园。需要同时做到：停留增加而不一次填满；林带/林隙/花簇自然；成熟树冠仍有空间；既有楼、道路、入口和人物不能被树困住；重画、载入、LOD不补货；生成树木确实是机制Plant而非贴图。

採纳两个研究方向，而非导入别人整个生态引擎：[Bridson原论文](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph07-poissondisk.pdf)提供最小间距与空间网格加速的基础；[EcoSys作者论文](https://algorithmicbotany.org/papers/ecosys.sig98.html)讨论密度编辑、植物之间及生境的影响和实例化。下述可变半径、聚簇、时间积分、事务及资产规则是Sonnheide自主设计，不声称是论文的直接性能保证。首版不复制论文代码，不增加依赖或重制全部树木几何。

## 2. 用户操作只有一个主要工具

底栏“地形与生态”增加“植被生成”。默认树木＋装饰小植物，另可选仅树/仅小植物。拖过一处只增加少量，按住逐渐增加；密度接近上限后自然停止。半径沿用其他画笔交互，不要求用户先填概率、数量、种子或生态模拟参数。正常画面仅显示画笔范围和有效候选，不增加装饰性小字。

使用当前实际地表与主题选择树池、花草和颜色。雪原松树，花甸多种果树，枫原纯红枫，樱野樱树＋深绿草，湿地菩提＋芦苇，荒原胡杨＋枯草，圣原圣树，炎地枯树且无小植物；干沙椰树且无小植物。不能因同一个工具开启“花草”就让沙地/炎地长装饰草，也不换掉旧树种。

海水、无支承、实际不适生的坡面/温度区域不生成。高峰对移动Actor禁行不等于Plant硬禁；该处树仍由真实适生规则决定，但不能凭画笔让工人上峰采收。湿地主题不要求淹水，芦苇在允许的湿润岸边带布置；不在深海放菩提。

## 3. 三种来源绝不混同

|来源|是否耗实物与劳动|是否受野生恢复开关控制|初始内容|
|---|---|---|---|
|玩家植被生成 `GOD_VEGETATION`|神力生成不扣文明材料|否，受玩家生态编辑权限控制|有限原创Plant与其明确登记的初始结构生物量；无成熟果、仓库货、货币、动物|
|居民种植 `CIVIC_PLANTING`|真实种子/苗木、路程、权利、劳动|否|按真实种苗账转移和生长，不重复登记同一生物量|
|野生恢复 `WILD_RECRUITMENT`|有界已保存生态过程|是|幼株与真实增长余数，不因屏幕可见生成|

用户授权的树木画笔**明确允许创造树木及有界木质生物量**。这补充旧合同中“神力新树初始可采木一律0”的限制；不是在背后给木材仓库加货。活树默认年轻阶段，初始生物量由冻结树型定义，成年树冠空间提前预留；炎地枯树采用明确有限死木配置，不让它成为永远0木的空壳。若后来实际采伐，必须真实路径、权利、劳动、预约和运输，从这棵树剩余木量唯一扣账。这是有来源的沙盒神力，不能包装成文明生产或无作弊成绩。

所有生成树初始 `fruit/nectar/pollen/forage_quantity=0`，真实花期/生长再形成。不生成种子库存、矿藏或人口，不重置旧树木量/年龄/果批；旧树死亡不被重画复活。保存 `creation_source/eventId/definitionHash/initialBiomass/remainingBiomass`。若将来加入成绩条件，查询真实神力事件；此版不因此锁核心画笔。地形画笔仍不生成库存，两者能力独立。

## 4. 停留时间的定义

密度输入不是渲染帧数，也不是仿真日历。输入层以单调EditorInputClock采集真实按压、光标世界轨迹和焦点状态，按25ms固定槽重采样；每个槽生成稳定 `StrokeId + slotIndex`。刷子暂停世界时仍能编辑，植物的自然长大和果期仍按SimTick停住。记录经过规范化的输入槽即可重播，不能在载入后重新读取墙上时间补长。

某世界位置x的剂量：

`E(x) = sum(dtEditorSeconds * K(distance(x, pointerSlot)/brushRadius) * strength)`。

`K(u)=(1-u²)²`（0≤u<1），之外0。固定定点计算与固定槽采样，不用每帧积分。短路径按世界弧长插入空间采样，以免快拖形成断点；时间权重守恒，不能每个插点再加完整dt。无事件证据的失焦、窗口隐藏、菜单打开、鼠标抬起、World/Session变化立刻结束stroke；系统卡顿不自动补算数分钟，单次无可验证输入间隔最多125ms，其余丢弃并记输入断点。低帧率需由独立输入队列保留真实轨迹；不能宣称两条不同采样轨迹结果必然相同。

每批只从**新输入剂量ΔE**和当前实际实现密度f计算 `Δf=(1-f)*(1-exp(-ΔE/tau))`，指数采用冻结定点查表。没有阻挡的连续近似包络是 `1-exp(-E/tau)`：树tau=6输入秒，中心1秒约15%、6秒63%、18秒95%；整数株数和空间硬约束优先，不能声称每处精确达到这些比例。小植物tau=3秒，簇渐增仍有裸地。拒绝的旧剂量不进入后批公式，也不从历史target减当前树数求补种缺口；障碍移走本身不能生成，新的输入则正常逐增。

增量笔刷每100ms可提交一小批候选，单批最多8树；待提交预算不超过当前批，拒绝/被障碍挡住的剂量不累成将来突然爆发的树海。某处达不到目标时将该处未实现增量记为已消费/拒绝，不保留数量信用。离散株数只允许保存小于1株的fractionalCredit且仅当前有可行生境/空间；拒绝、硬cap、清理、wipe时清掉，不能积出未来大批信用。之后障碍移走必须有新的有效输入剂量才能再生成。零合法位置时停止生成候选，重开或移开后重新检验。地理wipe、明确清树或真实采伐完成将相应根包络范围的树木生成剂量和待决计数失效，增加局部采样epoch；不会把旧饱和目标当成免费重植请求。相同槽/批id重试返回原回执。正常轻刷、慢刷、静止停留都遵循同一规则，不给点击单独“填满”模式。

## 5. 自然分布不等于完全独立随机

1. **生境场**：以真实材料、温度、坡度、湿区裁剪、稳定低频地块场及当前八主题求 `H(x,species)`；不能用生态颜色判断水深/导航。
2. **聚簇场**：世界坐标上的平滑多尺度场（首样12—24m林簇、40—80m林隙），seed来自World生态定义；它只控制生成概率，不改权威地形。多个笔触复用同一场，避免每一笔留下明显圆形森林。每簇保留固定空隙倾向，不用每棵独立白噪声制造盐粒图案。
3. **候选位置**：固定世界8m空间桶，按桶ID、已保存采样epoch和candidateOrdinal生成连续毫米坐标，不固定在地形格中心。候选有稳定优先级；空区域也要有基础候选，不能只沿旧树环形生长。参考Poisson思路使用有界拒绝采样，首样每个接受目标最多24候选；失败不降低最小间距硬塞。
4. **硬间距**：依据成年结构半径 `distance² >= (r_i + r_j + margin)²`。首样margin=.4m，所有邻桶和桶外halo都参与检查。当前幼树小不能作为理由密植，长大后不突然互穿。冠层允许有限视觉交叠时使用独立美术冠层半径，树干/真实占用不重叠；两者定义不可混用。
5. **密度上限**：计入已有树和其他来源的新苗。采用世界原点起、X/Y各以8m步长布置的32m×32m重叠固定窗口，检验茎数上限、冠投影预算和8m局部拥挤上限，任何一条达到即拒绝。这是明确冻结的离散窗口集合，不宣称所有连续滑窗；检查每个与候选成年冠包络相交的窗口，而非仅树中心所在窗。边缘用实际适生面积，不把海面/楼体算作可种地。没有“换seed再刷一次”绕密度的路径。
6. **尺寸与姿态**：原创树有有限已批准形态变体，稳定旋转/年龄/色调分布，但松/枫/樱等各自保特色。视觉尺寸由真实生长体规派生，不只随机缩碰撞体；红枫不能随机绿，圣树光有预算，LOD保持同PlantRef。

首样最大茎数/1024m²：松40、果林24、红枫32、樱24、湿地28、荒原18、圣原22、炎地枯树14、椰树16；混种按各profile归一化占额总和≤1，不把每种上限分别装满。另有成年冠投影覆盖预算≤48%，用成年美术冠半径的**保守外包八边形**与窗口精确裁切计算，不能把圆心在窗口外的树遗漏。八边形采用整数半平面 `abs(dx)<=r, abs(dy)<=r, abs(dx+dy)<=ceil(r*141422/100000), abs(dx-dy)<=同值`；141422/100000严格大于√2，故包住圆盘。裁切顶点与面积为有理数，临界额度向上计量，不用平台arccos或float比较；超估形成少量额外留白。已存在树同样算法计额，definition冻结这组半平面/窗口原点/步长。参数为审美校准值，不宣称真实森林密度；玩法最高密度不等于数学最大圆盘堆积。已经存在的更密天然/居民种植林不被此画笔删除，但其占额使新生成停止。

## 6. 小植物采用装饰簇，不建立假库存

保存 `DecorDensityField/recipeSeed/clearMask/editRevision`，不为每根草建立Actor。按稳定小植物簇原型和剂量逐级增加，最大地面视觉覆盖首样38%，保留可见地皮与树根边裸地。花甸不同花色成小簇，湿地芦苇沿岸润带，樱野深绿草不添热带花；沙/炎配置无装饰小植物。树下依配方减少装饰密度，不能把成熟树下原本装饰全部变成商品。

配方生成的花/草没有库存、碰撞、导航、采集任务或食物效果，不能给蜂免费蜜/给牛无限粮。机制草场、农田、真实树花期是另一类有库存来源的GroundResource/Farm/Tree reserve；此画笔不创建或补满它们。纯装饰生成和Tree creation分开记写集，重复装饰recipe重建不能增加树。

## 7. 植被不会毁掉已有文明通路

保护建筑全占地、入口、人行通道、车库进出/转弯、送料前场、农田、建设预约、港泊位和实际AccessCertificate走廊；不能只测树干是否穿门。明确存在的移动Actor身体与活Gestation位置也要排除，根/成年占用不将其困住。用户停留不覆盖保护区，忽略保护与删除既有楼是另外的显式地理操作。

每个合法候选在同次prepare建立临时root/canopy占位，然后复验导航。树间隙不小于成年树间距不代表一定有人行路：入口瓶颈和既有道路需整条证书仍有效。不允许生成最后一棵树后截断居民唯一通道。**无任务、无旧AccessCertificate的闲暇Actor也需检查**：以其实际身体/载荷能力保原可达组件中至少一条到合法原家/公共服务点或新植被影响区外原portal的EscapeConnection。目标不能仅是Actor当前点；原组件本就没有外侧portal时至少保原有足够身体转身/坐卧的开敞地，但不得用该退化情况豁免原来可达的外侧出口。原本受困者不要求神力造救援路，画笔仍不能进一步抹掉其现有可用连接。alive集合、旧组件与目的端口都进readSet，移动/出生/死亡后重新核验。若保护区在预览后变化，批次按readSet冲突重算或拒绝，不以局部random结果写进去。树在稍后长大也使用已批准成长包络；路径漂移进入预留根区需要真实避让，不能删树救AI。

## 8. 事务、缓存与存档

```text
CanonicalInput -> VegetationDoseProposal
  validate World/Session/tool permission + normalized input identity
  gather exact habitats, tree-neighbor halos, land-use/access dependencies
  simulate <=8 accepted trees with temporary occupancy + decoration field delta
  validate mature fit, regional caps, all affected old access certificates
  commit once: PlantIds, finite biomass source records, zero fruit reserves,
    occupancy indexes, density/decor revisions, receipt and presentation events
```

输入顺序由单写者稳定排序。相邻chunk/同时笔触共享World坐标邻域，不分别接受两棵互撞树；重画仍保旧身份。结果随实际操作顺序可以不同，这是真实先后占用，不伪称不同历史有相同最终树阵；相同规范化输入与初World重播结果必须一致。

缓存键包括terrain/surface/theme、tree definition、occupancy/access、局部density revisions与source sampler epoch，不能仅含seed。terrain改变先处理新地理类型wipe，之后才可按新revision生成；重画Soil不会把已删老树的ID复活。普通主题更换只改新候选池和decor，旧树不换种/回满。

保存全部已接受Plant、来源生物量/果批/预约、decor权威密度/seed/清理mask、已实现/已拒绝剂量游标、采样epoch与已提交stroke回执；活动未提交输入草案不在载入后自动继续按住。采伐/wipe/清理的局部剂量失效也进同一次写集，不等待renderer发现少树后补种。后台/暂停自然增长都按原SimTick语义，重新显示只重建mesh。GPU装饰可以剔除，树的机制状态不能剔除。

性能按本次affected support面积＋邻桶候选＋实际证书依赖计，不每帧全World扫描。可变半径搜索需要以冻结最大成年半径扩大halo或分层索引；不误称Bridson单半径线性证明自动适用于所有混合大树。大刷按明确有限小批连续提交，每批有独立回执；地理毁损的一笔原子提交规则不被它削弱。跨桶冠投影预算采用同一权威计算与依赖索引，不让chunk边成为放宽密度的缝。

## 9. 验收必须包含的反例

|情景|应有结果|
|---|---|
|同一规范化轨迹在30/60/144渲染FPS下重放|相同树ID、位置、源生物量与decor剂量|
|轻扫与同位置停18秒|轻扫少量，停留逐增至自然上限，无一次填满|
|在暂停世界时按住|生成照操作发生，旧树自然年龄/果期不推进|
|按住后失焦、切菜单、载入|停止输入，不补隐藏时长或续旧stroke|
|连续跨chunk缝|无重复树、间距一致、冠密度预算不翻倍|
|换seed/换工具模式重刷已满区域|不能绕已存在占额，旧树果不重置|
|大树幼苗混小树|按成年包络决定间距，不等成年再挤死|
|海岸一桶只有少量干地|适生面积分母正确，不向海或岸缘塞满|
|樱野/沙/炎同样开小植物模式|深绿草/无草/无草，主题特色保持|
|被保护入口/车道是仅剩空地|不长树、不堵出入；停留不积未来爆发预算|
|刷过活Actor、出生蛋或树根覆盖其位置|候选拒绝，不靠生成推出生命|
|预览时无楼、提交前楼占地批准|readSet失败，不能树楼同占|
|地理soil→hill然后马上生成|旧非生命擦除已结算，新树新ID，旧木果不回填|
|仅soil主题换枫原|旧树保种/木果，新树才按红枫池|
|God生成枯树后采伐|有限God来源木量真实扣账，不能伐空树造货|
|God生成果树/装饰花草|初果/nectar/forage为0，不即刻加食物库存|
|刷出圣树林远景LOD反复变化|原有光/树数量不增，不给能源或宗教收益|
|低频cluster位于四桶交点|同世界场，无四块方形/重复簇心|
|重复网络/保存回执重发|同批只提交一次，不加剂量/新Plant|
|移除旧树后再次刷|可生成新身份、真实新神力来源，非旧树复活或木量重置|
|没有任务路线的闲暇人物将被树环围困|EscapeConnection失败，拒绝最后封路树，不能以没有旧证书放行|

其余限密、随机、容器、源量和事务失败场景见机器合同。参数需阶段3艺术场景实测；有限参考模型仅验证输入重采样、占位与上限等指定不变量，不等于树木GPU/导航/果期已经实现。
