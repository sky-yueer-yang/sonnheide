# 三维像素地形、建筑支承与持续接入

2026-10-08。依据[ADR0012](../decisions/0012-editable-3d-pixel-world.md)替代ADR0010的平陆/沿海专有地基规则。以下是新版合同；旧site坡地oracle仅历史测试，新生产高地建址尚未实现。地形变化因果见[地形事务](PIXEL_TERRAIN_TRANSACTIONS.md)，原创建筑作者标准见[像素资产](PIXEL_RENDERING_AND_ASSETS.md)。

## 1. 实际表面决定建址

`TerrainSurfaceQuery`使用当前heightQ/material/water/占用修订，与可见块阶和碰撞相同。来源真实岸线只证明初态；God编辑以后不能按旧natural mask放楼/放船。完整footprint需要干燥、可承托的真实表面，水下土不是可直接放房的陆地。

地形格2m/高度0.5m是首样本规格，建筑模块和导航净空独立。不能把0.5m直壁用平均坡度0.25解释成汽车可走斜坡，实际step和slope都校验。侧壁、台阶、坡道/桥面形状都参与查询；细nav不能创造不存在的坡面。

## 2. 一份完整SitePlan

|组成|批准内容|
|---|---|
|BuildingPlacement|类型/footprint/旋转/绝对floorY/体积、地形profile与相关chunk revision|
|SupportPlan|无基或原创长方体地基、底面/顶面、与实际surface接触、材料/工期、边缘净空|
|PedestrianAccess|每个必需门→真实可用步行网，净宽/步高/坡度/净空与合法通行权|
|VehicleAccess|车库/装卸所需入口→车辆道路，坡度/step/转弯/宽度/停车位/净空|
|DeliveryPlan|当下可达前侧接货区、卸货/退出、真实SiteStorage；不能靠未建未来道路证明今日送料|
|Claims|永久建筑/支承/入口/通道，临时施工/配送/围网范围，各自独立角色与释放时机|
|EconomyAndAuthority|产权/法域、知识/建造能力、材料预约/预算、依赖与历史|

floorY固定，平地可`Foundation=None`，不收虚假地基费。跨高差需矩形承托、必要台阶/坡道；不可任意深基跨水造楼，模板设有界承托高度/面积/成本，超限拒绝并给换地/工程平整方案。普通楼不成独立水上建筑类别。

单笔批准保所有相关claims与接入证书；不能只建主楼然后以后想办法接门。基础/入口独立部件关联BuildingId，不因使用同矩形误释放永久通道。上层网罩仅表现，权威禁入由项目占用负责。

## 3. 后续普通建设保旧通路

后建房/道路/地基/港区不能堵先建人行入口、车库、接货路线或泊位。旧证书明确terrain/roads/portals/clearance/rights版本与保护域。替代路线先验证并预约，同事务切换后才释放旧路；无替代则拒绝普通施工。不是每栋房分配无限直线“不可动世界”，保护域只包含真实必要路线和净空。

Godterrain有另一明确权限：经后果预览可以改变保护域/支承/海峡，并同时失效证书、停新任务与记录损坏。法定路权和物权不因此转移；新的有效路径必须重新证明。保护God模式不能只看刷子内资产，须检查远港/组件依赖，否则称安全而实则毁全城。详见地形事务。

## 4. 当前房屋遇地形变化

既有floor、地基和门不跟着刷子自动抬升，抬山可能埋入口、挖地可能悬空、变海可能淹支承。按支承/淹水阈值进入稳定/受损/危险/废墟，容量和业务依据真实可用部分，停止非法入住/作业。居民和货物保留真实容纳/产权，疏散/抢救需要路线和时间，不直接删楼里所有人。

地形恢复只使重新验址可能通过；已经发生损坏、报损、死亡不能免费撤回。修理/重建真实投料；完全不损坏的楼无需莫名其妙重收建造费。普通切历史外观仍同footprint/authorityHash，不改楼板/容量/入口，像素画风也不能让门消失。

## 5. 港口、桥和工程造陆

PortCore正交矩形、海侧边连续泊位、水深/吃水/净空合格、陆路实际连广场。INITIAL/DIVINE_EDIT/CIVIC_EARTHWORK干陆一律按几何支持核验，取消仅填海来源要求。湖港/海港区分当前连通，不能把边缘渲染海面作为世界航路证据。

桥属于道路工程，真实桥面/桥底净空影响人车船，不改变下方水深。造陆/平整工程仍有材料/劳动、可达施工与未完旧表面；神力造陆明确单独来源，无完成材料退款。港口拆除不隐式删其地面；神力再挖海属于新的地形事件。

## 6. 施工表现与验收

[ADR0002](../decisions/0002-building-construction.md)仍有效：小人取料/携行/前侧放料，材料到齐后自动工期，人物不砌筑。像素矩形网罩逐层围/全包/反拆，纯表现不结算材料或决定完成。暂停冻结、离屏不补播、载入直接对应项目状态；完工通道立即可用，不被未拆网片挡住。

验证平地无额外基础、坡地矩形支承/每门人路/车库实际车道、四方向港区/水深、step与纵坡分别校验、先建后建不堵、依赖过期/批准无半写、地形破坏所有占用/容纳的后果、恢复不免费修楼、同权威版本mesh/nav/拾取一致。历史oracle结果不能替代新的城市生产案例。
