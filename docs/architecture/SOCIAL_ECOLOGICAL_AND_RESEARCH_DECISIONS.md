# 家庭、知识、信仰、科研与生态决策

2026-10-09，ADR0016＋ADR0018／v0.9；设计，生产未实现。机器合同见[social_decisions_v1](../../data/contracts/social_decisions_v1.json)，共享知情/人格/承诺见[决策核心](DECISION_CORE_PERSONALITY_AND_INFORMATION.md)。没有增加人口来源、季节、昼夜、私家马或新文化创始资格。

## 1. 社交对象和共同生活

熟人候选来自真实接触、亲缘、邻居/同事或收到的介绍；不从全World挑“最适合的配偶”。先排除实际不可接触/需避险/对方已拒绝且冷却未过的对象，再依已发生关系、共同语言或原始交流、当前目标、时间和双方兴趣安排一次接触任务。每个参与者独立决定接受、改时间或拒绝；同一邀请的多个回调不会形成多次同意。

关系分care/trust/familiarity/conflict与有来源事件，不存一个同时代表爱情、忠诚和政治赞成的好感值。陌生人实际救助可以增加care与特定信任；拖欠工资记雇佣信任，不直接扣家庭亲情。实际交谈须同一可交互场所、双方空闲和真实语言能力；语言不通仍可使用范围有限的原始手势交易/协作，不送正式Language熟练度。

Household合并/分户是协商方案：共同照护、食住利益、现有关系、可用居所、权利及预算分别核验；两边接受再提交成员与真实资产保管/费用分担。成员可有不同国籍文化/信仰。没有住房不禁止建立共同生活关系，但不能承诺不存在的床位。分户保原Family、债权与产权，不一人复制两户粮。

## 2. 育儿、生育与照护排程

生育计划先查同species生殖角色、生物成熟、法律公民成熟/同意、繁育WorldRule、实际营养和现有birth reservation。成熟身体外形不是未成年签约或生育资格。高级意识双方独立接受、拒绝或延后；亲密关系/君主命令不替代同意。

家庭规划以当前依赖者照料缺口→营养/冷热→现实照护人与可用时间→住房/收入情景→双方实际生育意愿排序。样例预测30游戏日照护窗口、至少一个真实可用照护计划；钱不足并非不能活的硬生育阶级门槛，可用真实家庭/公共支持方案，仍不免费造奶、保姆或家。野心/利他/风险等只改变承受计划和优先顺序，不保证怀孕。

受孕执行使用life既有唯一路径：真实接触、营养reserve、Genome/启智快照、due与capacity预约。已有孕体不因后续关生育、换国籍、编辑基因而删除或重写。照护排程绑定实际ActorAvailability与食物/保温；照护者同时被征召/死亡，原计划失效并发出求助/调整任务，不继续记满护理。

照护选择明确范围：当前急迫危险→已有受托依赖者→实际空闲/路线与物资→其他自愿救助。利他者可以从自身余量出更多力，不能忽视其本身的真实能量/长期不可替代护理；没有解时保`CARE_GAP`，对应生命实际后果，不补一个自动照护NPC。

## 3. 迁移与职业/家庭变化

迁移从实际危机、收到的岗位/邀请、亲属联系和当地长期需求触发，至少包括原地修复/换工作/寻求救助/加入已有城市/新聚落/等待。家庭成员分别接受目的地、费用和同行/暂留方案；不强制所有人因家长选了目的地立即搬家。

目的地资料来自真实公开准入、邀请、熟人或勘察的带时效报告。报价工资不是保证收入，目的住房预约不是已入住；通路、真实路程时间、粮衣、照护和允许入境重核。已知预期有改善但隐情导致岗位失效时，可重新协商/回程，保同Actor和货物。民族、文化或信仰相同不是自动入籍，国家准入与HomeCity分别提交。新城/同共同体迁建调用settlement_lifecycle_v1，而不是此域再刷城市。

## 4. 教育与语言学习

学生先从实际需要（工具/职业/邻里语言/安全/求知）形成TopicRequest。候选仅已知可教的现有人、真实书/档案和实际训练设施；教师/文献有对应知识、许可、沟通接口、座位与空闲。教学安排按先修图检查、双方接受、学费/公共资助/真实教材和照护班表准入。

课程序列是知识DAG的已掌握边界节点，不跳“大学开了→全城懂全部科技”。每次教学episode实际完成的有效work ticks经生命域learning效率、教师对应知识/示范、沟通和已安装设备的冻结定点系数积分，知识节点保存进度/lastTick/remainder。容量约束与预先规定的learning单位一致，不以课堂动画或teacher人格送知识；错误教材会传递带来源的错误belief，工程技能资格仍需真实训练/检验。

求知影响选课/主动询问和额外学习时间分配，职业/财政与species适配决定能否执行。虔诚者可能选既有教会学校，教会闭门或教义限制照常；高piety不授知识。动物高级意识可以教/学已有正式语言与知识，工具和身体要求仍实际核验。

语言熟练度仅从真实理解/练习/教学事件增长；未理解完整内容不能把秘密科研消息放入K。UI改中英德不改变模拟语言、教师资格或通信。原始交流不登记新正式语言；正式语言分化还须既有长期真实speech community及人类发起资格。

## 5. 文化参与、创生和传播

实际共同劳动、反复交流、仪式、教习、迁居和历史事件形成文化实践证据；玩家切旗颜色、统一服装或点元控制不补这些事件。文化强度改变有过程和独立membership，不因臣籍改变全部归零。

人类Primary/Secondary创生沿 [完整创生合同](../../data/contracts/emergence_algorithms_v1.json) 的真实接触图、双阈值、field、候选与唯一nucleation receipt：发起者必须真实合格人类、在场参加，文化与语言来源按既有原子规则。求知/野心影响发起参与/传播候选，不能让遗传编辑、启智牛、已知书或空位默认人物成为创始来源。高意识动物可以维持、教学、传播、治理既有文化语言，但不形成新实体。

文化接纳采用实际关系/语言接触、必要实践与本人选择，接触不等于完全同化。原文化可以并存；不使用强者文化覆盖全部人口/删除所有少数文化的全局回调。教义、法律和实践相冲时产生具体协商/保持多重实践/抗议/迁居候选，不给一个“文化兼容率”直接控制人物全部政治意见。

## 6. 信仰、教会与传播

根Religion仍只能由玩家建立、先知与性质来源冻结。自主决策只有了解/加入既有信仰、实践、奉献、参与教学救济、改革派内制度或明确符合条件的教派程序，不新造根宗教绕过玩家。

信仰确信、根/教派归属、对教义理解、教会领导信任分别存。实际教学/仪式/帮助/苦难与矛盾经历更新对应belief/信任，piety只改变寻求宗教解释与参与预算。虔诚信徒可以反对主教腐败、减少向机构捐款而保持信仰；无信仰者也可以接受符合教义的真实救济。

奉献从本人/合法Household可支配部分选择固定数量，基本食住衣护预算先保护；不能收一次钱在多个教会记多份奉献。教会同经济法人：现有钱、物资、人员先满足已承诺救济/教学/设施维护，再比较本地巩固、开放传播、服务教学。传播选择真实可达已知群体、语言与接受意愿；遭拒绝/法律限制/缺预算可暂停或诉求，不强制转信/凭旗色收税。

派内改革需要实际参与者、章程权限、议事及真实行动，根性质冻结不会因当前领导人格变成新根。不同信仰/不同species不是默认敌人或战争理由；宗教政治冲突沿具体权利、土地、税、违约与信息事件到政治/外交算法。

## 7. 发明、研究、采用和公开

研究题目来自已观察的实际工艺瓶颈、失败记录、用户提出的问题、已有知识/可访问专利与好奇探索。候选包必须列先修知识图、问题假设、实验方案、真实工具/试件/时间/资助、失败废料账与成果权利；未知不会被替换成“已经理解”。安全规则和property许可依既有法规执行。

不以“智力×求知×随机”直接发明机器。执行为`QUESTION → HYPOTHESIS → DESIGN_EXPERIMENT → RESERVE → PERFORM → OBSERVE → REVISE/VALIDATE → DOCUMENTED`；每阶段存actual work/material/effect，观察结果及噪声使用项目固定定义/counter，读档不重抽。反复实验次数受实际预算与设施容量；失败也有真实材料损耗和有界知识记录，不能失败无限复制经验/零件。

研究负责人选题先满足受托合同与急迫安全/生存改进，再在真实可做候选上比较已知瓶颈收益、成功区间、试验成本、可证伪性、研究者偏好与长期价值。研究未知成功率用区间，不隐读未来真值。探索与改良各留定义包校准额度，防全城只做短期最赚钱研究；无资助不强制另扣国家钱。

已验证知识与装机能力分开：公开/许可/保密按所有者/资助合同，档案保管与实际掌握者独立。采用方要实际得到知识、取得许可、培训现有人、生产/购买设备、安装/工装、安排停机和检验；比较真实未来增量收益与切换成本。旧产品不免费升级，研究经费不由学者当前总分凭空生成。408旧技术激活视图仅来源，实际节点须完整定义/三语/资产和功能验收。

## 8. 动物与野生生态的独立决策

普通动物使用固定species行为词典，感官范围内食物/敌害/同species社群/真实巢、疼痛/能量/繁殖状态作为候选；不授国籍、工资、政治投票或语言。启智后高层增公民任务，实际身体/年龄/营养、物种食性和普通生命词典仍同Actor连续。

觅食先当前实际能量与危险，再真实可接触可食源、回程/照幼/冷热和消化能力。装饰花草无营养、无捕食目标。进入采食episode预约真实Plant/Forage/Item量，实际接触劳动后唯一转可代谢份额，不同动物同食一果只有一次扣账。蜂的花期reserve/花位/路径与授粉事件沿life/ecology接口，不在视效蜂群上生产蜜。

捕食候选有物种食性、真实感知的活猎物、预期追赶能量、伤害风险和照幼约束；关闭新捕食只禁新episode，接触阶段按规则明确停止/退出，伤势和食物不回满。追逐失去接触后只搜最后已知区域有限时间，不全知追到远端新位置。再饥饿也不能从成人体规凭空生成可收肉；击杀/吃肉使用真实productive reserve。

野生繁殖使用实际同species合法成熟接触与life预约，predisposition影响行为不是保证新生命。群居位置为已观测同伴/安全点，不全地图挑最大群；迁徙为真实觅食/危险路径，不新增季节/天文系统。固定高峰禁区不会被飞鸟、遗传耐寒或饥饿突破。

## 9. 领域交接与故障

所有任务领取同一ActorAvailability、库存预约和ActionCommitLedger。教授被征召、母亲受伤、港口毁坏、教会资金不足、祖国改籍等事件使相应claim失效而不是给每系统补一份备用人物。无解显示缺口，真实伤害/饥饿仍按WorldRule；关闭AI自选只禁新选择，不能停孕期/腐坏/债务。

多主体协议状态：`INVITED → PARTIALLY_ACCEPTED → ACCEPTED → RESERVING → COMMITTED → PERFORMING → CLOSED`，拒绝/超时保原实物与历史；死亡使未完成同意/角色失效，已实际教学、奉献或出生不撤销。邀请与对象生成generation绑定，晚回复不能签同名新人物或换了一任的角色。

样例预算个人社会候选≤12、课程节点≤16、项目实验计划≤24节点、普通动物觅食候选≤16；各含在共享固定总work预算内。紧急碰撞/生理不截断到这类认知候选cap。存实际due、接受版本、claims、基因快照、项目counter/余数与进度，摄像机/LOD/locale不影响任何产出。

## 10. 差异必须能说出原因

同样有一笔余钱，高求知者可能订课程，利他者自愿补照护，野心者储创业本钱，虔诚者参加已有教会任务；每个选择仍在本人义务和基本预算之后。一个求知高但受伤、缺教材的人可能选择休息/询问，不像健康有书者立刻学习。一个虔诚且利他的人可能向腐败教会拒捐、直接提供合法救济，不能由单piety数值一票决定。

信息、经历、责任、习惯、关系与随机近优变体都有独立可解释记录。预设人格画像仅用作验收输入，不给每个人永久职业标签。未来SD01—SD48见机器合同，覆盖同意/照护冲突、启智来源、语言/信仰差异、研究真实成本和动物库存；本批未做生产测试。


## 11. ADR0018：真正形成文化／语言／谱系的条件

详细可施工函数、微型实例与有限内存界见 [EMERGENT_CULTURE_LANGUAGE_AND_LINEAGES](EMERGENT_CULTURE_LANGUAGE_AND_LINEAGES.md)，机器权威为 [emergence_algorithms_v1](../../data/contracts/emergence_algorithms_v1.json)。它收口此前“沿 Genesis”“持续语言分化”“自然亚种”的接口句，而不是在旧接口外再造自动进度条。

文化只取实际合作／照护／教习的稀疏互惠接触证据。创生候选用纯人类诱导子图；启智动物能帮助既有实践和传承，却不能用一只牛把两群不交流的人串成创生人核。至少3共同已知实践才有边，未知不能填0。和谐、互惠、实际恢复／未解冲突、实际已完成成果分别进入 mu／phi；七类实际事件固定正负脉冲、真实数量／目标／质量归一，God事件和同一因果回声不重复计。phi 噪声须乘真实准备度，单独噪声稳态小于2800，跨不过4000起源门；还需两次实际正成果、30实际新实践日和人类发起会议，不由人口／闲置天数自动刷文化。

初生人核全部尚无文化和正式语言。根语言16个意义，创始者与至少3成熟人类参与者须已在至少3实际证据日互认相应原始意义；未知必须拒绝，不能生成词形后假装大家知道。正式会期是实际任务：每意义3次100专用工作tick，学习者和每组最多4人的教师均占真实时间、支付实际代谢／工作能量；每学习者4800实际tick才获已传授意义 basicQ3000，未完成参与者不被群体一键赋语言。Secondary 文化和正式语言分支另需600实际专用通信工作tick／人，创始者加至少3同意成熟人类，会议在实际可通信8m或真正送达的消息上完成。中断保真实已做工作，重新核候选／知识／主体；同事务创建新实体与正式来源一次，不刷城市／广场／科技。

语言仅16意义×4特征×4整数变体频率，实际听懂／教学的 token 才收敛；隔离漂移来自180实际使用日中的人类创新，须真实教学传播。正式分支需12真实用过意义、3改变特征、至少6成熟人类、两实际受教代群跨360日、互通低于6000与隔离高于6500，恢复联系用7500／5000双阈值避免摆动。未知意义贡献0，不把国家、制服色、locale或现成文化当语言。动物可长期教／学并维持已有人类语言，没有纯动物正式分支。

亚种分支只取同species12维真实继承等位特征原型与720日真实繁育图；至少8成熟成员、2真实出生事件及4不同亲代，内部繁育占比6500、90实际证据日、原型离父分支2500，持有阈值1500／5000。颜色、人格、法律群体和国家均不进距离。混血靠最近距离与500差距保守归属，模糊保母体快照来源；首分支复制父共享特性不发能力奖励，不产生新species或新Actor。

科研的原408项激活来源与实际节点分开。[technology_runtime_v1](../../data/content/technology_runtime_v1.json) 逐节点给先修、实际实验／材料／观察／学习／采用工作与有限操作参数；[economy_content_v1](../../data/content/economy_content_v1.json) 给真实商品／产线／资金边界。知识成功不赠机器，设备采用只修改真实未来操作版本，不回溯免费升级；实际项目仍依知情、不确定性、预算、产权、材料和生产角色完成。本版只有12000tick／游戏日；生理、教习、劳动、军训全用同一 ActorAvailabilityLedger。
