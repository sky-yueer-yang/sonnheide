# ADR0026 — 双排工具栏、固定时间控制与独立时代页

2026-10-10。最新用户要求覆盖ADR0025的工具台布局与分类图标；深灰石材、边缘短裂纹、三语、世界事务与保存约束继续有效。

## 观察依据与结构

实际检查开发者[界面截图](https://x.com/Mixamko/status/1575249911507046400)及其[原图](https://pbs.twimg.com/media/FdxpN2qXEBkSxIE.png)，并检查Steam官方ArmyBox更新的[动态截图](https://clan.fastly.steamstatic.com/images/39496096/9fb9f8d9f44fbe37957e84e8b25af22452de4b44.gif)。可直接观察到：分类页签宽而低，上缘小阶梯斜肩，下部接入横栏；页签内为紧凑的浅色横向符号；工具固定为两排，以竖向分隔划分控制区。参考的是可见结构与交互方式，原图不进入分发素材；全部图形仍由自己的配方生成。

Sonnheide工具区固定两排，最左侧控制区始终保留播放/暂停、速度、时代和世界信息。改变八个分类只替换分隔线右侧工具；固定控制不移动、不重复、不受分类开关隐藏。未实现的领域继续明确禁用，不补假工具。窄窗口保留两排，必要时横向滚动工具区，不把整栏堆成第三排；八页签仍可达。

分类页签低矮、宽肩、开放底口，接在连续凸沿上。常态38dp、选中42dp，图标适合扁宽空间；不再放大成独立直立石碑。八分类图标使用单一微黄白色`#fff6df`，独立48×28逻辑格与整数倍率PNG/SVG；粗轮廓靠符号自身剪影和负空间，不给白图标再套彩边。类别名称进入中英德提示。其他普通工具图标保留原创实物颜色。播放和暂停只保留三角与两根竖条，外面没有圆环。

## 时间控制与弹层

速度只显示一个当前倍率按钮。点击展开七项`0.5× / 1× / 1.5× / 2× / 3× / 5× / 10×`；选定立即生效并收起，Escape和点外部收起。弹层吞掉相应输入，不把关窗点击透传给世界。改变倍率不自动继续播放；暂停时仍可选下一次播放的倍率。

倍率是本地墙钟节奏，不改权威20Hz离散tick。用整数半倍档位和纳秒累积，0.5与1.5不能被整型截断；成功完成权威tick后才扣一份时间。保留不足一tick余量，暂停/隐藏不新增时间债，换世界时清除旧会话债。单帧墙钟上限250ms、每帧工作上限256tick沿既有契约，禁止以改变模拟规则实现加速。偏好写`speed_half_steps`，世界存档不混入本地运行倍率；历史偏好1保持、4迁为3、16/64迁为10，非法倍率拒绝而非静默冒充。

Age只在工具栏提供一个入口，打开居中的独立时代页面，展示光明/黑暗两种时代、当前选择、手动/自动方式。手动选择时代通过原子命令同时关闭自动；开启自动保留现有权威tick期限与保存余量。弹层切换本身不切时代、不改倍率、不耗模拟RNG；时代也不改变UI材质与颜色。键盘焦点、Escape、错误模态优先级、会话切换和三语切换完整覆盖。
