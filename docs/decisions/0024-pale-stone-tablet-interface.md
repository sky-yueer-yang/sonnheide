# ADR0024：浅奶黄石碑界面

2026-10-10。用户纠正石材方向：要微微泛黄的浅色完整石碑，大面干净；只有边缘少量毛糙缺口，或从上边缘向内延伸的短裂纹。此前未发布的暗赭黄碎岩、满面分块裂纹方案明确撤回，不能作为本轮结果。ADR0023其它材质、粗重实物图标、高分辨率像素和世界规格继续有效。

石面使用低饱和的浅奶黄、暖灰和旧石灰岩色，色差克制；不是金黄、褐黄、砂岩碎石铺面或大理石花纹。512²原件只保存洁净的细像素石面与轻微粉质颗粒，不包含周期平铺的裂纹。边缘缺口和裂纹必须按实际控件尺寸在真实外缘生成：少量不规则轮廓缺损、从上缘向内收细的短裂纹，中央石面保持完整。有限色块、最近点采样和1纹素/逻辑dp保留，不模糊放大。

工具台顶端有一条窄的凸出石沿；八个分区页签再搭在这条石沿上。实际布局为6dp完整石沿、2dp温灰阴面，页签底端与石沿顶端相接；不挖掉整条石沿，不覆盖两次。石碑的厚度由本色与温灰阴面表现，不使用纯白亮条或深黑工业边框。

浅石面上的标题和正文改用深红与深棕墨色；标题保留真实像素加粗，移除浅石面上的亮黄白色轮廓。深色按钮、输入槽和其它材质各自保持可读的文字配色。

`rock`是当前石面生产注册名，旧`marble`纹理与绑定移除；其余八材质及41图标123件原件保持字节一致。页签/石沿/窗口的真实几何使用缓存分块网格，不逐纹素生成几何，不让纹理边界决定裂纹位置。维护移动、缩放、切换页签后的缓存和点击区域，保持三语、窄窗口、模态输入与世界存载行为。

本轮完成全部新源件后统一ALL构建、完整CTest、ASan/UBSan和原生GPU流程。旧暗岩版本的本机通过只属于被用户纠正的工作稿，不证明新浅石碑方案。实际证据记在`STONE_TABLET_DELIVERY`。
