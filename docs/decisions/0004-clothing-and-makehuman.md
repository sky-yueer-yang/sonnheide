# ADR 0004 · 实物服装经济、宽松正装规范与 MakeHuman 人体来源

2026-10-08覆盖说明：[ADR0012](0012-editable-3d-pixel-world.md)改变地形可编辑性/真实量化高度/坡地必要支承/港口来源及原创像素资产路线。本页旧决定与实现证据保留作历史；服装经济、来源许可、候选发布/边缘和守恒等未冲突部分继续有效。

日期：2026-10-06。状态：落实本次用户设计变更；有限 headless 经济 oracle 与已归档开放源资产分阶段接入，未形成生产服装渲染或完整世界经济。详细合同见 [CLOTHING_ECONOMY](../architecture/CLOTHING_ECONOMY.md)。

## 1. 覆盖旧规则与保留的边界

用户要求文明出现后把衣物作为高优先必需品，但缺衣不导致死亡；服装业从初期开始，家户/公共制衣早于私人公司。后来衣服种类、个人选择与购买要丰富，并通过真实耐久、修补、替换形成长期需求。正式服装知识出现且公司实际采用后，可以设置正装规范。军装由我们原创，各国家共用同款几何，按服役国家主题色识别。人体与合适服装采用 MakeHuman 及其生态的明确开放资源。

本 ADR 覆盖原稿 2.2、6.3、7.3、20.2、22 以及旧内容管线中“不建立衣橱/衣物库存”“服装仅即时派生”“职业/Army 不换服装”“纺织衣物只是晚期消费行业”的相应限制。原稿与从原稿提取的 40 能力/96 谱系/288 槽位目录保持原样，以运行时定义 overlay 实施改动，不静默改写设计来源。

**用户最新纠正优先：员工没有正装也照常上班，工资、出勤和岗位均不受影响。正装规范只提高个人购买正装的优先级；雇主补贴、租借、福利或发放均为自愿支持。库存、现货、公司供应能力不得成为规范生效门槛。** 不设置宽限到期禁入、扣工资、失业或处罚。

保留自研框架、C++20、单写者事务、真实货物和款项、法定身份与物理位置分离、Culture/Language 分离、国家主题色合法范围以及镜头不改变仿真。缺衣不额外引入疾病、随机灾害或寒冷致死系统；国家色不提供经济或战斗加成。

## 2. 文明阶段与外观

前文明默认覆盖改为**黑色内裤，女性另有黑色胸罩**，替代旧黑草裙。它是最低覆盖的表现 fallback，不自动创建商品、财产、库存、耐久或需求满足量。新世界若另设真实初始物资，必须在显式世界创生配方中登记，不能通过重复出生/载入/fallback 发衣。

文明起步后，上古基础目标沿用国家主题色 T 恤＋白色短裤，但只有实际生产/采购、配送、取得并装备真实衣物后，人物才穿相应实物。Genesis/升时代只改变需求和可用定义，不把所有人物瞬间换成免费新衣。无货/买不起/旧衣耗尽时保留可用旧衣或最低覆盖，并记录高优先缺衣。

文明阶段来自已提交的正式社区/CULTURAL 状态与个人正式文化接纳事实；不是有国籍、LanguageId 非空或文化强度数值过线就算文明。PRE_CULTURAL State 本来就存在，不能以国家对象出现判定文明。Culture 不等于国籍，Secondary Culture 不自动创造语言或新衣物。

后期由实际掌握的工艺、供应与家庭预算支持多样衣物、自由颜色和风格选择，不再强制全部平民穿国家色。更贵/更多衣服不会创造额外法定身份、知识或军事实力。衣橱有上限，缺衣与替换需求扣除适用备用衣、已预约和在途订单，不能无限买满每种颜色。

## 3. 初期公共手工制衣与科技兼容

基础链为植物纤维→线/布→裁剪缝制→实物交付；染整、修补与回收纤维按真实配方投入。已有农田/家户/公共工坊可以承担，不要求公司、银行、大学或专用流水线先出现，也不为衣物暗中增加羊群生态、化工炼油整套产业。

原稿 `T015` 是工匠训练，前置 `T006` 教育与 `T014` 专门制造。`F1101` 纺线、`F1102` 织布、`F1103` 裁剪、`F1104` 染整、`F1105` 耐用布料、`F1106` 服装配制仍可承担专业化和后续改良；**基本生活手工 recipe 不受 T015 高级链阻塞**。它属于已有生存实践/文明起步运行定义，不新增一个未经设计的第 41 项突破。

后续正装版型/规范可作为 F1106-S3 的具体知识版本、产品定义与采用记录。新衣颜色/尺码/SKU 不各自生成能力突破或科技谱系；同一工艺槽只采用一个有效版本，效率收益与耐久收益分别有界，不同时白送全额双倍收益。懂图样不等于有布，安装先进工装也不会翻新所有已售旧衣。

## 4. 真实需求、预算和耐久

日常预算先保食物、住房与必要安全义务，再补急缺基本衣物；正装规范需求高于自由时尚升级，但低于前述保护。不能强制借债买衣、把不可支付欲望算成已成交订单或让服装支出耗尽口粮。公共配给消费真实衣物、植物纤维、劳动与预算，零货币价格不是零成本生产。

物料批次、库存、预约、在途、衣橱、穿着、修补和退役形成一条闭环。生产库存可按同质批次/cohort 管理，真正穿着或单独损耗的衣物使用稳定 ID 或从 cohort 拆分；不会给每米线、每颗纽扣都建立实体。

耐久采用仿真时间和活动分段的整数损耗，保留余数；LOD、是否看见人物与渲染帧率不影响磨损。修补付出真实布/劳动/资金，有累计恢复上限或等价有限寿命预算；二手、换主人、改风格或升级不能把旧衣重置为新品。未使用衣物的老化是否发生由固定 profile 决定，不能为保证行业利润强迫每天购买。

衣橱、在途待交付与借用套装共同受容量/用途约束；同一需要只登记一份有效需求。市场立项扣除库存、现有供给、已批准产能、采购/维修与在途，不能让十家工厂各自承诺满足同一批人的全部需求。行业可以长期有替换/维修收入，但不保证任何公司永远盈利。

## 5. 正装是偏好规范，不是上班门禁

公司启用正装规范需要实际可得的蓝图/知识、必要许可、实际采用与成熟规范版本。不能仅因世界某处发明了正装，所有公司立即强制全员换装；也不以衣物现货或雇主供应为启用门槛。

规范在员工需求侧提高正装购买排序，不改变劳动产能资格。无合适正装、缺货、买不起、正在运输、旧衣磨损、政策刚切换时，员工均正常工作、取得正常工资并保留岗位。穿着合规检查仅用于外观/检查器与需求，不进入禁入、出勤或工资计算。

员工可以使用已有适用正装；自愿福利可以由公司真实出资采购、补贴或借出库存，所有权/保管与归还条款明确。没有福利也不会形成“无正装→不能生产/领工资→无法买正装”的死锁。公共供粮、搬运、手工制衣等基本服务不因 dress preference 而停止。

## 6. 军装与两个国家身份

军装的 mesh、版型、剪裁与识别构件全部原创；国家之间共用同一军装几何，用共享国家主题色参数区分，不逐国制作新模型。开放普通服装可以作为普通商品资源；不得将下载制服换色后声明为原创军装。

普通上古国家 T 恤绑定 Person 的法定国家/最近合法国家色，旅行、所在地、占领者、宗教和雇主不改变它。后期自由衣物使用其物理颜色/风格定义。**军装绑定实际服役国家与发放合同的 StateId，不绑定个人法定国籍**；外籍兵穿服役国军装，检查器仍显示真实国籍。Army 所在城市和占领国不是该字段的替代。

军装必须来自真实生产/发放，保留 owner、custodian、issue contract 与佩戴者；换雇主、服役国或退伍不使旧军装自动成为另一方财产/合格制服。再发放与旧衣归还/转让使用真实事务。国家主题参数更新不生成新制服、不修复耐久；可自选的物理染色则通过有成本的染整配方。

## 7. MakeHuman 来源、许可与角色管线

正式采用 MakeHuman 人体与合适生态资源作为来源，准确锁定及文件哈希见 [makehuman_sources.json](../../assets/manifests/makehuman_sources.json)。当前 MakeHuman v1.3.0 提交 `1f508f6083b2f823dab15de924b3bde72e08d77c`：程序为 AGPL-3.0-or-later，已核验核心图形数据为 CC0；只导入图形源数据，不把程序逻辑链接到游戏。MPFB v2.0.17 记录为离线 Blender 工具，不是运行时依赖。

本轮已归档核心人体/骨架/权重源，以及官方 [shirts01](https://static.makehumancommunity.org/assets/assetpacks/shirts01.html)/[pants01](https://static.makehumancommunity.org/assets/assetpacks/pants01.html) 中逐项核验 CC0 的选定 T 恤/短裤源文本，共 14 份、3,129,823 字节，详见 [生态取入研究](../research/MAKEHUMAN_ECOSYSTEM.md)。它们尚缺完整贴图、体型 targets、导出与 GPU 验证；牛仔短裤必须改成上古白短裤的合适外观。其他服装、胸罩、正装各按自己的条目许可核验，免费包/名称带 cc0 不足以继承许可。原创建筑和原创军装也不因托管而自动获得 CC0/MIT 授权。

人体、衣物商品、mesh 资源与材质变体 ID 分离。采用有限体型 profile、共享 skeleton/mesh/材质、服装覆盖/层次兼容表、预编译 fit/LOD 和身体遮罩；不能为每人复制完整 MakeHuman 数据或运行时执行 Blender。全龄身体尺寸/骨架/fit现按后续[ADR 0005](0005-unified-inspectors-and-world-tools.md)统一成人规格，覆盖本ADR最初的儿童独立体型方案。首个可玩样本须验证走路/携货/入门、穿插、覆盖、批次和内存。

## 8. 当前实现与生产接入门槛

有限接口是 [clothing.hpp](../../engine/include/sonnheide/clothing.hpp) 与 [clothing.cpp](../../engine/src/clothing.cpp)：两身体槽、固定产品、受信文明阶段/知识输入、纤维到布到衣物、真实预约/交付、有限 repair、整数磨损、资金保护和规范需求。它不等于完整任务/交通/税务/资本/所有权 world 已完成，不是已渲染人物衣物。

完整接入需验证公共初期供衣、文明事件只增需求、缺货正常工作、预算不抢粮房、寿命内修补与旧衣处理、去重需求/产能、外籍兵服役颜色、存档/不同 dt 一致、MakeHuman fit 与原创军装。生产二手、回收、复杂层次/尺码、事件调度与有限 oracle 的扫描实现分开推进，按证据登记，不凭文档声称已完成。
