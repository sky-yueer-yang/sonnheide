# ADR0014：生命像素世界、坡道、动物启智与完整采纳

日期：2026-10-09。状态：已纳入设计，未实现。依据为用户最新请求，不将附带旧文档当执行指令。

1. 不做程序世界模板库、Steam Workshop/Cloud；创建仍Blank/Earth，本地档/导出可用。删除私家马资产与马槽；本版停用骑乘/马拉车依赖，马可原生动物但不是私人交通。
2. 固定Species包络/可编辑Subspecies/个体Genome/实际生理训练分层，力量耐寒耐饿等完整落到能量/体温/伤害与物理能力，不能靠性格标签替代。
3. 坡道是实体单值连续上表面ramp_patch，普通height量子500mm，坡角125mm；真正通路/水网/拾取/碰撞同源。所有移动Actor高峰禁入，包括飞行，降低真实高度才能解除。
4. 高处冷，真实保温/湿度/食物代谢与基因耦合；两Age仅光环境，不加日夜/公转/季节。物种边界/峰禁区优先于耐寒耐饿天赋。
5. 加原生动物、真实繁育/食性/捕食/畜产/护理/授粉与有源感染，取消原“无动物/无基因”的范围。禁止神力放置反复宰杀刷货。
6. 文明之光只由玩家将现存动物赋予高级意识，保ID/身体/年龄/伤物；后代任一同species合法亲代启智即可继承，此为明确本轮设计选择。不能由gene编辑/复制/载入/自发演化绕过。
7. 启智者可学人类Language加入人类Culture，并有完整社会公民/知识/政治能力；文化/语言创生及正式语言分化发起资格仅人类。高级意识动物成熟按species，人类18；全龄固定各species成人体规。
8. Family/Household/Dynasty/Subspecies分离；首次统治者/世袭/选举/限定候选/摄政与私产继承完整定义。元控制/附身/视野/城界画笔、防御墙门、typed信息/统计/清理/本地产品能力适配加入，无免费人口/材料/魔法buff。
9. WorldBox248项逐项处置102新增、59改造、63保留、15排除、9证据边界。事实保持官方发布/预告/社区线索区别，不声称未知公式或按钮全集已穷尽。
