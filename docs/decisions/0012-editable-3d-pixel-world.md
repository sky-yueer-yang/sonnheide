## 非平凡的边界

1. **三种不同的尺度。** 地形格、建筑构件/导航净空、贴图texel是不同单位。一个人的面部可以有64×64个texel，无需把人物建成几十万个体素；一个2m地形格也不能直接代表人的步高。
2. **单份有效地表。** 高度、材质和水位决定真实表面；渲染、射线、碰撞、建址和导航读同一修订。Biome不是高度、森林不是另一层可站立地面、海浪不是水深。
3. **拓扑与损坏一并提交。** 一格海峡可影响远港；改地同时撤销失效通路/运营许可，处置物件和账本。异步mesh/路径候选不决定死亡、财产或新的水域事实。
4. **空白与真实来源没有两套游戏。** Earth岸线量化后只构造同一种TerrainWorld；Blank不依赖地理包。真实数据不导入现实居民/城市，也不冒称含真实海拔。
5. **旧证据不能继承新完成度。** 旧PBR阶段1与修复截图是旧客户端证据；新高度地形、像素人物、Godterrain与迁移器均须重新验收。

## 当前明确的首版

表面采用分块高度列，一列一个顶面及立面，不采用全世界稠密体素，不支持洞穴/悬空自然陆块。首样本profile为2m格、0.5m高度量化、64×64格chunk，参数是待样本校准的配置；选定profile在该世界创建后冻结。高分辨率人物来自贴图和造型细节，不能以增大世界格密度替代。

地形工具首批八类：Shallow Water、Close Ocean、Deep Ocean、Sand、Soil、Hill、Mountain、High Peak。工具是预设组合，权威数据分为高度、表层材料和水体关系；沙/土可以只换材料保高度，抬高/降低/夷平/平滑另有明确模式。山体刷有宽度、中心高度及阶梯坡型，不生成单柱假山。

首版海、湖共用静水位0；地面低于水位则为湿格，水深由水位减海床高度派生。四连通到有限外海源的水域为SEA，隔离水域为LAKE。内陆画Deep Ocean实际是深水湖，连海后才是海；不做高位湖、瀑布、体积流体、潮汐或侵蚀。Light/Darkness只改环境，不结冰、不改变水深与地形。

Godterrain不耗文明材料，但来源明确，不产商品、矿物库存、人口或工程退款。保护笔刷显式跳过将破坏资产/人口的目标；破坏笔刷在有具体后果时提供一次紧凑批准。编辑范围是权威可玩域，远海外沿保护带与域外仅渲染海不开放；命中越界直接拒绝而非clamp。预算内世界仍能建成岛、山脉和海峡，视觉外海连续。

地形编辑后的安全迁移、困住/落水、建筑失效、港口搁浅、货物报损、城市应急及撤销规则详见[地形事务](../architecture/PIXEL_TERRAIN_TRANSACTIONS.md)。无条件undo不得复活人、退回已消费货、恢复有经济后果的旧世界。居民应急转移必须有真实可达空间、容量与时间；没有安全路径时风险必须真实存在。
