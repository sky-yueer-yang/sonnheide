# ADR 0006 · 地图中心、底部分区工具栏与英汉德编辑界面

日期：2026-10-06。状态：采纳用户本次前端与工程计划变更。继承ADR 0005的稳定引用、人口来源、统计和清理合同；本文改变界面组织，不撤销世界不变量。原始v0.6设计逐字保留。

## 决策

1. 游戏采用地图中心布局。所有**全局工具**集中在最底部的固定工具栏，以section切换工具组；取消当前原型的顶部工具排和常驻左侧40类目录。地图点选、悬浮/选中标签与对象窗口保持近距离关联。
2. 底部有section行、当前section的工具行和紧凑状态/工具参数。设置、界面语言、世界统计、收藏、搜索、世界规则及分类清理均从这里进入。对象窗口中的关系、页签、关闭、返回和提交属于该对象局部操作，仍在窗口内。
3. 对象窗口复用40类InspectorRegistry。默认概览；关系跳转打开同一窗口并记录浏览历史。窄屏采用工具栏上方的可滚动抽屉，窗口和模态不能盖住工具栏，也不能将点击泄漏给地图放置/清理。
4. 界面首批语言为简体中文`zh`、英文`en`、德文`de`。切换仅更新玩家界面偏好，不改Person的语言技能、国家行政语言、文化、名字或世界修订。消息、工具提示、错误、辅助说明和可访问名称统一使用message key；实体专有名与玩家自写文本按原文保存。
5. 信息页提供可操作字段编辑。人物采用源设计的六性格轴；国家宗教地位、官方宗教与法律采用有类型的编辑草案和后果预览。用真实合法程序表达制度变更，不能靠一个checkbox吞掉帝国/条约、科技门槛或财产。游戏页面不出现裸JSON覆写入口。
6. 草稿值、预览版本与已提交状态分开。换section、查看关联、改界面语言不静默提交或丢草稿；实际提交复核世界修订、目标、权限和依赖。被拒绝时保留用户输入并解释可修复原因。
7. 新施工计划将原创建筑、人物服装及原创UI美术放在最前面开始，并与窗口/内容加载/地形工程并行；按可运行贯穿切片退出阶段，不等待全经济完成才处理资产。

## 权威与实现边界

生产客户端仍采用C++20、SDL3、bgfx、RmlUi等独立库和自研框架。`tools/previews/world-inspector.html`是示例数据交互验收；它的底栏、语言切换与编辑不能冒称原生客户端、生产World、完整法域或资产已经接入。

生产设计见[UI_ARCHITECTURE](../architecture/UI_ARCHITECTURE.md)、[EDITING](../architecture/EDITING.md)和[CLIENT_STRUCTURE](../architecture/CLIENT_STRUCTURE.md)；施工阶段与退出门槛见[IMPLEMENTATION_PLAN](../planning/IMPLEMENTATION_PLAN.md)。计划目录不先建空壳；实际完成与测试记录写入[VALIDATION](../planning/VALIDATION.md)。

## 参考方法

官方更新记录确认WorldBox有底部power bar、分区tabs、工具提示/快捷键、近景对象/远景元对象点选、关联窗口与选择历史。[WorldBox官方更新记录](https://www.superworldbox.com/changelog)。据此采用统一空间入口与分区操作，不复制其美术、代码或游戏机制；我们的section按本游戏领域重新安排，冻结地形、原创建筑、实物经济与18岁放置规则不受参考游戏影响。
