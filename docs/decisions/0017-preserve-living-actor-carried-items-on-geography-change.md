# ADR0017：地理改写保留活生命及其随身物品

2026-10-09；v0.8接受的设计修正，生产未实现。用户明确要求衣物、携带工具等非生命物品保留，所有跟着生物的东西保留，植物建筑等清除。覆盖ADR0015中命中生命穿戴/携带物也核销的规则；其他地表毁损、城市连续性、真实危险和决策约束继续。

以提交前旧状态合法积分后的冻结快照为准，先求活Actor实际穿戴/握持/背包/携行绑定和递归内容保护P，再求真实变化footprint的完整地表/support/container毁损候选C，最终删除非生命D=C\P。人、普通动物、启智动物同规则；被删楼/车/船的室内Actor及其随身子树仍保护，不能向上保护整楼/车船。外部活Gestation原身份保护继续。

保实际Ref、数量、owner/custodian、耐久、湿度、到期、body-relative绑定、装备能力、枪膛/装填/冷却/随机计数。搬运第三方货同样保护。仅owner相同、任务预约、跟随目标或未来待领取不是实际携带；地面/仓储/独立货舱可删。源树/仓库被删不能按来源引用连删已真实收获且携行的果木批。衣物保留不赠保暖buff、不回满，也不阻正常落水浸湿、食品腐坏、磨损或后续生命危险。

目标仓/接货口被删，只撤实际失效目标/路线预约，保在途实际货和产权，安排真实新配送/返运；不传回仓库，不计随身wipe loss，不复制可用库存。只有确实被毁对象生成物损，P与loss refs不相交；实际死亡后遗产仍用当时真实物品，已毁地表物不重现。

保护集依赖Actor生存、装备、握持、容器、交接和空间revision，预览后拾取/放下/脱装/交接改变集合必须拒绝旧预览并重算；完整候选单写者一次提交。该修正不开放免费修理、复制、恢复建筑或生命复活。

现行入口：[地理改写](../architecture/GOD_CONTROL_AND_GEOGRAPHY_MUTATIONS.md)、[god_control_v1](../../data/contracts/god_control_v1.json)。主设计、像素地形、城市/动作、经济/政治/军事、前端清理、阶段2与验收同步。旧报告保持历史；当前[统一核验](../planning/DESIGN_AUDIT_ADR0017.json)仅证明合同与有限模型，不证明生产游戏。
