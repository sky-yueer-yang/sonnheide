# ADR 0011：Poly Haven、Hex-Tiling、有限世界远海与同精度选区

2026-10-07 · 已采纳。依据用户最新指定与随后确认的“不规则海岸过渡”。本文覆盖 ADR 0010 中“选区边不是海岸”的绝对表述；普通数据块边仍绝不是海岸。原始设计稿不修改。

**决定：** 地表采用 Poly Haven 扫描材质与 mmikk Hex-Tiling；天空采用 Poly Haven Pure Sky 的固定 Light/Darkness 两套配置。创建界面提供可平移缩放的真实全球地图，选区最高级预览与游戏地表共用渲染路径和生成定义。世界仿真有限，外侧只呈现连续大海与天空，没有地图围框、实体墙、海面尽头或天空盒接缝。

这是正式工程合同和来源准入。2026-10-08阶段1已接入全球导航、full冻结地表、PBR/Hex GPU、天空/SH9/GGX、静态远海及可靠空世界首checkpoint/发布；实际证据见[阶段1验收](../planning/PHASE1_ACCEPTANCE.md)。完整Abyssal动态水、阶段2权威环境计时和完整游戏界面仍待施工。实际源件状态见[资源锁](../../assets/manifests/ground_sky_sources.json)，实现顺序见[施工计划](../planning/IMPLEMENTATION_PLAN.md)。

## 1. 四个必须一起解决的问题

1. 裁切大陆后，选区外若全为海，就必然形成新岸线。必须在创建前生成、预览和冻结，不能进入游戏后才偷偷改海陆。
2. 最精细的预览必须预览游戏实际绘制的地表。卫星照片、放大的粗略矢量或一张超大图片均不能证明这个承诺。
3. 海面看似无尽不意味着无限世界。港口需要真实有限 WATER，外侧表现海不能生成航路、人口、财产或材料。
4. 消除纹理重复仍须保持 PBR 各通道对齐、真实纹理尺度、跨块连续与受控成本；不能只对颜色随机旋转。

## 2. 三个空间域与冻结边缘

|域|内容|权威与交互|
|---|---|---|
|S：玩家地理选区|真实来源海陆；最外侧允许窄带自然化裁切|内部真实海陆不改；边缘最终结果在确认前展示|
|G：有限游戏域|S 加一圈明确计入预算的纯海缓冲|真正的 World 格、航路与合法填海；全部有限|
|G 外：表现远海|连续海面、天空、雾与反射|无 World 格/身份/航路/产权/货物；不可放置、建设或填海|

海缓冲不是另取选区外真实陆地：选区外一律海，不能在水平线、反射、地图 LOD 或天空里漏出被排除的大陆。G 的宽度、格数、缓冲宽度和外沿保护带随候选定义冻结、保存，并在创建摘要的“包含海域”中解释；不暗中扩大仿真预算。

G 最外沿为永久纯水保护带。它不是城墙、建筑或可编辑 World Law；拒绝在此填海/造陆，防止玩家把土地铺到权威域尽头后重新露出硬裁切。S 周围一般海缓冲仍按真实材料、劳动、四邻接和完工 LAND 的旧规则允许造陆。保护带不得侵入真实选区、截断已有支持地块或任意扩展到正常海岸。

保护带宽度至少覆盖最大获准船体包围体、转弯/制动走廊、导航余量和允许填海工程的隔离余量；数值由合法内容规格与实际地图预算决定，不拍脑袋固定为若干米。路径的完整船体扫掠保持在合法有限水域内，规划时就转向/返航；不依赖隐形墙碰撞、瞬移、删船或把越界坐标 clamp 回最后一格。目的地不可达时给出原因，既有人员货物保留。新船规格超过冻结域的安全裕度时必须拒绝该规格或限制其允许航行方式，不能修改冻结域。

### 2.1 自然化闭合岸线

用户已选择“不规则海岸过渡”。设边缘自然化宽度为 B：核心区 `S ⊖ B` 的源海陆逐点保持；只在 S 内侧最外圈产生平滑、有界、非重复的裁切轮廓 N，`S ⊖ B ⊆ N ⊆ S`。最终陆地为 `SourceLand ∩ N`，只移除裁切带内的源陆地，不把源水域变为免费 LAND。

配方先构造圆滑拐角的内收轮廓，再以低频有界偏移形成长短不一的海岸凹凸；波长、振幅、最小通道/岛宽均以游戏米和源几何分辨率计。独立 boundarySeed 和 CPU 确定性配方决定轮廓，不消费仿真 RNG，不用 GPU sin-hash 决定权威海陆。轮廓必须完整闭合、无自交，并逐项验证上述包含关系；不合格时返回草案错误，不静默扩大 B 或改核心。

窄岛和完整来源岸线不因显示 LOD 被侵蚀。小选区无法同时留下足够核心、岸带及海缓冲时，要求扩大选区/改合法比例；不保证任意一格内陆都能变成自然、可生活的岛。最外圈被裁掉的岛、开口湖及河口变化必须在最终预览出现。现阶段不另加河流水文系统。

来源岸段标记 `SourceCoast`；由裁切产生的岸段标记 `SelectionClosureCoast`，保留 source provenance。两者都使用同一冻结窄岸坡规则：普通内陆统一略高于水面，岸边缓降入水，水下浅滩仍为 WATER。普通瓦片边、LOD 边、相机边不产生岸坡。创建后填海不重算天然/闭合岸线或原始岸坡；所有陆地仍无现实海拔。

截开的来源湖可能与外海连通。源 lakeId 可作为出处保留，最终世界的海/湖连通与 Port/船路径按裁切后的完整水域重算；不能把已接外海的水继续判为封闭湖。完整湖、湖中岛和嵌套水陆按来源拓扑保留。

### 2.2 游戏视野中的无终点海面

近处用随相机重定位的有界海面网格/环带，远处接覆盖所有可见方向的海天线表示；具体实现可择等价方案，但固定有限大四边形不是验收答案。近远海共用水面高度、世界锚点、Abyssal 相位与反射环境；浮动原点只改变提交坐标，纹理/浪相位不随相机游走。海面可覆盖视锥，仿真域绝不随它扩展。

雾只软化衔接，不能承担隐藏终点的全部保证。所有允许的最低/最高镜头、俯仰、360°朝向、全景比例、DPI、窗口缩放及浮动原点都不能看见直边、背景漏色、裁切环或水面断层。相机焦点和最大缩放有明确定义的允许范围，镜头可看向远海；创建完成后不保留选框或常驻边界线。地块操作越界时可显示必要的临时原因，不能为保持美观伪造有效操作。

## 3. 地表：扫描材质与一致 PBR Hex 采样

首批来源：brown_mud、grass_ground、sparse_grass、forest_leaves_02、dry_ground_01、sandy_gravel_02、sand_03、damp_beach_sand。这是泥土、浓/疏草地、落叶地、干土、砂砾、干/湿沙的表面库，不是新增八种权威地形或八个自动生态系统。材质角色、作者、物理覆盖尺寸、原始通道、URL/大小/MD5/SHA-256见资源锁。

锁定原始 2K PNG 三通道集合：base color、OpenGL normal、ARM。它们是可复建的首批材质源，2K 不代表全球地图最多 2048 像素：同一小片扫描纹理以固定游戏米尺度覆盖大地；空间几何与远近显示分辨率分别管理。未来提高源分辨率须新增锁与对照画面，不能把纹理上采样当新增真实细节。

固定 mmikk/hextile-demo 提交 `43c3ed7e18e1e4539fa9323f72d5e2a65147ebb3` 的 MIT 算法源，保留 LICENSE、两种 hextiling 和 surface-gradient 参考。归档是移植输入，DXUT/HLSL demo 不作为游戏引擎或运行依赖。[准确源锁](../../third_party/hextile/UPSTREAM.json)

移植的关键约束：

- 三角网格邻域、候选变换及随机索引共用于同一套 PBR 通道；base color 以 sRGB 输入、线性光照混合，normal/ARM 为线性数据。ARM 明确 R=AO/G=roughness/B=metallic，不猜通道。
- 旋转 UV 的同时旋转采样梯度；normal 的切向方向必须逆变换/重新投影并规范化。采用 surface-gradient 合成或经过验证的等价法，不把三条 RGB 法线直接相加。
- 演示中的颜色与法线权重策略并不自动保证整套 PBR 对齐。先确定共同几何候选与共享基础权重，再验证色彩防发灰/方差处理，标明针对不同量的归一化；禁止每通道单独随机造成湿度、石子与凹凸错位。
- 纹理按来源物理尺寸映射游戏米；人物/楼体尺度不随经纬瓦片或视角变化。跨块、跨 LOD 与浮动原点保持相同世界采样坐标；大索引的乘法溢出必须处理。
- 低频混材控制草/土/湿沙分布，中频 Hex 打散重复，近景 normal/roughness 描述微观表面。低频噪声不改变权威海陆，不新增可采资源。落叶纹理不生成库存，真实树/矿仍由后续领域合同决定。
- displacement 初版只可用于受控近景着色效果；不做真实地形位移，不凸起成山、不改变支持几何/导航/建址。先验收平面、岸坡、PBR 与正确 mip，再据画面证据增加可选效果。

先做一个原生材质验证场：8 种表面、跨块、岸坡、掠射光、远近 mip、两种 Age、普通重复/Hex 对照。记录 GPU frame cost、texture fetch、VRAM 和接缝；不先加载全部最高分辨率。2K BC7+BC5+BC7 完整 mip 约 16 MiB/材质、8 套约 128 MiB；这是压缩内存估算，Metal/Windows实际格式、质量和测量仍须验证，不当实测预算。纹理转换、mip、法线重整、压缩产物均保存配方及工具版本。

## 4. 天空：固定明暗，天空与反射共用

|环境|选择|意图|
|---|---|---|
|Age of Light|[Kloppenheim 05 Pure Sky](https://polyhaven.com/a/kloppenheim_05_puresky)|晴朗云层、有体积感与宏阔天空|
|Age of Darkness|[Qwantani Night Pure Sky](https://polyhaven.com/a/qwantani_night_puresky)|深蓝夜空与银河；地表仍保留必要可读性|

只选纯天空版本，避免拍摄现场山、树、房屋混入世界背景。两张8K原件的全部像素解码及地平线检查已通过，未见可辨识山/楼/树/道路，但夜图仍有明显青白/橙色地平线辉光，日图下半球有模糊填充拖痕与小黑斑。游戏派生配方必须处理这些拍摄/填充痕迹：保留可信上半球天空，校正近地平线残留辉光，以连续、无地物的环境延拓替代有瑕疵下半球；极点/360°接缝、能量与颜色连续性要在原生立方体和海面反射验收。原始文件保持不变，不能直接把完整摄影图当作最终GPU环境。两套 8K 原始 HDR 进入来源包，预处理为立方体、diffuse irradiance 和 roughness-prefiltered radiance，保存源 hash、线性色域、固定 yaw、环境强度、曝光、转换/过滤版本和产物 hash。不加载 24K 原始图常驻 GPU；桌面档位选择合适的 cube 分辨率和压缩，天空/反射不同分辨率仍来自同一个处理后环境。

天空背景、地表 IBL、海面反射与主光方向保持一致。HDR 摄影曝光不是照度标定；已核验小样的夜图均值接近日图，故“换夜图”不等于游戏自动变暗。Darkness 使用固定较低环境强度和曝光约束，禁止自动曝光把黑暗补成白天。亮太阳/月盘与显式主光的能量不能重复累加；可移除卷积环境中盘的直接光贡献并由固定主光承担，或使用经测量的等价方案，记录决定。

不做自转公转、太阳运动、天气、日出日落或新增 Age。初始手动 Light，未来自动由已有仿真 tick 合同切换；短交叠只负责呈现。夜里点灯仍要求真实可用灯具及后续供给，不赠照明对象。

## 5. 创建流程与最高可见精度

### 5.1 全局导航 → 最终地表预览

创建页以地图为画面主体，全球岸线高质量抗锯齿、深海与克制陆色。拖拽平移；滚轮/触控缩放以指针位置为锚，缩放后地点不跳；双击放大，双指平移/捏合（设备支持时）；键盘有等价操作。显示选框只在创建页，拖动边角调整，完成后可点“预览地表”。核心是地图，不铺满侧栏卡片、图标和说明。

全球/区域导航使用完整锁定来源的 full/high/intermediate/low/crude 矢量金字塔，按屏幕误差选 LOD。它只是宏观导航。选择后生成只读 Draft，逐步切换到游戏同路径的正射地表预览：同源 full 岸线、闭合边、海缓冲、平面/岸坡、Poly Haven 物理尺度、Hex、Light 环境和画质配置。浏览器缩放原型不代替原生 bgfx 对照验收。

最高级地图的 `gameMetersPerDevicePixel` 达到游戏最近允许镜头在相同 framebuffer/DPI/画质下的地面清晰程度，且屏幕几何误差目标一致。上限由草案 worldScale、投影、游戏近景镜头、材质/纹理档和像素密度共同决定，不能硬写地图 z18/z23。相同源可持续细采样，但不得在最大缩放时伪造未取得的 full 几何。

地图和游戏观看角度不同，所以不承诺整屏截图逐像素一样；固定正射校验镜头下必须同几何、同材质与同采样。真实游戏旋转/掠射效果由游戏材质路径实现，不能让一张预渲染卫星图冒充结果。现代楼、道路和国界不进入零文明预览。

### 5.2 数据准确度不等于图片清晰度

优先路线仍是 GSHHG 2.3.7 官方原生 binary，保留湖泊、湖中岛/嵌套水体和南极轮廓选择。官方维护者明确来源较旧，不适合所有大比例尺用途：full 表示未简化，不能承诺米级现实岸线。真实源准确度、逻辑格尺寸、表面采样与屏幕纹理清晰度分别记账。任何更精细地理替代都先逐项核验来源/许可，再固定版本与完整 SHA。

2026-10-08已取得并锁定完整官方binary ZIP 118,617,033字节和五个LOD成员，C++每次准入独立校验SHA。GSHHG 2.3.7/full是真实生成依据；导航LOD不改最高地表。[锁](../../data/geo/gshhg_sources.lock.json)及[验收](../planning/PHASE1_ACCEPTANCE.md)列出实际版本、南极ice-front选择、极区/日期线及湖泊/小岛验证，不承诺旧source具现代米级测量准确度。

日期线选区围绕中心展开经度并拆源窗口；极区按完整投影多边形处理，不只投四角。当地水平投影的有效域、形变和同一 worldScale 必须验证；大区域形变超预算时给出改选范围/比例建议，不在 shader 中悄悄拉伸。局部真实精度无法支持某窄岛/海峡或建址时，明确限制或拒绝，不因 PBR 漂亮就通过。

### 5.3 一个不可变草案描述创建与预览

`WorldDraftDescriptor` 必须包含：source release/manifest/fullGeometry SHA、source quantization/accuracy或 unknown、WGS84 selection 与投影后 polygon、projection/model/version、worldScale/cellSize、N/G/海缓冲/保护带、boundaryRecipe/boundarySeed、waterY/landY/coastProfile、finalLand/waterTopology/surface SHA、materialRecipe/贴图 SHA/物理尺度、Hex shader版本、visualSeed、Light sky/IBL profile、renderPreset。

最高预览和创建从该描述派生，不再执行一遍可能不同的地理算法。确认前校验同描述哈希和完整源就绪；改范围、比例、自然化参数、配方、质量档递增 revision，旧清晰预览失效。只动镜头不改权威地理哈希。来源缓存可按不可变 source SHA 共用，投影/裁切/着色缓存必须绑定草案指纹。

异步结果绑定 `SessionGeneration + DraftId/revision + recipeHash + tileKey` 和取消令牌；过期结果可放进正确的不可变缓存，但不得覆盖当前选区、预算或创建批准。瓦片请求按可见区域优先、有界队列/内存/LRU、取消和背压处理，不因连续缩放无限排队。游戏离线使用项目来源包，不依赖地图 API key、广告或在线第三方底图。

完整 full 源缺失、精细预览未准备好或预算不合法时，“创建世界”保持不可执行并给一个明确原因。保留已选择位置和草案，不假清晰、不假成功。最终确认展示实际初始地表、包含海域、世界名称/尺度和零人口零建筑；生产候选仍先校验、首存档 durable 后才发布，旧世界与 Continue 指针保持既有可靠交接合同。

## 6. 创建页视觉与三语

沿用深沉、新古典与极简风格：地图占绝大部分，光照克制，细致海岸与纹理作为主体；控制集中在底部，必要选区摘要按需打开。主菜单的油画/Logo/紧凑纯文字布局保持既有决定，创建页不复制庞大钟盘遮挡地图。

所有按钮禁止 border、outline、ring 或伪元素形成变相边框。以字重/明暗/柔光表达 hover 和键盘焦点，地图选区轮廓属于地理编辑覆盖，不是按钮框。无需图标的文字动作就纯文字；缩放与定位可使用含义明确的少量图标，并有三语可访问名称。不要装饰性小字、重复提示、经纬调试数或处处画质徽章；具体错误和选区后果属于必要业务事实，应使用正常可读字号。

页面的 zh-Hans/en/de 同步排版和术语，UI locale 与世界 Language 分开。流转：创建入口→全球地图→选择范围/尺度→检查同路径精细地表→命名确认→准备/可取消→进入空世界。名称和技术来源可按需展开，地图上不留冗余多步“下一步”按钮。卡住时保留地图位置并提供可行动的原因。

## 7. 程序归属和施工门槛

|责任|目标文件/模块（首次实现时才建）|禁止跨越|
|---|---|---|
|地理源工具|`tools/geo/`：官方源→多级矢量索引、full几何、拓扑、来源报告|不把显示粗档变为最终mask|
|候选定义|`engine/world/`：投影/边缘/纯海域/冻结profile、只读Draft、哈希|不分配生产人口/实体、不依赖GPU|
|创建交互|`client/application/`、`ui/application/`：全球导航、指针锚缩放、草案/错误/取消|不自持另一份可写World|
|共用地表绘制|`presentation/renderer/`：PBR/Hex、岸坡、mip、正射预览与游戏视图|不由像素/LOD决定LAND或合法入口|
|环境与海洋|`presentation/renderer/`：两套天空/IBL、Abyssal近海、远海衔接|不增加天文/天气或无限可玩海|
|来源/制作|资源锁、原始源码、来源包、转换配方、notices、Release|不提交本机缓存，不把资产原始源称作游戏ready|

阶段1先实现全球导航交互及一个 full 区域的同路径预览，继而补齐全球选区可创建的源覆盖。全球导航上线不表示全球生成已验收；正式对玩家宣称“全球可选”前完整全球 full 包与所有准入路径都必须完成。所有此处地表/天空/UI 任务仍在建筑制作之前；阶段2保存载入/返回门槛通过，阶段3才开始新建筑/人物/服装制作。

贯穿验收包括：全内陆选区闭合、截湖接海、真实岛/窄海峡、普通瓦片无假岸坡、港口海缓冲与连续泊位、填海不动冻结岸坡、保护带拒绝与无货物损失、最高预览/创建描述相等、固定正射画面对照、日期线/极区/形变、过期请求与取消、连续缩放缓存上限、所有允许镜头无海面终点、两 Age 的天空/IBL/反射一致及Darkness不被补亮。
