# ADR 0001 · 自研框架与初始边界

日期2026-10-06。状态：初步工程决策。前提是本轮用户明确“不用游戏引擎，全部自己搭”；设计原稿20.10允许Unity/Unreal的描述被该新要求覆盖。

1. **C++20原生仿真与生产桌面客户端**。长期高人口、布局热列、共享原生资源与稳定跨平台工具链是理由。TypeScript旧参考若之后取得，只迁移经过验证的规则思想和fixtures，不把旧领域契约数量视为成果。
2. **SDL3负责平台，bgfx负责GPU提交**。不引入Unity、Unreal、Godot或通用游戏编辑器。我们写场景、相机、PBR/water通道、LOD、选择、工具、调度和资源管理。SDL_GPU只作为bgfx平台桥实验失败后的单一替代，参见 [调研](../research/OPEN_SOURCE_STACK.md)。
3. **一个世界、一个写入屏障**。领域提出写集，可信调度器授权，提交时重验。暂用整状态copy-on-commit形成oracle；生产改写集/页事务。回执必须与世界同时提交，内存失败不能破坏幂等。
4. **数据驱动定义、有限机制**。424项科技不是424个system；普通消费品为批次。货币与物品分账，实际资产才有独立ID。复杂企业、教会和国家不强行转换成每帧ECS对象。
5. **建筑全部原创**。可以复用材质、人物基体、动作、动画库和DCC工具，不能用开源码头/楼房替代建筑制作。先完成灰盒权威合同，再制作写实模块与三时代变体。
6. **地理源离线打包**。沿用原稿GSHHG2.3.7候选，许可证原文和重建输入与配方一起托管；没有在线地图库/现实城市人口注入。地球天然边界与人工造陆分层。
7. **所有项目作者源与正式分发输入可由本项目GitHub取得**。小文本Git，大二进制LFS，大源归档/发布包Releases固定版本。当前公开仓库可直接发布这次明确要求托管的文件，但不变更原创作品的许可。
8. **按可验收切片增长，不堆空目录**。A-F覆盖完整设计。最先突破平台桥、海岸一致性、拓扑更新、公共经济死锁、时钟/噪声语义；后续私企/金融以共享基础完成后接入。

权衡：选择C++会增加编译、资源生命周期和调试成本；选bgfx仍需自研写实管线，不能获得现成引擎编辑器。最先做平台与可见负载实验，失败时仅替换GPU适配边界。不得因难度回退到违反“不用引擎”的方案，也不得以截图代替真实工作负载。

变更条件：必须有具体平台阻塞、测量、许可证缺口或设计冲突。新ADR描述证据、替代影响、存档/资产兼容及验收。纯粹换一个等价术语或库名不能算工程推进。
