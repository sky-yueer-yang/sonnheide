# ADR 0013 · 三层地表、八种主题与真实果树

日期：2026-10-08。状态：用户已确定的设计方向，生产实现待验收。按用户最新要求覆盖v0.7原十类自然生态目录与随后十四类建议；[ADR0012](0012-editable-3d-pixel-world.md)的高度列、海陆、水深、Godterrain/文明工程、原创像素和Steam规则继续。原始v0.6与旧来源/验收保留，不覆写。

## 1. 每个地表固定三部分

|层|当前职责|状态与权威|
|---|---|---|
|地面地皮|主题像素纹理、色板与地被覆盖；适配真实顶面和立面|当前高度/水深/支承仍由TerrainWorld决定；主题不能把海变陆|
|小型植物|花、草、芦苇、枯草、零星低矮装饰|纯表现；没有经济库存、采收、生长任务、碰撞/通行惩罚或独立生命实体；按持久seed/密度/清除mask复建|
|树木|真实可砍伐树；部分树提供可采食果实|稳定TreeRef、位置/权属/生长/condition/可采量/预约/事件；受地形和建设影响，消费真实时间劳动与搬运|

农业庄稼仍是独立农业设施/生产批次。它们不属于主题中的装饰花草，既有粮食、纤维、衣物生产规则不删除。绘画小植被不生产粮食/木材，也不创建额外阻路的Actor。

## 2. 用户确定的主题与沙地

|主题ID与三语名|地皮/装饰方向|功能树|
|---|---|---|
|snowfield · 雪原 / Snowfield / Schneefeld|蓝灰阴影的雪面、稀疏覆雪装饰|松树；常绿分层树冠，局部积雪|
|flower_meadow · 花甸 / Flower Meadow / Blumenwiese|嫩绿地皮、大量分簇热带花；保可读留白|多种果树；首样苹果、梨、桃、橙、芒果、石榴六类候选，规格/产量待校准|
|maple_field · 枫原 / Maple Plain / Ahornland|暖土、落叶地被与少量低草；金/橙/红成片协调|枫树；固定变体，不需要太阳季节循环|
|cherry_field · 樱野 / Cherry Blossom Field / Kirschblütenfeld|淡粉/浅绿地皮与克制小花；不可整屏粉白曝光|樱花树；稀疏落瓣、缓慢飘落/翻转，落地淡出|
|wetland · 湿地 / Wetland / Feuchtgebiet|深绿湿润地皮；芦苇为装饰|菩提树；真实湿/干和水深由高度决定，主题不排水/赠站立面|
|savanna · 荒原 / Savanna / Savanne|赭黄土、枯草，裸露地皮与植物团簇相间|胡杨树；不改成金合欢/普通草原树|
|sonnheide_sacred · Sonnheide圣原 / Sonnheide Sacred Plain / Sonnheide-Heilige Ebene|深沉地皮、白金/淡蓝低植被；光辉有主次|原创圣树；树干/枝叶发光，有受控局部树光与柔光，仍可砍，非免费灯具/能源/宗教增益|

这是游戏的原创风格组合，不把松树/果树/菩提/胡杨的游戏适宜性说成现实气候学。雪原与热带花甸可以相邻；环境Age仍只有Light/Darkness，不引入季节、气候模拟或太阳系统。

八主题是生态/风格，不替换八种几何地形预设。沙地是材质habitat而非第九个soil主题；干沙上默认新树为椰树且没有小植物。水下沙仍WATER，沙池不自动长陆生椰树。裸土/裸岩无主题是中性编辑态，不另增加必选群落。

## 3. 果实是附着在树上的实物

果树定期分批形成新果，数量逐渐增长；每批果经历形成/长大/成熟阶段，大小和颜色取实际年龄。不同树种有独立外观/容量/形成节奏/成熟时间；参数随定义版本保存，不用季节计算。不是全树在一个瞬间统一红、一次重刷免费满果。

树上果有有界附着批次、数量/成熟进度、可采/已预约量和年龄。采摘只取成熟可采的真实部分，经现有任务/路权/授权实际到树、劳动、转入携带/货批并搬运；直接吃仍先采摘再由同一消费账本结算。重复命令、换主题、存载、LOD和镜头不生成果、不恢复采完库存。满树停止新形成，lastTick仍推进，不累积满树期间的未来补果额度；有界果批不能合并不同成熟/腐坏期限来提前成熟或延迟腐坏。

树木砍伐与采果共享版本/预约，不能一边给木材一边另复制已摘果。倒树时树上现货按实际位置和损失/可回收政策处理；未熟果不直接变成食物。树木condition、生长/结果和灾损在离屏时照常按SimTick推进，装饰花草不参与这套调度。

## 4. 绘制、恢复和既有对象

生态刷改变地皮/装饰配方与新树候选池，不改既有树的物种、年龄、果量、库存或产权。可联合预览真实植树候选，确认后用有界种植事务生成幼树；重复涂已占位置不重种、不满果。玩家神力种植核当前Godterrain规则，生成零可采木/果的幼树；文明回种核真实苗种/劳动/路径/权利，野生新株只由受恢复开关约束的可信有界调度产生。人工重植/替换树群是明确清理/种植过程，同步材料/预约/权利后果；模板复制仅地表字段，不复制真树和附着果。

自然恢复开关只管理新的野生树萌发/传播，关闭不冻结已有树的成长/结果，也不暂停农业；开启不补发停用期间树。道路、建筑、门、车道、接货/施工区及农田的LandUse/净空阻止野生树侵入。装饰可以在合法庭院存在，但同样避开必要表面与净空；树冠/躯干的表现和权威占用分别核验。

改地、淹水、抬升/埋根同事务更新树支承/condition/预约/真实果木损失。填回原高度不复活旧树；有实际安全地/合法任务可重新种植。圣树的内源发光来自仍存活的真实树表现，不需要为它自动发电；树死亡/伐倒后状态控制光，GPU光预算与镜头不反改树生命或经济。

炎地的熔岩首版为固定有界地皮效果/表现片区，不是另一种权威海、流体或可采矿。绘制炎地不触发随机火山喷发、蔓延、灼伤或建筑焚毁；这些若以后需要，先明确独立静态危险/物理合同，不以shader亮度暗中判伤。

## 5. 落地合同与验收

完整[三层地表与树木](../architecture/SURFACE_ECOLOGY_AND_TREES.md)、[像素资产](../architecture/PIXEL_RENDERING_AND_ASSETS.md)与[机器合同](../../data/contracts/surface_ecology.json)规定接口；当前均为planned。三语工具与TreeRef关联复用现有稳定信息页，必要果量/可采/木材与任务正常字号展示。P0锁地皮/树根/冠/果/落瓣/圣光预算，P1—2先同路径地表与占用fixture，P3正式树果花资产，P4真实砍伐采食，P5接完整农业/公共资源链。

验收必须覆盖渐进果实与变色、采摘/砍伐竞态、重涂不补果、装饰不可采不可阻路、沙上无草/水下不长椰树、圣光LOD/毁树一致、稀疏落瓣/降低动态、炎地不伪造物理、淹树/建路/任务取消，以及跨生长节点存载与离屏重放。文档/registry通过不等于CPU行为/GPU/可玩城市已完成。
