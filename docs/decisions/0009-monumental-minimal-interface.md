# ADR 0009 · 纪念性极简界面与纯文字主菜单

日期：2026-10-07，同日最新修订：品牌中心左上向内，主页字体略小，文字/射线/光晕共用#fff6df；完整多圈内环、无射线窄空隙、几乎贴着内环的细三层外圈及低亮密集外射线；外圈大幅缩小、边缘减细，射线降低亮度和辉光，字体和Logo柔光不变。覆盖本ADR上一版过大的亮中心及完整仪器居中构图，也覆盖[ADR 0008](0008-sacred-interface-and-light-ages.md)旧“所有动作必须含图标/禁止纯文字按钮”。标题右移、菜单右下紧凑、小中央亮焦点/大部分渐暗、油画节奏、无边框、两种环境和基础优先施工顺序继续有效，原始设计源不改写。

## 决策

1. **禁止不必要的小字。** 主页面只保留品牌、游戏标题和必要菜单动作，不常驻技术说明、版本串、原型状态、装饰性口号、重复提示或细碎标签。必要的错误、输入校验、保存选择和来源信息放到对应窗口，用正常可读字号；不得以删除关键后果说明来冒充简洁。
2. 主菜单的所有动作使用**无图标、无边框的纯文字按钮，集中右下角并全部右对齐**。主页文字较上一轮略小，菜单保持紧凑行距，三语自然排版且点击区域不重叠；hover/focus靠文字/背景明暗与字重表达，不画外围框、不添加装饰图标。
3. 一般界面的文字按钮也不再强制附图标。地图底栏等密集工具只在图标确实解释功能、便于辨认时使用；可保留功能性tooltip/accessible name。图标不得承担“神圣/宗教感”的装饰任务，不因美术目标给动作添加十字、圣徽或任意符号。
4. Sonnreich原创Logo的**品牌中心仍在左上区域，向内移动而不紧贴角落**。拓扑由内向外为完整多圈同心内环、无射线窄空隙、几乎贴着内环的细三层外圈，最后是**仅从外圈起点向外延伸的大量低亮密集射线**；内环保持，外圈大幅缩小、三层边缘减细。射线降低亮度和辉光，保留长短/粗细差异，不能穿入窄空隙或变为稀疏游离束线。远端可越屏裁切，整组以品牌中心固定轻微顺时针倾斜；禁止持续旋转/呼吸/闪烁，不跟随World环境或充当真实时钟。
5. 游戏标题为大写 **SONNHEIDE**并右移；主页字体均较上一轮略小，右下菜单保持紧凑。**主页文字、射线和光晕统一为暖白微黄#fff6df基色，字体和Logo柔光不变，射线亮度和辉光降低**，取消昏暗旧金文字；允许字形光，禁止按钮盒子的发光边框/ring。纪念性极简新古典/未来感与精密金色品牌构图保留，不增加小字或按钮图标。
6. 油画**亮部仅限小范围中央焦点，大部分画面连续渐暗、边缘更深**，覆盖上一版大范围清亮中心。小焦点保留画作亮度/颜色/笔触，原图不改字节，禁止整幅统一约半亮度或去饱和。两幅共用渐变层，继续ADR 0008极慢微移/淡化，不随World环境改亮度。Logo/油画记录原文件hash/允许托管范围，不擅授CC0或开源许可。

## 验收

三语/不同窗口比例中，主页字体略小、标题右移，右下纯文字菜单紧凑且不重叠，无icon/边框且可键盘访问；主页文字/射线/光晕基色同为#fff6df，字体和Logo静态柔光保持、射线亮度和辉光降低，无按钮ring。品牌中心左上向内；完整多圈内环→无射线窄空隙→几乎贴着内环的细三层外圈→仅从外圈发出的低亮密集长短粗细射线，远端可越屏；整组固定轻微顺时针倾斜且静止。中央亮焦点小，大部分渐暗但仍有画作层次；没有不必要小字，降低动态关闭油画运动。同步[应用流程](../architecture/APPLICATION_FLOW.md)、[视觉规范](../architecture/VISUAL_STYLE.md)和[施工计划](../planning/IMPLEMENTATION_PLAN.md)，不改环境计时/存载。
