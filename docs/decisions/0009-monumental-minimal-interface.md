# ADR 0009 · 纪念性极简界面与纯文字主菜单

日期：2026-10-07。状态：采纳用户最新视觉修正。覆盖[ADR 0008](0008-sacred-interface-and-light-ages.md)中“所有动作必须含图标/禁止纯文字按钮”的旧规则；油画计时、深沉背景、无边框、两种环境和基础优先施工顺序继续有效。原始设计源不改写。

## 决策

1. **禁止不必要的小字。** 主页面只保留品牌、游戏标题和必要菜单动作，不常驻技术说明、版本串、原型状态、装饰性口号、重复提示或细碎标签。必要的错误、输入校验、保存选择和来源信息放到对应窗口，用正常可读字号；不得以删除关键后果说明来冒充简洁。
2. 主菜单的所有动作使用**无图标、无边框的纯文字按钮，集中右下角并全部右对齐**。文字在简体中文/英文/德文中自然排版，间距和字形构成可点击层级；hover/focus靠文字/背景明暗与字重表达，不画外围框、不添加装饰图标。
3. 一般界面的文字按钮也不再强制附图标。地图底栏等密集工具只在图标确实解释功能、便于辨认时使用；可保留功能性tooltip/accessible name。图标不得承担“神圣/宗教感”的装饰任务，不因美术目标给动作添加十字、圣徽或任意符号。
4. 左上角使用用户提供的**Sonnreich公司原创Logo**，保持原有图形身份；其后可有微弱静态柔光，以及作者制作的长短、粗细不同的精细放射线。光晕和线条始终静止，不呼吸、闪烁、旋转或跟随环境Age。该Logo是公司品牌，不是游戏内宗教对象。
5. 游戏标题为美观的大写 **SONNHEIDE**。整体是纪念性、极简的新古典构图，金色克制、暗底深沉，兼有未来感和艺术网站的留白与秩序；不靠增加小字、图标密度或高亮装饰表达庄严。
6. 油画仍按ADR 0008极慢微移与逐幅淡化，主菜单不随World的Light/Darkness变亮。Logo/油画均记录原文件hash和允许的托管范围，不擅自授予CC0或改为开源资产。

## 验收

三语与不同窗口比例中，主菜单始终保持右下角/右对齐、纯文字、无图标/边框且全部可键盘访问；标题和Logo不挤压动作。没有不必要的小字，必要状态只在对应操作窗口出现。Logo柔光/放射线在等待、轮播和切世界时均静止；降低动态关闭油画运动。此决策同步到[应用流程](../architecture/APPLICATION_FLOW.md)、[视觉规范](../architecture/VISUAL_STYLE.md)和[施工计划](../planning/IMPLEMENTATION_PLAN.md)，不改环境计时与存载合同。
