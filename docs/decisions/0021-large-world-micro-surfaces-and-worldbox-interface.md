# ADR0021：大世界、独立微地表与WorldBox界面结构

本轮最新用户要求覆盖ADR0019/0020：取消之前所有前端约束，界面按WorldBox截图参考重做；扩大创建尺寸，连续拖拽选区；地表的最小颗粒度与建筑合法占地单位分开。soil/sand与所有水面同高，按统一0m解释；海床水深继续存在。以下是本批实现合同，验收通过前不称游戏完成。

## 必须突破的边界

旧版本将250mm小格密集铺满世界，1008²上限只对应252m；全部格还有逐格revision、保存和全域GPU驻留成本。再减小同一个格距会进一步缩小物理世界。必须把建设管理单位、实际地表覆盖、素材像素、屏幕LOD四者分开，所有权威查询仍落到同一实际地表。

新几何profile 2采用2m管理格，每格最多64×64独立微表面，即31.25mm。管理格不是建筑自动有效的证明；建筑必须检查完整实际支承及通路。均匀区域用逐行RLE保存，只有岸线/编辑/不同覆盖格才存微片；微片是palette与独立编码的indices，海陆两色允许1bit原始片，并按真实微行选择无损区间或行字典；典型斜岸不重复存64行位图，任意复杂形状仍有bitpacked fallback，不为均匀8km世界分配数十亿微面。所有预算根据实际结构计算，超预算原子拒绝，不能截掉细岸或静默降低精度。128MiB仅指权威geometry驻留预算；source共享内存、最高128MiB生成scratch、旧世界/隔离候选/存档临时与GPU各自单列，不能称游戏总内存128MiB。

五个实际创建预设：256、512、1024、2048、4096管理格，即512m、1.024km、2.048km、4.096km、8.192km。默认1024²，Blank长宽独立，Earth保持地理纵横比例。最高尺寸须以真实创建、细覆盖、存载和GPU场景验证；人群文明容量仍须后续实测。

新soil/sand表面为0m，与海/湖面同高；深海/近海/浅水海床仍−20/−8/−2m，hill/mountain/highpeak仍16/48/96m。不能以height>0判陆、以height=0判水。kind与微片覆盖决定陆水；水深由已知海床到统一水面派生。共面渲染按同一实际覆盖互斥，不用抬高陆面或海面掩盖冲突。

稀疏微片进入查询、mesh、raycast、hash、保存、重载及事务；Earth以官方GSHHG全精度线段命中的管理格细采样，保留中心粗采样可能漏掉的小岛/狭窄水道。二值微片在原始位图、固定单跨度行、多跨度行、单跨度行字典和64bit行字典之间选择较短的无损编码；近景按行展开，远景按palette计数汇总，不能逐个岸格展开4096样本来初始化概览。geometry hash流式读取统一解码字节，编码变化不改变世界几何hash，也不积攒全世界原始位图缓冲。TERRAIN schema 2记录独立index_encoding与共享palette表；schema 1保持原字节。视觉噪声不更改权威海陆，不能把普通数据chunk边当海岸。profile 1显式250/2000mm旧几何仍按旧高度解释，不静默迁移不同定义/资源hash的旧存档。

人造填海对选中的管理格只替换实际水面微片，已有陆地的kind、theme、revision保持原值；真实变化微面和面积进入后果预览及一次提交。神力不得产材料；文明施工材料劳动属于后续真实建造领域，不能以该几何命令伪称已经完成施工产业。

## WorldBox参考与独立实现

根代理实际在浏览器查看了三张参考图：[开发者工具栏图](https://pbs.twimg.com/media/Far8W91XgAAxuAm.png)、[开发者地图叠层图](https://pbs.twimg.com/media/FdxpN2qXEBkSxIE.png)、[创建窗口截图](https://cdn-www.bluestacks.com/bs-images/WorldBox_Play-on-PC_ES_2-591x1024.png)。官方[更新记录](https://www.superworldbox.com/changelog)说明PC的Iceberg大于Titanic、创建尺寸具有数字和图标、工具栏可调大小。截图不能证明闭源内部算法或精确米制尺度；本项目的管理格和微地表算法由自身定义。

采用可观察结构与用户最新覆盖：全部框改深色半透明像素窗口，切角/明暗边、嵌入标题和独立关闭按钮；截图中的实心灰橄榄底板不采用。面板#082c3bcc、底栏#062b39c8、输入#0a2836b0、tooltip#092735e8；外沿与内部填充互不重叠，避免透明度叠加失真。底部上排紧凑类别剪影tab，下排当前类别彩图标工具格，选中砖红，工具全称在实际tooltip显示。创建窗口有明显的尺寸预设与独立轴、底部主操作、清晰预览/返回状态。三语、typed意图、输入隔离、草案与后果预览必须保留；未实装机制仍明确禁用，不能复制WorldBox品牌、图标、贴图或假造工具成功。

## 连续地图框选

底图仅随视口/地理范围变化重采样；选框由每frame原生UI覆盖，不能把选中区域烘进异步地图RGBA。一次按下捕获指针，移动连续更新经纬度与归一化选框，越出地图仍有边界夹取，释放与失焦解除捕获；UI不能偷吃拖动中的release。仅选框变化走局部UI更新，不重建整页、不重新layout、不触发GSHHG采样。选区支持当前完整地图经纬范围，取消旧60度绘制上限。

原生验收必须多次真实SDL motion、检查每次UI实几何和期间source raster次数为0、GPU中间截图、release/失焦/越界与缩放后再拖拽。完整批次修改与跨模块审查结束后统一编译、完整CTest、sanitizer与原生GPU，不沿用上一批证据。
