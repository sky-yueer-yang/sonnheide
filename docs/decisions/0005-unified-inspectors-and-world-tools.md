# ADR 0005 · 全域互通信息页、世界工具与显式人口来源

日期：2026-10-06。状态：采纳本次用户变更，生产合同已登记；可运行前端原型与有限 headless oracle 的验证范围以实际交付记录为准。本文不声明完整 World、原生窗口、GPU 拾取、全领域编辑、死亡继承或经济统计已经实现。

## 1. 最新决策与旧规则覆盖

用户要求现在加入世界统计与跨对象比较、World Laws 全球规则、人物/物品收藏与地图标记、树木/矿物/植物/建筑/道路/生命清理，并全面建立直观、集中、相互跳转且能编辑的对象信息页。地图近看点人进入人物页；人物页点击国籍进入国家页；远看点击国家疆域或牌子进入国家页；国家、城市、企业、文化、语言等也必须能继续进入相关对象。

所有人物只有两种新建来源：玩家主动放置，或已有真实人物繁衍。玩家放置的人固定以 18 岁开始，繁衍出生的人从 0 岁开始。世界创建不自动播种人口，殖民、迁移、征募、叛军、企业招聘、宗教活动、人口不足补救不能再创建人。没有外来人口刷新、克隆、复活或后台随机新居民。加载仅恢复已有 ID，开发测试初态明确标记，不得作为自然人口增长。

从 0 岁到老死，所有人物采用同一身体规格。年龄不改变身体尺寸、骨架、碰撞/入口净空或服装 fit，不制作儿童比例、小孩 skeleton，也不把成人网格缩小模拟儿童。本决策明确覆盖 ADR 0004 第 7 节中的“儿童使用正确比例与适配衣物”以及其他旧文档的儿童体型/成长换尺码要求。性别及允许的外观材料区别可保留；人物仍共享同一尺寸规范和骨架接口。年龄仍决定入学、成年资格、衰老和寿命等仿真规则；成人外观不赋予儿童成人岗位/军役资格。

本次直接生命清理是玩家神力工具：清理真实 Person 时产生死亡和不可变历史，不只是移出镜头，也不能用旧版“非破坏性工具”要求拒绝这一功能。本决策只覆盖明确选中的生命清理，不加入怪物、瘟疫、随机灾害、现代炸弹、免费库存或天然地形编辑。

## 2. 必须突破的几个边界

1. **同一对象在不同页面、地图代理和历史中保持同一身份。** 用带 world/kind 的稳定引用，不能以名字、数组下标或当前绘制实例为身份；档案和拆分后的物品保持可追溯引用。
2. **全知查询与写入权限分开。** 看见账户、库存、国籍并不使这些字段能任意改值。信息页提供明确字段编辑和程序入口，所有世界修改仍经单写者命令；禁止任意 JSON 覆写。
3. **神力清理不是无代价删行。** 删除建筑或道路会影响住户、财产、库存、合同和旧入口证书；必须先计算受影响集合并原子处理，不能吞货或让邻楼断路。删除生命须死亡结算，不能连同债权/亲属/作品抹去。
4. **统计口径决定比较含义。** 国籍人口与所在地人口不同，货主资产与保管库存不同，在途不可双计，跨实体总和必须排除重复。统计需带时期、分母、版本和来源。
5. **全球规则不能暗中创造人和物。** 关闭饥饿后仍显示真实食物需求；禁止新 AI 战争不删除既有战争；开关跨保存与排队提交仍有效。
6. **统一身体不等于统一年龄。** Placement 18/Birth 0 与全龄共享尺寸必须分别成为创建、加载、渲染和服装接口的合同。

## 3. 统一信息空间

建立一个实体注册表，首版登记 40 种已有领域对象，详见 [INTERACTION](../architecture/INTERACTION.md) 和 [机器合同](../../data/interaction_schema.json)。其范围包含人物/家庭、聚落/城市/国家/帝国/联盟、文化/语言/宗教/教派/教会、企业/设施/生产线、建筑/道路/港口/车辆、衣物/货物/账户、合同/预约/运输/工程、发明/研究/文献/许可、植物/矿床，以及战争/条约/文明创生/姓名/历史/世界/地图标记。

同一个侧边面板使用共同结构：概览、关系、资产与任务、统计、历史、编辑。各对象的空节隐藏并解释缺失原因，不能用大段原始 JSON 代替内容。上方固定对象标题、状态、收藏、定位、跟随/比较、前进/后退；概览突出最多四项主要事实和最重要的当前问题。全部关系显示可点击的对象卡或标签。

人物页必须明确区分法定国籍、居留资格、住家城市、即时所在地域、雇主、实际服役国家、文化、语言与信仰；财物页必须明确区分所有者、控制者、保管者、位置、预约和在途。关系标签不能合并成一个模糊“所属”。国家远景点击依据激活图层区分法定领土和实际占领，不把占领者写成国籍或主权。

全局搜索、筛选、收藏与地图标记复用注册表。物品收藏以真实 item/batch 为目标，不将商品种类或图片当库存。不存在的历史目标进入档案；改名、死亡、拆楼、货物拆批不改变旧引用含义。地图标记属于玩家观察资料，不占地、不生成资产。

## 4. 编辑与清理

名称、允许的性格、任务优先级、偏好、预算草案等明确允许字段提供就地编辑。国籍、财产转移、法律、任命、机构迁址、合同、维修、知识采用等提供对应程序入口。姓名来源、作者、历史事实、生命来源、初始年龄、实际余额、库存、现有磨损和天然地图只读。每个锁定字段显示原因与可用合法路径。

清理工具明确分类：树木/植物、地图矿物资源层、建筑、道路、人物生命；“全部”是这些被勾选类别的联合，不包含天然水陆、高程、造陆、企业法人、文化或文献史。小批量按依赖连通分组预览，组内原子；若选择独立分组部分执行，提交前须展示分组成功/拒绝策略，不能悄悄漏目标。

建筑/道路直接神力清除可以不走普通拆除工期，但必须保存债权/产权历史，疏散住户与容纳人物，搬迁或显式核销实际货物、取消/重路由预约和在途合同，并为所有仍存在建筑提供合法替代通行证书。不能安全安置或替代通行时，该依赖组拒绝并显示原因；不自动扩大成“顺便杀人/清掉客户货/拆掉邻楼”。普通有劳动的拆除另设入口，不用来替代用户要求的神力清除。

人物清理记录 `DivineDeath`，保留 PersonId/姓名/亲属/国籍史/作品，终止其未来任务和身份岗位，结算唯一死亡、遗产和实物保管交接。批量死亡不得重复继承、复制军装、把仍活人的财物分给继承人，或为替代空缺刷新新人。先知死亡保留根绑定历史；军队仍由实际幸存者及继任规则决定。

矿物清理有两种明确意图：默认“清除矿源”令 rate=0 并核销当前可采储量；可选“仅清除当前矿量”保留 rate，后续仍可能再生。两者都只作用于资源层，不改变冻结高程、水陆、地下空间、已采出货物或仓库库存，不给玩家免费矿料。当前有限 oracle/展示原型只演示资源记录停用，对应“清除矿源”，尚未实现真实矿量积分、库存损失账本或可选仅清当前矿量。

## 5. 全球规则与人口

World Laws 页面是世界级仿真规则，国家法律页面仍维护本国制度。四项世界开关为允许生育 `reproduction`、允许仿真衰老 `aging`、饥饿后果 `hunger_consequences`、AI 发起新战争 `ai_new_wars`，默认都开启。改变记录为 `WorldRuleChanged`，保存来源、旧/新值、生效 tick 和 revision；下一提交屏障统一生效，不追溯改写过去。

- 关生育阻止所有后续 Birth 提交，排队候选提交时二验；已有儿童保留，玩家放置仍可用。
- 关衰老冻结 simulationAge 和依赖该年龄的成熟/自然老化，不倒退年龄，不复活，不消除已有伤亡；出生日期和经过日历时间保留，界面同时解释冻结。冻结 0 岁者不会因为共用成人外观自动成年。
- 关饥饿后果暂停营养欠账增长及饥饿制裁/死亡，食物需求、正常真实消费和购买预算仍存在；不赠食物、不计虚构成交、不把缺货当满足。旧营养欠账冻结保存，恢复后从真实保存状态继续，界面明确恢复含义。
- 关 AI 新战争只阻止 AI 新战争发起，包括新的战争声明；现有战争、占领、仇怨和有效军令继续。玩家战争动作仍走合法命令、资源及外交约束。

神力生命清理、战斗伤亡等不会因为关闭衰老/饥饿而被取消。规则开关不是神力修改余额或跳科技的入口；真实地形、材料守恒、身份分离、港口/造陆与旧入口保护永不变成可关规则。

## 6. 验收与阶段

必须验证同名与改名引用、近人远国拾取、跨页前后导航、死亡/拆批后收藏、只读查询 hash/RNG 不变、编辑过期预览、批量清理的货物与路网保护、反复死亡幂等、Placement 18/Birth 0、规则关闭下排队 Birth、保存续跑一致、年龄不影响身体规格、比较口径不双计。

前端原型可以用标记清楚的夹具演示 40 页、导航、表单、筛选和预览；独立 headless oracle 可以证明有界身份/规则/命令合同。只有在接入真实全域 World 和对应事务，并完成贯穿场景后，才称这些产品功能实现。原稿、第三方许可与原创建筑限制保持原样。
