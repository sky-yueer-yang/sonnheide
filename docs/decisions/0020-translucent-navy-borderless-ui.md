# ADR0020：半透明深青蓝与无框大图标

2026-10-10，按最新用户纠正覆盖ADR0019的柜式边框、紫绿主色与大字号；最终指定所有框为深色半透明，替代中途卡其羊皮纸提案。ADR0019的250mm真实地形、32px/m材质、显式旧格距、创建/拾取/存载同源继续有效。

背景为偏青的深蓝；主页保留闪烁细星和偶发流星。删除主页大外框和五个大色块按钮，改为紧凑、无描边的像素菜单。重要标题保留清楚层次，正文显著缩小。不能只写font-weight:bold而假称当前Regular字库已经加粗；重要处使用实际像素字号、亮度与有界实体投影。

信息窗口、创建面板、底栏、输入、下拉、tooltip与浮动工具全部用偏青深蓝的半透明填色，让背景仍可见；文字浅白蓝。按钮尽量无边框，底栏按钮全部无边框；选中、悬停、按下和键盘焦点采用实际填色/字色/图标明暗，不能用装饰线围住每个工具。工具按钮固定宽、图标与字居中，避免含block子节点自动撑满整个面板；工具框依内容收紧。

底栏以大图标为主、小字为辅。宽屏目标64dp图标和12dp标签，窄屏保持比例；英文/德文使用可识别短词，完整名称进入tooltip，三语信息不丢失。文字宽度尽量接近图标边长，不再用长句撑开按钮。所有当前页面采用真正像素字体，布局仍保640×480、DPI1/2、可达滚动与输入隔离。

UI和图标以蓝、红、白、黄为主；黄色本色统一#ffaa00，允许从它派生亮暗渐变。世界植物的自然绿色与机制国家theme不因此改变。原创图标保持32逻辑格、96/192整数点采样、二值alpha、配方和hash；不新添未接入工具。

表现时钟与World独立，隐藏/降低动态/世界暂停严格冻结，恢复不跳时。原生GPU两帧冻结对照允许最终UNORM通道最多1/255舍入差，并同时要求CPU时钟严格相等；活跃对照必须有超过这一差值的实际像素运动。报告如实记最大差和容差，不声称GPU字节完全一致。
