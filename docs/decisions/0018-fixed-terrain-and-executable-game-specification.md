# ADR0018 固定地形与可执行游戏规格

日期：2026-10-09。状态：用户最新规则已采用；运行定义、参考算法和接口规格已交付并通过本批有限核验。**不是原生游戏完成证明。**

## 决策及覆盖范围

1. 新世界没有已解锁枪械、火炮、火药库存或持枪军队。原始/早期文明使用实际制作的冷兵器；弓弩也需各自知识与装备。后期火绳/燧发和炮只能在对应科技、工艺、设备、实物、训练和合法征募均满足后使用。研究只解锁能力，不赠成品。军事模板列出全部阶段，不表示开局全部可用。
2. 取消自然地理对象的稳定身份：山、峰、海、湖没有实体、名称、ObjectRef、信息页、继承、分裂/合并谱系或保存的身份锚。导航仍根据真实水面/坡面计算版本化连通分量；它们只是可重建空间索引，不能成为收藏对象或法律主体。人物、动物、机制树木、实物、城市等真正机制实体继续有稳定Ref。玩家地图标记仍可命名，标记属于玩家记录，不生成被命名的湖/山。
3. 每种普通地形只有一个固定高度：深海−20m、近海−8m、浅水−2m、沙+1m、土+2m、丘陵+16m、山地+48m、高峰+96m。所有参数作为同一WorldProfile版本冻结。没有类型内高度噪声、自由高度、平滑画笔、海岸坡降或选区自然化过渡。水面固定0。升降只跳相邻固定档，平整只涂为选中档；同类型相邻普通格绝对同高。
4. 先前明确批准的坡道仍是唯一地形几何例外，连接两个真实固定高度平台，按固定采样产生连续坡面。坡道需要完整可用通路，不能以坡面绕过高峰禁入；移除是新的有后果事务。普通类型画笔覆盖坡道时撤其几何归属/证书，并按最终真实后果处理。
5. Blank/Earth都精确矩形量化和裁切，不为了藏矩形海岸而暗改陆地。不做边缘不规则岸线和高度过渡；外围保护海域与更远纯表现海面继续存在，无实体墙或世界边框。取样/最高预览/生成/读档同管线。此决定覆盖ADR0011/0012/0014及v0.8的不规则外缘/自由高程部分。
6. 首样时间改为20tick/运动秒、12000tick/游戏日、500tick/日历小时、360日/年；各域共享命名转换。变速只改变墙钟。移动、休息、劳动、研究使用实际tick，不凭日历标签补完成；长旅行可跨天。

## 本批交付及权威边界

v0.9主设计与game_v0_9是当前总入口。新增运行基础、涌现、交互合同和life/combat/economy/technology定义包，收口上一轮识别的九类缺口。culture/Language/subspecies分别使用共同实践证据、真实交流与遗传繁育图，而非同一经验进度条。所有离散数值为可调的游戏首样参数，不能宣称科学事实或已平衡。

参考Python算法能核验确定性、单位、保存连续性和具体小场景，但不代替C++实现、完整3D碰撞、GPU画面、长期经济、最终世界容量或Steam实机。已有源件、历史审计与原v0.6逐字保留。本批全部改动和交叉审查后统一验收；不在小改后反复编译。

## 优先级

本ADR与v0.9新增可执行定义覆盖现有合同中的旧默认/骨架；各合同必须显式引用唯一计算所有者，不允许同一生命伤势、科研进度或货币余额由两个域计算。历史ADR0014—0017保留为决定来源；随身递归保护、真实材料送料自动施工、人口来源、原创像素资产、八底栏/三语和Steam唯一发行继续有效。
