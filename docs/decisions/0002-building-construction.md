# ADR 0002 · 材料实送、自动建房与分层铁丝网表现

日期：2026-10-06。状态：用户确认的设计变更；生产建筑系统与GPU动画尚未实现。本次新增可播放的视觉预览，不将其视为游戏客户端。

最新[ADR 0010](0010-flat-land-and-coastal-transition.md)覆盖后续ADR 0003的真实高程及全楼找平要求：内陆统一平面，普通房屋无独立找平地基；沿海确需支撑时才加基础/连接，纳入该楼自动工程。前侧到货仍在现存可达地面，围网闭合实际施工范围，人/车接入和旧路保护继续成立。

## 1. 本次具体替换

人物把真实材料送到建筑前侧接货区；建筑本体不需要人物砌筑、锤击或现场施工劳动，也不设置不可见的施工工人。材料齐备后按建筑定义的自动工期推进。

建造表现采用原创长方体铁丝网罩：从下向上逐层围起，约几秒；四面及顶部全部围好后保持包围；建筑完成后从上向下逐层拆去，使用相同动画的反向采样，约几秒。包围期间可加入少量预制建筑阶段动画，首版没有额外动作也成立。

这覆盖冻结原稿5.4/5.6中建筑本体的建造者熟练度、现场人工投入，以及建筑公司条目和13.5 Temple首期费用中对应的现场砌筑人工。材料、地块、资金、知识、法律、数量/宗教门槛仍保留；采购、运输、组织等实际支出保留。建筑公司的采购、物流、合同、组织和合法项目并发仍有作用，不能重新用“隐藏工人”恢复本体施工劳动。`construction_efficiency`在建筑本体只修正自动工期，不能同时获得旧施工劳时收益。

本次适用于房屋及采用Building工程的建筑本体，包括CitySquare建筑组件和Port陆侧建筑。**填海仍逐格、有材料和真实劳动、完工才变LAND；Port先完成RECLAIMED地基。** 道路/桥、维护、拆除和生产线工装没有被本次改成自动工程。原稿逐字保留，原稿生成目录仍标记源材料；运行时定义必须显式叠加本ADR，不静默改源数据。

## 2. 权威施工状态与材料

```text
WAITING_DELIVERY → AUTOMATIC_BUILD → COMPLETE
        ↘ CANCELLED        ↘ CANCELLED
```

- 接受项目时预约合法场地、接货/等待/退出空间、预算和源材料；未送达仍是等待状态，不能启动自动工期。
- 人物领取、搬运、交付是真实任务，占用Person时间和合法路线。人物动作至少为取料、持物行走、放料、返回；没有建筑`build`动作需求。
- 材料在源仓、在途、现场`SiteStorage`之间只有一份。现场保管人、货主与位置独立；不创建第二个城市Warehouse。到货确认来自运输事务，不来自放料动画的marker。
- 首轮规则为**所有必需批次实送到齐才开工**。开始事务重验材料数量/配方版本、场地、许可及整个网罩工程范围与接货/退出区清场；一次将全部建筑配方材料从现场库存记为`consumed`，写`startedTick`和正整数`durationTicks`。封网后不要求持续穿网补料。
- 可信Scheduler按SimTick自动推进至到期，不分配现场施工劳时。到期的完成事务重验工程仍有效，发布`completedTick/completeRevision`并原子启用建筑容量、入口和相应功能。
- 围/拆网几秒属于表现参数；**动画回调不扣料、不完工、不开放建筑、不延迟已经完成的入住或生产。** 取消/完工事务幂等，镜头、帧率、显卡和是否看见工地均不改变结果。
- 取消前未领取材料释放源预约；在途按运输合同停靠/返回；现场未投入材料保留真实地点并安排实际运回；取消`AUTOMATIC_BUILD`不返还已消费的配方材料，首版没有额外回收配方。未使用资金按合同释放，不把材料已耗规则扩大成所有资金不退。取消释放合法工程占用，不等待撤网动画。

存档保存工程ID、Building目标、配方/定义版本、现场实际批次与货权、在途运输、已投入量、状态、起止tick、完成事实和占用。建筑本体没有现场工人预约。自动工期具体数值、科技修正和合同组织费仍需后续平衡；不能把预览的中段秒数当生产工期。

## 3. 前端接货区与网罩空间

“前端”是建筑本地坐标中的交货前侧，不是屏幕下方。普通住宅首选局部`-Z`侧，Port使用合法陆侧道路侧；接货区与永久入口可以对齐，但保持独立定义。`deliveryAnchor`、卸料区、等待/退出点与建筑使用同一四向旋转和平移。

接货区位于网罩外可达LAND，须有合法使用权和道路净空，不能落在WATER、邻地产权内或Port泊位。送货者放料后从合法路径退出；开始包围前不把人物留在网罩内。接货区是空间锚点，不是凭空生成物品的位置。

`cageBounds`覆盖完整建筑主体、屋檐和屋顶，但必须包含于已批准的`constructionEnvelope`；禁止直接给模型AABB任意加padding侵入道路、邻地或泊位。若二者无法同时满足，修原创模型/合法工程范围或拒绝方案。它不修改最终footprint、容量、碰撞、authorityHash或冻结天然地表。包围动画使用固定完整bounds参与剔除，不随当前层数缩小。

网罩由原创矩形网片/线段生成，四面加顶盖，底面由地面封闭。`layerHeightM`决定竖向层数，末层允许不足整层；不是建筑楼层或容量。每层依次出现网片，不能将整个罩子纵向缩放成弹性立方体。顶盖随最后一层闭合，反向拆除时最先移除。

铁丝网是临时施工表现，**不增加钢铁资源、钢铁科技、城墙、城防或军事遮挡**；古代建筑也不因此增加现代工业依赖。建造期间禁入来自权威工地占用。完工事务后所有已启用人物/货运入口和装卸路径处的网片首帧让行，其他部分继续逆序撤除，避免合法进出看上去穿过封闭网片。

## 4. 可见状态与表现时钟

```text
DELIVERY → RAISING → ENCLOSED → LOWERING → READY
                         取消：当前覆盖比例 → 清除
```

首轮升起3秒、拆去3秒，均可调，见[表现参数示例](../../data/building_construction_presentation.example.json)。使用客户端单调表现时钟，游戏暂停时冻结，游戏加速不强制将3秒缩成一帧；权威工期仍按SimTick和加速正常推进。

设层数`N`、整体包围比例`p∈[0,1]`，第`i`层（从0开始）的展开量为`clamp(N*p-i,0,1)`。升起时`p:0→1`，拆除时`p:1→0`；中间完整包围时`p=1`。底到顶逐层展开/顶到底逐层撤去由同一函数决定。可选中段clip只播放，不输出权威事件；没有clip时保持完整罩子。

|情况|表现处理|权威结果|
|---|---|---|
|正常开工|开始RAISING，随后保持ENCLOSED|材料已由开始事务投入，自动工期已开始|
|完成发生在围网尚未升完|立即显示成品，记录pendingComplete，先升至完整罩子，再立即逆序拆除；入口同步让行|功能按完成事务生效，不等待包围补播|
|完成发生在ENCLOSED|停止可选中段clip，开始LOWERING，显示成品|不产生第二次完成/扣料|
|重复完成事件|按`jobId/generation/completeRevision`去重，不重启动画|回执/世界不变|
|当前可见工程取消|从当前覆盖比例反向退去；不补围顶、不生成成品；若场地被新工程复用，立即淘汰旧job/generation的网片|按取消事务结算材料与释放占用|
|镜头离开再返回|保留轻量表现时间锚，按经过时间直接采样；离屏完成的旧撤网不排队重演|工程照常推进|
|首次观察或载入WAITING_DELIVERY|恢复工地和真实材料配送，无网罩|未到货齐备不自动开工|
|首次观察或载入AUTOMATIC_BUILD|直接完整罩子，按当前工程快照恢复|不重开工/不重新扣料|
|首次观察或载入已完成/取消|直接成品/无罩子；不重播历史|不增加已完成/取消事务|

GPU对象、网片采样比例、局部表现计时和pendingComplete缓存不进入权威存档。降低动作偏好可用离散层快照代替连续运动，不能改变实际工期。LOD只降低网格密度/表示成本，不改变层数逻辑、工程ID或完成事实。

## 5. 本轮证据与后续接入

- 已更新建筑规则、合同、内容动作、渲染、存档和实施路线之间的交叉引用。
- 新增[可播放视觉预览](../../tools/previews/building-construction.html)：一位示意人物把材料送到前侧，离开后矩形网罩逐层围起，中段完全包围，成品出现后逐层撤去。中段时长是演示，不是游戏平衡参数。
- 预览不是Person物流系统、GPU客户端、真实工程或所有建筑资产的实现；现有C++填海正确性内核保持原语义。
- 生产接入验收：缺任意材料不启工；真实批次守恒；人物退出后封网；无现场施工劳时；四向投递/网罩净空合法；暂停/加速/早完成/重复/取消/离屏/载入不重复结算；完工入口让行；多建筑网罩有LOD与批次预算。
