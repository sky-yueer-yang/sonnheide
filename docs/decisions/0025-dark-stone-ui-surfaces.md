# ADR0025：深灰石材统一界面

2026-10-10。用户要求将石材改为很深的灰色，并用于所有弹窗等背景和大部分按钮，石面也要有裂纹。本条覆盖ADR0024的浅奶黄颜色、浅底深墨字及此前多材质背景分配；原有布局、功能、图标、世界和存载约束继续有效。

同一原创512²深灰石材用于创建、世界信息、设置、帮助、错误、存档、菜单承托、提示与状态面板，以及通常的动作按钮、工具按钮和分区页签。输入槽可以保留更深的黑曜石。非激活材质原件仍保留，但不再让窗体、提示或普通按钮呈现木、皮、蓝珐琅等不同大面积底色。

石材本色很深、近中性略冷，细颗粒与低对比矿物层次保留高分辨率像素质感。完整石面不变成碎石拼贴。裂纹由每个控件的真实边缘生成，短、不规则、少量分叉；按钮和页签也有适量裂纹，中央文字图标保持完整。凹槽和相邻断面有可辨明暗，不能靠大面积亮边或白框装饰。纹理按1纹素/逻辑dp、最近点采样，裂纹使用有界缓存几何。

全部正文和事实改用亮暖灰，次要文字用可读灰色。石面标题使用实际加粗的亮色字，不保留浅底深棕/深红墨色。普通、悬停、键盘焦点、选中、按下及禁用都保持同一种石材，使用足够清楚的明暗和文字强调区分；不得依赖大片彩色底板。原有彩色图标保留。

工具台保留连续6dp凸石沿、2dp阴面及站在其上的58/62dp页签。材质统一不得破坏凸沿连续性、文字排版、三语、DPI、窄窗口滚动、模态遮挡、草案或世界事务。资源颜色不影响模拟、Age或存载。
