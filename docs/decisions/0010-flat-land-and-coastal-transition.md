## 1. 最新决定及删除的依赖

只使用全球真实海陆/岸线数据保留大陆、岛屿、海峡和湖泊的水平轮廓。不使用真实海拔、山脉、丘陵、河谷或真实海底高程；新世界不需要 ETOPO、DEM/DTM/DSM、垂直基准转换、真实地形高程误差或 X/Y/Z 三轴地理等比转换。

天然陆地在水面上方一个很小、统一的游戏高度。普通内陆全部为平面，普通房屋直接立在该平面：无独立找平地基实体、无额外找平材料/工期、无内陆山坡接入求解。仅水边的狭窄过渡带逐渐下降、接触水面并延伸为水下浅滩；只有位于这条过渡带且实际需要支撑的建筑才增加原创长方体地基。

水平投影、`worldScale`、天然水陆及完整岸线仍在世界创建后冻结。统一陆面高度/过渡宽度是游戏米制的表现与接触参数，和人物、原创建筑的尺寸使用同一游戏单位；它们不是现实地球高程或现实地形缩放。正式数值在地图视觉与可通行性验收时固定，不在本次设计修订中擅定。

## 2. 不把海岸表现变成新增陆地

`NaturalLandWaterMask` 和完整 `CoastCoverageIndex` 决定天然 LAND/WATER。岸坡只在已有真实水陆交界上生成，不把真实岸线移到别处，不用显示表面的 Y 正负或水体波峰判定水陆。合法有效陆地支持域是天然 LAND 与已经完工 RECLAIMED 的联合；未完成填海仍是 WATER。格心为 LAND 不证明整个建筑 footprint 都在陆地，必须按完整岸线/已完成工程几何核验。

设静水面为 `Ywater`，统一陆面为 `Yland = Ywater + H`，`H > 0`。以冻结天然岸线在游戏 X/Z 中的有符号距离 `d`（陆侧为正）和固定陆侧宽度 `W` 派生局部表面：

```text
d >= W:       groundY = Yland
0 <= d < W:  groundY = Ywater + H * S(d / W)
S(t) = 6t^5 - 15t^4 + 10t^3
d < 0:       天然WATER；未填筑时水下浅滩不提供陆地通行权
```

陆侧曲线在岸线和平台接缝处平滑；水侧接同一位置/切线，不采真实海底。已完成填海单独提供ReclaimedSurface，不改此天然派生面。导航查询和渲染从同一版本的天然规则与已完成工程表面取接触高度，不让人物穿地或在未填筑水域获得免费陆地路径。水体波动仅表现，不改天然水陆或触发灾害。海/湖水面采用统一游戏基准，湖岸默认复用水边过渡，仍保留原始海/湖/岛嵌套拓扑。

`H/W` 必须满足需开放的自然步行坡度，不用陡岸坡伪称可走。区块接缝采用同一岸线和有效距离范围的 halo；选区边、tile 边不是海岸。资料不完整或接触几何无法保证时返回不可用/Pending，不补造岸线。窄岛和狭窄陆带可以全处于近岸过渡带而无内部平台，但不能为制造平台删除岛屿、拓宽陆地或封海峡。显示 LOD 不重写权威岸线。

## 3. 岸坡在填海后也保持不变

岸坡只从 **冻结天然岸线** 派生，绝不从动态 `effectiveSurface`、当前水域距离或玩家填海结果重新生成。否则一次填海会外移显示岸线并抬高既有天然地面，破坏老楼与通道。

完工填海仍是独立 `ReclaimedSurface`，首版顶面接统一陆面；与较低天然岸坡的高差通过该工程的合法连接表面解决，不修改旧天然地面或旧接入证书。它仍须逐格、四邻接、有真实材料劳动、完工才变 LAND，不能以平地或岸坡规则免掉工程。水下浅滩不是填海，Port 核心仍须全在已完成 RECLAIMED 上、正交、保留连续 WATER 泊位。

## 4. 平地与沿海建址分支

|条件|主体与地基|接入验收|
|---|---|---|
|完整占地及接入均在统一陆台|楼板/门槛接统一陆面；`Foundation = None`|平面人行入口、必要车库车道、前侧现状接货及净空/宽度/权利/旧路保护|
|完整占地合法 LAND，但与沿海下降面有实际高差|楼板固定统一陆面；仅此情况添加长方体支撑，填补必要支撑空间|完整人行连接；有车库时用车辆可走连接，不以台阶代替车道；现状配送单独可达|
|占地有未填筑/未完工 WATER 或有效陆地支持不完整|拒绝普通建筑；不能把地基伸到未填筑水上造陆|不能用水下浅滩、波浪、未来坡道或未完成填海证明可达；已完成填海可合法支持|

移除旧 oracle 的“每栋 `floorClearance > 0` 且 `embed > 0`”默认要求；仅输入零高程仍会自动造出地基，不能作为本决定的实现。建筑普通底板是原创楼体的一部分，不是额外的找平工程。

批准仍把完整 footprint、可选沿海地基、各必需入口、人/车接入、前侧现状接货与退出路径、临时网罩、永久通行保护及权利作为一个单写者事务。无地基不等于无建址校验；不得堵门、车库或旧邻楼通道。不同入口沿同一个固定楼板布置，后建项目不能改变老楼楼板/地面/道路接点；改路先验证并预约可用替代路线，再原子切换，失败保旧。

人物实际送材料到前侧现存地面；不能依赖未来沿海地基或连接构件送达它们自己的材料。到齐后自动工期，无砌筑人物；围网层起层撤只读工程状态。普通平地不添加地基配方和动画，沿海必要构件纳入对应建筑配方/工期及罩范围。

## 5. 创建、存档、来源与范围

正式创建包只需经过逐项官方许可/版本/hash核验的海陆/岸线、水平投影与范围/分辨率/拓扑证据，以及固定的平面/岸坡配方。不下载或要求新的高程包。世界仍人口0、建筑0；候选校验和首存档成功后发布，取消/失败保留旧 World 与继续指针。未来保存记录天然 mask/岸线/配方/参数/hash，而非真实 DEM。

不自动把旧高程研究/未来旧 profile 存档改解释为平地世界；已发布世界如存在仍按原 profile 加载，转换必须显式新世界或有证据的迁移。当前没有生产高程 World 存档需要转换。

已托管 ETOPO 窗口、原始来源和许可证保留为历史研究，停止新增高程采集，不列为当前世界创建依赖。旧 `site.hpp/site.cpp` 坡地 oracle 仅保留独立历史回归，从当前 kernel 链接图移出；它不是新的平地/沿海建址实现。Abyssal Ocean 固定代码与许可继续采用。

本次完成规则、工程依赖和施工计划的修订；已有 headless 天然海陆/填海/Port 不变量沿用。原生地图、岸坡表面、新建址、生产创建和世界存载尚未接入，本次不下载真实海陆包、不冒充创建一个世界。
