创建设置是画面正中央的一个弹窗，608dp宽、648dp高的目标尺寸，宽高均受视口减32dp约束；内容可滚动。成功预览后折起为底部创建托盘，三维场景可360°查看，选项可恢复居中的完整表单。改名称、尺寸、地表或主题使旧候选失效并重新打开表单；候选取消、迟到结果隔离和首存档持久读回后发布不变。

所有信息框保持深色半透明；主色蓝、白、红、黄，黄色基色 `#ffaa00`，背景为更深、稍偏青的蓝。用户追加纠正：纯白描边是全周均匀的平面轮廓，绝不作为上左高光或白色斜面。控件、弹窗、工具栏与页签只使用深色边缘表现厚度；中心只混合一次。图标使用原始32格、整数缩放、二值透明度，饱满深饱和蓝与略偏橙的深红；全周均匀白轮廓和细深蓝外界线，无定向高光、投影或亮色分区。

重要标题使用红/黄实体字、均匀纯白像素描边。锁定字体仅有Regular，不请求不存在的Bold字面：原创FontEffect以单向水平实体膨胀加粗中文标题和世界名称，保留内部笔画空隙；主页Latin标题保留方形膨胀。外层为均匀白色二值轮廓，无白高光或阴影。字号、描边与DPI同源；不能用多份重复标题冒充可编辑重要文字。

八分区使用搭接工具栏上沿的低矮梯形页签：顶窄底宽、阶梯斜边、底口开放，选中状态略高并使用深橙红；不能画成八个四边封闭的独立方块。参考已实际检查的[WorldBox开发者界面截图](https://x.com/Mixamko/status/1575249911507046400)，只参考结构与衔接，使用本项目原创图标。工具栏内部仅当前分区按钮，类别与工具分层，八分区都可选择；尚未生产实现的工具明确禁用，不能伪造执行。Settings页签先显示该分区工具，再由设置按钮打开实际设置窗口。工具全名使用三语悬停说明，键盘focus与pressed均有可识别状态。
