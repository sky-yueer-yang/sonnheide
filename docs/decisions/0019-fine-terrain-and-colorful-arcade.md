# ADR0019：细地形、彩色街机与星空主页

后续视觉由[ADR0020](0020-translucent-navy-borderless-ui.md)收紧为深青蓝/半透明无框、大图标/小字；本条250mm地形与同源尺度继续有效。

2026-10-10，按最新用户要求实施。视觉覆盖此前主题色、禁绿紫、禁止描边、纯文字主页、油画/花园背景与粗块Minecraft画面；其余规则继续由ADR0018规定。

全部当前界面重做为色彩丰富、高分辨率、细像素复古街机风。黄色本色唯一为 `#ffaa00`，阴影、明亮与渐变从它派生。中性文字用白色。Age改变世界环境及必要状态，不限制UI整套颜色。

主页只有深蓝星空、细星闪烁及偶发流星。星点大小、分布、闪烁相位与流星周期稳定，由本地表现时间驱动，不创建World，不用模拟RNG，不加载油画、花园图或假的菜单陆地。降低动态和隐藏窗口保持当前时刻，恢复不跳时；游戏暂停冻结世界表现动画。

新世界格距250mm，材质32px/m。默认512²格即128×128m；当前最大1008²核心格即252×252m，加8格保护海。Earth选区统一游戏缩放，非1:1真实地理；UI、生成、最高预览、拾取、水深与保存读同一尺度。尺寸先量化整数微度再计算，不能在UI另用浮点ceil。

几何revision是变更序号，不是格距schema。保留显式旧2000mm几何解释；definition/asset hash仍严格，不能因此称实际老版本档案已迁移。保留旧存档与指针，不静默缩小旧世界。

新格距下计划坡道角高量子为1mm，否则125mm/250mm使最小单面坡度50%，无法满足普通车道。坡道尚待S02实装；历史125mm场景不是新profile验收。八种平地高度不变，不增加自由高度、自然岸坡或第二套碰撞面。

渲染精确合并同高度/同类型/同主题顶面，保留全部侧面和海岸；世界空间纹理不随合面改变。纯装饰花草随风动，没有库存、食物、碰撞、导航、任务或TreeRef。机制树、人物、动物、建筑在后续施工。

整批修改与交叉审查后统一构建ALL、完整CTest及sanitizer，再做真实GPU贯穿。记录运动及冻结对照；按ADR0020严格核本地时钟并允许GPU最终通道1/255舍入差，不声称字节完全相同。Windows GPU和Steam安装独立实测。
